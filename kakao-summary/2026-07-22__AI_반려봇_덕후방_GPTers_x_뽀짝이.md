# AI 요약

## 인사이트·노하우

- **Hermes Agent 0.19.0 주요 변경사항**
  - 첫 응답 시작 시간 약 80% 단축
  - GPT-5.6 (Sol/Terra/Luna/Pro) 정식 지원
  - 모델 실시간 추론 과정 표시 기능 추가
  - Gateway 재시작 후에도 완성된 답변 복구 전달
  - 단일 Gateway에서 채널별 서로 다른 Hermes 프로필 연결 가능
  - 서브에이전트 작업 과정 실시간 확인 + 재시작 후 결과 복구
  - Bitwarden·1Password에서 API 키 직접 로드 가능
  - 신규 모델 추가: Claude Sonnet 5, Grok 4.5, Kimi K3
  - CLI 기능 추가: 구독 관리, 일회성 모델 변경, 세션 내보내기

- **Claude Code 5시간 사용량 10분 소진 문제**
  - 원인 후보 1: 다이나믹 워크플로우가 활성화된 채 고사양 모델 다수 호출
  - 원인 후보 2: 계정 해킹 (실제로 웹 콘솔에서 연결된 기기 전부 삭제 후 해결된 사례 보고)
  - 대응: 웹 콘솔에서 인증 토큰·연결 기기 전체 삭제 → 재로그인
  - "다이나믹 워크플로우를 끄는 기능이 있습니다" — 과도한 에이전트 자동 소환 방지
  - MAX 플랜은 사람 상담사 연결 불가 → 문의는 로봇 채팅만 가능

- **Claude Code Fable 사용 시 자동 에이전트 소환 현상**
  - Fable이 기본적으로 멀티에이전트를 띄워 진행 (`0/5 agents done` 표시)
  - effort 설정을 ultracode가 아닌 일반 모드로 낮추면 단독 처리

- **컨텍스트 초과 시 처리 방법 (Claude Code)**
  - 선택지 1: 오토컴팩트(자동 압축) 기능 사용
  - 선택지 2: 핸드오프 후 새 세션 생성

- **모델별 언어 품질 차이**
  - 한국어 감성 표현: Claude > GPT > Codex (Codex가 deepseek v4 flash보다도 문학적 표현 열위라는 평가)
  - "영어 클로드보다도 한국어 클로드가 말투가 매우 따듯하다"
  - GPT는 학습(프롬프트 튜닝)으로 말투·길이·습관 교정 가능
  - "굳이 따지면 F인 사람과 T인 사람 같은 느낌"

- **로컬 LLM 실행 환경 선택지**
  - ollama / llama / LM Studio 중 LM Studio 사용자 보고 있음
  - "llama가 성능이 더 좋다는 말이 있다"는 언급 있으나 구체적 근거는 불명

- **Orca vs Hermes 개념 정리**
  - Orca: AI 코딩 에이전트 특화 작업 환경(터미널에 가까운 개념), 에이전트 게이트웨이·세션 관리 부가기능 포함
  - Hermes: 실제로 일을 수행하는 AI Agent (뇌=모델, 신체=에이전트 툴)
  - "일을 하는 건 Hermes가 하고, Orca는 CLI를 불러올 수 있는 것" — 업무 자동화 시 Orca 유무가 결과에 큰 영향 없음

- **Hermes에서 GPT가 최선이라는 현장 평가**
  - "헤르메스엔 지피티가 일단 최고 — 사용량도 많고 일 잘함"
  - GPT의 단점: "장문충" (불필요하게 긴 응답)

- **Codex 연결 오류 (`waiting up to 30s before retrying startup initialization`)**
  - 복수 사용자 동시 발생 → OpenAI 서비스 장애로 추정
  - Codex 5시간 한도가 사라지고 주간 한도만 남았다는 보고
