1️⃣ Anthropic, 가장 싸고 빠른 소형 모델 Claude Haiku 5.5 출시

Anthropic이 10월 7일 Claude Haiku 5.5(claude-haiku-5-5)를 내놨어요. 요약, compaction, database 조회, 분류처럼 빠르고 반복적인 대량 작업용 소형 모델로, coding 작업에서 Opus 5.5나 Sonnet 5.5의 subagent로 붙이기 좋고, 평균 실행 비용은 Haiku 4.5보다 약 75% 낮다고 해요.

👉 볼 포인트

Haiku 계열 처음으로 effort 설정을 조절할 수 있고, Claude Platform과 Amazon Web Services, Google Cloud, Microsoft Azure에서 바로 쓸 수 있어요.

🔗 <https://www.anthropic.com/claude-haiku-5-5>

━━━━━━━━━━━━

2️⃣ ChatGPT, GPT-6과 함께 그림·차트·버튼으로 답하는 Intelligent UI

OpenAI가 ChatGPT에 Intelligent UI를 넣어, 답변 안에 diagram, chart, form, 누를 수 있는 버튼을 섞어 보여 주고 은퇴 저축 계산기나 bill splitter 같은 도구도 대화 안에서 바로 만들어 줘요. GPT-6 Sol과 Luna를 ChatGPT에 들여오면서 web search가 나아지고 정보를 모으는 동안 부분 답을 더 빨리 보여 준다고 The Verge가 전했어요.

👉 볼 포인트

Plus, Pro, Business, Enterprise는 발표 당일부터 GPT-6 Sol로, Go와 무료 사용자는 목요일부터 더 효율적인 GPT-6 Luna로 쓰게 됐어요.

🔗 <https://www.theverge.com/ai-artificial-intelligence/1007276/openai-chatgpt-intelligent-ui-gpt-6>

━━━━━━━━━━━━

3️⃣ Claude Max·Team에 매달 API credit, Sonnet 5.5 cache read는 절반 가격

Anthropic이 Haiku 5.5와 함께 Claude Sonnet 5.5의 cache read 가격을 100만 token당 $0.20에서 $0.10으로 50% 내렸어요. cache read가 token 사용량의 큰 몫이라 대부분의 agent 작업에서 Sonnet 5.5 비용이 약 20% 줄어든다고 해요.

👉 볼 포인트

이번 주부터 Max 5x는 매달 $100, Max 20x는 $200, Team은 사용자 합산 최대 $500의 Claude Platform API credit을 받고, 어떤 모델에든 쓸 수 있어요.

🔗 <https://www.anthropic.com/claude-haiku-5-5>

━━━━━━━━━━━━

4️⃣ Meta Muse, iPad 전용 앱과 소규모 사업자용 connector 추가

Meta가 수요일(현지) AI agent 앱 Muse를 iPad 전용 앱으로 내놨어요. 모바일 출시 한 달 만이고, 계정을 연결해 이메일, 회의, 청구서를 챙기고 예약, 장보기, 구매까지 맡기는 agent라 여러 서비스를 한곳에서 처리하려는 사람에게 맞아요.

👉 볼 포인트

Asana, Canva, Dropbox, Figma, QuickBooks, GitHub, Klaviyo, Zoom 같은 소규모 사업자용 connector와 Notion, Granola가 추가됐고, Sensor Tower 추정으로 9월 8일 출시 뒤 설치 수가 660만을 넘었어요.

🔗 <https://techcrunch.com/2026/10/07/metas-muse-launches-on-ipad-just-a-month-after-its-mobile-debut/>

5️⃣ Google, AI 생성 여부를 확인하는 SynthID Detector를 누구나

Google이 10월 7일 SynthID Detector를 전 세계 누구나 영어로 쓸 수 있게 열었어요. 이미지, 영상, 오디오 파일이 Google이나 OpenAI, NVIDIA, Kakao 같은 파트너의 AI로 만들어졌는지 확인할 수 있어, 온라인에서 본 미디어를 믿어도 될지 따져 보려는 사람에게 맞아요.

👉 볼 포인트

SynthID는 지금까지 이미지와 영상 1,800억 개 이상, 오디오 24만 년 분량에 watermark를 넣었고, Search, Gemini app, Chrome의 기본 확인 기능은 하루 100만 건 넘는 요청을 처리해요. Apple도 곧 파트너로 합류해요.

🔗 <https://blog.google/innovation-and-ai/models-and-research/google-deepmind/synth-id-ai-content/>

━━━━━━━━━━━━

6️⃣ Google, prompt만으로 게임을 만드는 실험 플랫폼 Playground

Google이 10월 7일 코딩 없이 text prompt로 게임을 만들고 플레이하고 공유하는 실험적 플랫폼 Playground를 공개했어요. 물리, 규칙, 캐릭터, 환경을 말로 고치고 바로 테스트할 수 있어, 게임 엔진을 몰라도 아이디어를 게임으로 만들어 보고 싶은 사람에게 맞아요.

👉 볼 포인트

지금은 미국 18세 이상 사용자에게 playground.google로 열렸고 Google AI 구독에 따라 만들기 권한이 단계별로 열리며, 곧 Unity Spark 연동으로 고품질 3D 게임 제작도 붙는다고 해요.

🔗 <https://blog.google/innovation-and-ai/technology/ai/playground-experimental-gaming-platform/>
