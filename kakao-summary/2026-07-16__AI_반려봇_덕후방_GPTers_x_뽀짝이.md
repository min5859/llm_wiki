# AI 요약

## 인사이트·노하우

- **멀티모델 연동의 비용 함정**: 여러 모델(GPT 5.5 + Fable/Opus 등)을 역할 분리해 연동하면 오히려 토큰 소비가 증가할 수 있음. 단순하게 끝날 작업도 연동 구조가 강제하기 때문. "꼭 필요할 때만 연동해서 작업하도록 개별 명령하는 게 나을 것"
- **멀티모델 연동 설정법**: Claude Code의 AGENTS.md 또는 CLAUDE.md에 서브에이전트별 모델을 기록하면 됨. 예: Advisor → Fable, Worker → GPT 5.6
- **AI 작업 루프 설계**: 작업 완료 후 항상 회고(retrospective)하고 개선하도록 루프를 만들어두면 자동화 품질이 높아짐
- **로컬 LLM 무검열 운용**: 검열 제거 모델은 Hugging Face에서 `uncensored` 키워드로 검색하면 바로 다운로드 가능. 직접 탈옥할 필요 없음
- **WSL 램 주의**: 윈도우에서 WSL 설치 시 WSL 전용 램 사용량이 크게 증가함. 8GB 환경에서는 불안정할 수 있음
- **GPT 5.6 Hermes 사용 시 추론 과다 문제**: 글 10개 생성에 1시간 이상 소요될 정도로 thinking이 과해지는 경우 → GPT 5.6 Luna(sol) 모델로 전환하는 것이 권장됨
- **Claude 토큰/Codex 주간 한도 리셋**: 2026-07-16(목)에 Claude 및 Codex 모두 주간 토큰 한도가 예기치 않게 리셋됨. 리셋 시점을 예측하기 어려우므로 한도를 아끼기보다 소진 후 리셋을 노리는 전략이 유효

## 질문·미해결

- **Hermes용 Mission Control 성숙한 오픈소스 존재 여부**: PatterStage가 후보로 언급됐으나 "성숙하지 않다"는 평. 현재 뚜렷한 대안 미확정
- **OpenClaw + Hermes 동시 사용 시 OAuth 기반 GPT Sol/Luna/Tera 모델 사용 가능 여부**: "가능하다"는 암시적 답변은 있었으나 구체적 설정 방법은 미설명
- **MT5가 레버리지 거래 외 용도로도 활용 가능한지**: MT5 = FX 마진 전용이라는 오해가 있다는 언급만 있었고 구체적 활용 사례는 전개되지 않음
- **Claude 개인 계정에 "your organization is banned" 표시**: 원인 및 해결 방법 미해결
