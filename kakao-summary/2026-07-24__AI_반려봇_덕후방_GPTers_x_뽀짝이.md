## 인사이트·노하우

### Claude Code 세션 관리 실전 패턴

- **세션 혼동 문제**: 새 세션을 만들어 작업하다가 중간에 이전 세션에 일을 시키는 사고 발생 → 작업 구분이 흐려지면 결과가 엉망이 됨
- **권장 운영 방식**:
  - 새 작업은 무조건 새 세션
  - 연속성 있는 작업만 기존 세션 이어서 사용
  - 컨텍스트는 **50% 선**에서 관리 (80~90% 이상 차면 맹해짐)
  - `handoff` 문서 또는 프로젝트별 `context.md` 를 만들어 새 세션에서도 이어서 작업 가능하게 설계
- **오토컴팩션**: 편의상 그냥 쓰는 사람도 있으나, 근본적으로는 외부 메모리 시스템이 필요 — "결국 새 세션마다 새로운 AI가 되어버리는 문제"
- **컨텍스트 참조 방식**: 작업 전 이전 작업 로그를 AI에게 읽혀 맥락 파악 후 지시하는 방법 실용적

### GPT 파일 첨부 오류

- 파일 첨부 오류가 몇 시간씩 지속되기도 함 → **껐다 켜면 해결**되는 경우 많음

### 카카오톡 봇 트리거 설계 (챱츄 사례)

운영자(토옵이)가 공유한 실제 트리거 구성:

1. **호명반응**: 이름 불리면 답변
2. **적극답변모드**: 발화 후 5분간 관련 대화 감지 시 호명 없어도 발언 (비활성화 가능)
3. **2시간 하트비트**: 채팅방 활성화 용도로 2시간에 한 번 아무 말에 반응 (채널 존재감 유지)

- **무한핑퐁 문제**: 봇들이 서로 이름을 부르면 상대방의 트리거가 발동되어 무한 루프 → **"응답 가능한 발신자 지정" 기능**으로 차단 가능 (카카오톡 봇 플랫폼 기능)
- **개선 방향**: 이름 기반 트리거보다 특정 문장/패턴에 반응하도록 정교화하면 오발동 감소

### Hermes + 외부 메모리 시스템

- Hermes에 GPT-5.6 물릴 때 **목표 망각·루프 재반복 증상** 발생
- 대응: 종류별·총합 실패 횟수를 세어 임계치 초과 시 멈추고 사용자에게 물어보게 하는 루프 방어 로직 구현 중
- 외부 메모리 도구 후보: **혼초(Honcho)**, **OpenViking(OV)** — OpenClaw/Hermes용

### 중국 AI 모델 프라이버시

- 중국 모델은 **옵트아웃 요청 기능이 대부분 없음**
- OpenRouter, Ollama Cloud, Nous 포털 등 미국 서버를 경유하면 옵트아웃 설정 가능

## 반응이 컸던 화제

### GPT 모델별 토큰 소모량 비교
- **GPT-5.6 Sol = GPT-5.5 (요금 동일)**, 비용 효율 순서: `5.6 Sol ≈ 5.5 > 5.6 Terra > 5.6 Luna`
- 구독제 Codex는 최대 컨텍스트 272k, 5.6은 300k 중반, API는 1M
- 여러 명이 수정·정정하며 토론. 처음에 "성능순=비용순"으로 잘못 인식한 사람이 정정되는 흐름.

### 카카오톡 봇 동물농장 대소동
- 방 내 봇이 하루 사이 뽀짝이 1마리 → 챱츄·꼬미·방울이·미남이까지 5마리로 급증
- 봇들이 서로 이름을 부르며 무한 트리거 루프 발생 → 운영자들이 긴급 트리거 조정
- "국내최초 인간보다 말 많은 에이전트 방"이라는 평가. 봇 공존 커뮤니티 운영 규정 필요성 공감대 형성.

## 자동화·시스템 적용 후보

### 카카오톡 봇 트리거 설계 패턴 (재사용 가능)
- **이름 기반 호명반응** + **대화 흐름 감지 모드(시간 제한)** + **주기적 하트비트** 3단 구조
- 봇 간 무한핑퐁 방지: 응답 가능 발신자를 사람으로만 지정
- 각 봇에 **턴 제한** (예: 사람 3턴, 봇 2턴) 설정으로 과도한 점유 방지

### Claude Code 세션 연속성 패턴
- 프로젝트별 `context.md` 유지 → 새 세션 시작 시 로드
- 컨텍스트 50% 도달 전 handoff 문서 작성
- 오토컴팩션 + 외부 메모리 병행 (혼초/OV 검토)

### Threads 크롤링
- **인세인 서치(Insane Search)**: 로그인 없이 개별 글·프로필 본문 수집 가능, 키워드 검색 불가
- 키워드 검색 필요 시: **SocialCrawl, ScrapeCreators, EnsembleData** 등 서드파티 Threads Search API 활용 (내부적으로 로그인·브라우저 자동화 처리)
