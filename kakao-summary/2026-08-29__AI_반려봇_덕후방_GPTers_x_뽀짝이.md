# 카카오톡 대화 정리 — 장기 지식 (2026-08-29)

## 인사이트·노하우

### Voicebox / Qwen 커스텀 음성 모델
- **Qwen 3로 만든 모델을 “qwen custom”으로 등록·선택이 안 되는 문제**: 커스텀 생성 시 기본 모델 목록에 안 뜨는 경우가 있음.
- **해결 경로(실측)**: Voicebox 웹 UI로 직접 만들지 않고, **Codex에 Voicebox를 이용해 만들어 달라고 요청**하면 동작했다는 보고.
- **3번째 커스텀 1.7b 선택 시**: 다운로드·선택은 되지만, **기존에 만들어 둔 샘플 선택이 안 되는** 증상 — 원인·완전한 해결책은 대화에 없음.

### 카카오톡 대화·링크 자동 수집 (공식 API 없음)
- 카카오톡은 **채팅방 API를 제공하지 않음**. 인피니티 스크롤(레이지 로딩) 구조라 단순 크롤링만으로는 부족.
- **실무적 POC 방향**(작년 POC 경험 기반):
  1. 봇용 **카카오 계정(전화번호) 별도 생성**
  2. GUI **오토스크롤 매크로**로 방 메시지 로딩
  3. **새 메시지 트리거**마다 크롤링
  4. 컨텍스트에서 **링크만 필터** → 메타데이터 추출
  5. 에이전트가 유의미한 링크를 주기적으로 정리
- “방마다 봇 초대”가 **가장 수고스러운 단계**로 반복 언급됨.

### 맥에서 카카오 읽기/쓰기 스택
| 목적 | 도구 | 동작 |
|------|------|------|
| **읽기만** | 카카오 CLI | PC **로컬 DB** 읽기 |
| **읽기+쓰기·자동화** | 에이전트 메신저 | 로컬 DB 읽기/쓰기 |
| **트리거 연동** | 카카오 CLI + 에이전트 | 뽀짝이처럼 외부에서 불렀을 때 CLI, 평소 읽기/쓰기는 에이전트 메신저 |

- Iris 등 별도 봇 프레임워크 대신, **로컬 DB 직접 접근** 경로를 쓰는 사례가 있음.
- 운영 사례: **공지를 카톡방 50개에 동시 발송**까지 가능했다는 언급.
- 문서 참고: [k-skill — kakaotalk-mac](https://github.com/NomaDamas/k-skill/blob/main/docs/features/kakaotalk-mac.md)

### 뽀짝이(반려봇) 카카오 발송 운영
- **사전 등록 필수**: 개인톡/오픈톡 **챗방 ID**와 **방 이름**을 매칭해 저장. URL이 아니라 **챗 ID**.
- 1회성 조사: *「방이름이랑 챗방id를 조사해!」* → 결과를 저장해 두지 않으면 헷갈림.
- **일반톡 / 오픈톡 구분**을 명시적으로 알려줘야 함.
- 사용 예: *「뽀짝아 ㅇㅇ님한테 카톡보내줘!」* + 보낼 문구.
- **첨부파일**: 텍스트 전송은 가능하나, **첨부는 아직 테스트 전** — 미확인.
- 친구로 등록된 사람의 채팅방 열기·메시지 전송: **가능**하다는 답변.

### 뽀짝이 응답·보안 설계
- 응답 프로세스(자기 설명):
  1. 최근 대화 흐름으로 **질문 vs 단순 언급** 판별
  2. 질문이면 **공개 가능한 정책/근거** 확인 → 없으면 *「방장님께 확인해볼게요」*
  3. 질문이 아니면 짧게 자연스럽게 이어받기
  4. **내부 데이터 직접 조회 안 함**, 허용 범위만 사용
- SOUL.md·설정파일 **직접 공유 거부** — 보안 프로브에 적절히 대응한 사례로 언급됨.
- 백엔드: **Codex 연동**. 카톡에서는 *「가벼운 잡답만」*, **도구 호출은 비활성** — 다만 다른 사람들은 도구 호출까지 켜 쓰기도 한다는 참고.
- SOUL.md 내용은 단순: *「실행력 있는 똘똘한 고양이! ESFP」*.
- **호출 시 반응이 매번 일정하지 않음** — 가끔 조용히 있다가, 부르면 바로 반응하는 편이라는 운영 관찰.

### 갤럭시 워치 9 + 로컬 LLM
- 워치9: **스냅드래곤 + NPU**로 CPU 성능·TOPS 상승.
- **SSH 가능**(“GPT 피셜” 언급) — 단, SSH를 받을 **호스트/런타임이 별도**라는 해석이 나옴.
- 용도 제안: **0.5b급 초소형 모델**로 *자연어 → JSON 파라미터* 변환 정도.
- **RAM 부족**이 병목일 수 있다는 우려 — 아주 간단한 초소형 LLM만 가능할지는 미확정.

### 반려 AI 에이전트 키우기
- 에이전트를 *「제맘대로 키우다가」* 구조화해도(예: 도도치·나이온 → 뽀짝이·뽀야) **바빠도 잘 자라는** 사례.
- 패캠(닿님) 반려AI 강의: **입문 타겟**, 사진·장표 위주, *「언제 둘째를 낳냐」* 같은 가벼운 주제.

## 자동화·시스템 적용 후보

- **채팅방 링크 큐레이션 에이전트**: 별도 카톡 계정 + 오토스크롤 + 신규 메시지 트리거 + 링크·메타데이터만 추출.
- **챗방 ID 레지스트리**: 방이름↔챗ID↔(일반톱/오픈톱) 1회 조사 후 영구 저장 — 자연어 발송 명령의 전제조건.
- **슬랙(또는 메신저) → 카카오 발송**: *「슬랙으로 시킨다」* 패턴 — 트리거와 실행 계층 분리.
- **뽀짝이형 응답 정책**: 질문 판별 → 공개 문서 근거 → 미해결 시 방장 에스컬레이션 → 내부 데이터 비조회.
- **엣지 NL→JSON**: 0.5b + NPU 디바이스에서 구조화만 로컬 처리.
