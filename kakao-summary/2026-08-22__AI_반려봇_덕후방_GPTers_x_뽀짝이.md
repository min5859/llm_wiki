# AI 요약

## 인사이트·노하우

- **Grok 요금·프로모션 현황**
  - 안드로이드 슈퍼 Grok: 3개월 49,000원.
  - iOS(아이폰): 월 44,000원 — 플랫폼별 가격 차이가 있다.
  - 과거 $300 Grok 프로모션(그쫀쿠): Stripe에서 구독 업데이트 전 활성화가 막혀 현재는 불가로 보인다.

- **iOS에서 안드로이드 요금제 우회 시도 → 실패**
  - 원인: iOS 가격(월 44,000원)이 부담되어 BlueStacks로 안드로이드 앱 결제를 시도.
  - 시도: Play 스토어 결제, 카드·카카오페이·네이버페이 등 다수 결제 수단.
  - 결과: BlueStacks에서 Grok 결제 불가. 구매 버튼 누르면 즉시 구매 취소 화면. (과거 Play 스토어 ID로 결제했던 사례는 있었지만 현재는 동작하지 않는 듯.)

- **봇·카톡 계정 운용 팁**
  - 카톡 계정을 봇으로 굴리려면: 적당한 안드로이드 기기 + 번호 하나 추가 + 알뜰요금제 조합이 실용적. 안드로이드 전용 앱·서비스를 병행할 때 유리.

- **Grok 4.6 + OpenClaw 조합**
  - Grok 4.6을 OpenClaw에 연결하면 일 처리가 깔끔하고, "헛소리"(환각·잡담)가 적다는 실사용 후기.

- **Ox alpha 무료 사용 경로**
  - OpenCode 결제 없이 `zen free`로 Ox alpha 사용 가능.
  - OpenRouter에서도 무료로 사용 가능.
  - Ox alpha free는 커뮤니티에서 GLM 계열로 추정되는 이야기가 많고, "쌧바닥 길고 생각하는 흐름"이 Qwen과 비슷하다는 관찰.

- **Banked reset(초기화권) 동작**
  - Banked reset = 주간 토큰 사용량을 100%로 되돌리는 **초기화권**. 원할 때 아무 때나 사용 가능(자동 리셋과 별개).
  - UI에서 해당 항목을 누르면 주간 사용량이 초기화된다.
  - Tibo(티보형) 트윗에서 리셋권 배포가 **예고**되어 있었고, 실제로 티켓이 들어온 사례. 트윗 본문에 "And we will have some other good news later too!"가 있어 **전체 리셋** 또는 **API 가격 인하** 등 추가 혜택을 기대하는 분위기.
  - 과거 패턴: 토큰 소모가 많다는 제보 후 업데이트와 함께 리셋을 주는 경우가 종종 있다. 이번에도 비슷한 흐름으로 보는 사람들이 많다.
  - 리셋권을 받았어도 당장 쓰지 않고 "존버"하는 전략도 논의됐다(추가 전체 리셋 기대).

- **Aside 사용 맥락**
  - 크로미움 기반 브라우저 + 에이전트. Claude를 바로 연결할 수 있어 편하다.
  - 스택 예: 클코(Claude Code) + Hermes → Aside(Opus 5) + Hermes(5.6 sol max)로 전환·병행.
  - 5.6 sol은 헛바퀴(루프) 한 번에 토큰 소모가 크다는 운영상 주의점.

- **Hermes 모바일 사용**
  - 텔레그램을 주로, 슬랙은 가끔, 디스코드도 연결 가능.
  - Desktop app 품질 괜찮고 **봇 모드**가 추가됐지만, 모바일 앱에서는 아직 미지원으로 보인다.
  - 봇 모드는 Grok Bot 대항으로 테스트 단계; 유저 반응이 좋으면 본격 투입 예정이라는 기억.

- **Grok Bot 플랫폼 제약**
  - Grok Bot은 안드로이드에서 사용 불가 — PC 위주. 모바일 채팅앱 형태인데 안드로이드 버전이 없다는 불만.

- **무료 체험 로테이션 운영**
  - Claude 무료 체험으로 Claude Pro 3개 + Codex Plus 1개 + Grok을 돌려 쓰며 세션을 나눠 쓰는 방식. 번거롭지만 세션 여유가 있다.

## 질문·미해결

- **Grok 4.6 품질** — 아직 못 써본 사람이 많아 실사용 후기가 부족. OpenClaw 연결 시 긍정적 1건만 확인.
- **Ox alpha = GLM인가? 차기 모델은?** — 커뮤니티 추정만 있고 확정 정보 없음.
- **Open Minis와 Aside의 향후** — "어떻게 될진 모르는데" 일단 Claude 직연결 편의만 확인.
- **Tibo "later good news"의 정체** — 전체 리셋 vs API 가격 인하 등 추측만 있고 미확정.
- **리셋권 UI 사용 위치** — "아래에 사용한도 초기화"가 맞는지 확인 요청이 있었고, 대화 끝에서 답이 완결되지 않음.
- **Grok Bot 안드로이드** — 출시 계획·일정 불명. Hermes 봇 모드가 대안 후보로만 언급.
- **Banked reset 자주 주는지** — 처음 겪는 사람도 있어 빈도·규칙은 불명. Tibo "광기" 발휘 시 주간 단위 리셋도 가능하다는 농담성 기대만 있음.
