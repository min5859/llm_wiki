# 카카오톡 대화 지식 정리 (2026-08-22 · AI 반려봇 덕후방)

## 인사이트·노하우

### Grok 구독·결제
- **플랫폼별 가격 차이**: 안드로이드 앱 기준 슈퍼그록 3개월 49,000원, 아이폰은 월 44,000원으로 체감상 차이가 있음.
- **$300 그쫀쿠(스트라이프 구독) 우회 불가**: 구독 업데이트 전 활성화가 막혀 있어 더 이상 안 되는 상태로 공유됨.
- **블루스택으로 Play 스토어 결제 실패**: 블루스택에서 그록 결제 시 구매가 바로 취소됨. 카드·카카오페이·네이버페이 등 여러 수단을 시도해도 동일. (과거 Play 스토어 ID로 결제됐다는 정보는 실제로는 통하지 않았음)
- **대안**: 카톡 봇·안드로이드 전용 앱을 쓰려면 **저가 안드로이드 기기 + 알뜰요금제 번호**를 따로 두고 실기기에서 쓰는 편이 낫다는 조언.

### Grok 4.6 + OpenClaw
- 그록 4.6을 **OpenClaw에 연결**해 쓰면 일 처리가 깔끔하고, **헛소리(환각)가 적다**는 실사용 후기.

### Ox / OpenCode 관련
- **OpenCode Go**에서 **Ox alpha free** 체험 가능. 유료(약 $5) 전에 zen free·OpenRouter 무료 경로로 먼저 써볼 수 있음.
- Ox alpha free는 커뮤니티에서 **GLM 기반** 얘기가 많고, “쌧바닥 길고 생각하는 흐름”이 **Qwen** 느낌과 비슷하다는 관찰.
- Ox alpha는 대화 당시 **어제 릴리스**된 버전으로 언급됨.

### Banked reset(초기화권)
- **Banked reset = 개인이 원할 때 쓰는 주간 사용량 초기화권(초기화 1장)**.
- UI에서 해당 항목을 누르면 **주간 토큰 사용량이 100%로 복구**됨.
- **리셋권 배포**와 **전체 리셋(서버 측 일괄 리셋)** 은 별개일 수 있음.
  - Tibo(Tibo Sottiaux) 트윗에서 리셋권은 예고됐고, 실제로 들어온 것으로 보임.
  - 같은 트윗의 *"And we will have some other good news later too!"* 는 **전체 리셋** 또는 **API 가격 인하** 등으로 기대 중이었으나, 당일 기준 **아직 미확정**.
- **리셋 타이밍 패턴**: “토큰 소모가 많다”는 업데이트·언급 이후 **리셋이 따라오는 경우가 꽤 있다**는 경험 공유. 그래서 리셋권을 바로 쓰지 않고 **존버**하는 전략도 나옴.
- 서드파티 구독권을 쓰는 경우 UI 통화가 **유로**로 보일 수 있음.

### 멀티 도구 운용
- **Claude Code + Hermes** 조합에서 **Aside(Opus 5) + Hermes(5.6 sol max)** 로 전환해 실험 중.
- Aside는 Claude에 바로 연결돼 **입문·기존 봇 운영자 모두 편하다**는 평.
- **GPT-5.6 sol** 은 헛바퀴 한 번 돌 때 **토큰 소모가 크다**는 체감.
- 무료 체험을 여러 개 돌려 쓰는 사례: **Claude Pro 3개 + Codex Plus 1개 + Grok** — 번거롭지만 세션을 남길 수 있다는 방식.

### Hermes 접속 채널
- 모바일·봇 연동은 주로 **텔레그램**, 가끔 **슬랙**, **디스코드**도 연결 가능.
- Hermes **데스크톱 앱**은 괜찮고 **봇 모드**가 생겼으나, 모바일 앱은 없거나 제한적.
- 봇 모드는 **Grok Bot 대항** 성격의 **테스트 단계** 기능으로, 반응이 좋으면 본격 투입 예정이라는 커뮤니티 기억.
