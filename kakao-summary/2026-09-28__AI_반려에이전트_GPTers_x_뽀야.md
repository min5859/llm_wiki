## 인사이트·노하우

- **메타 Muse(뮤즈) 한국 가입 우회 방법 (VPN 경유)**: 한국은 아직 대기 상태, 미국에서만 가입 가능 → Windscribe 무료 VPN으로 미국 서부(LA) 지역 연결 후 muse.ai 가입. VPN은 가입 시에만 필요하고 가입 후엔 꺼도 계속 사용 가능. (STEP 1~5 상세 가이드 공유됨: VPN 켜기 → 뮤즈 가입 → 초대코드 입력(48시간 내) → 커넥터 연결(지메일/드라이브/노션) → 활용 예시)
- **대안 우회 방법 (가상 PC 경유)**: Gemini Spark에서 미국 IP의 가상 PC를 열어 muse.ai 접속 → 가입 후 비자/마스터카드로 나이인증 완료 → 이후 국내 일반 환경에서도 접속 가능. "국내카드로도 나이인증 가능하지만, 마스터카드 기능이 있는 카드여야 함"이 다수 참가자(P39, P18)에 의해 확인됨.
- **브라우저 가상 환경(Browserling) 경유 가입법**: browserling.com에서 Mac Tahoe 선택 후 실행 → 무료 3분 사용 시간 내에 신용카드와 메일함을 미리 열어두고 빠르게 가입 진행. 윈도우10 환경에서는 잘 안 됨(Mac 환경 권장).
- **미국 Apple 계정 생성 + 아이폰 Muse 앱 설치 절차** (단계별):
  1. 준비물: 미사용 신규 이메일, 인증 가능한 휴대폰 번호(+82), 유효한 미국 청구 주소/연락처
  2. Mac 크롬에서 account.apple.com 접속 → 국가/지역을 United States로 설정해 신규 Apple 계정 생성 (가입 오류 시 Windscribe를 끄고 재시도)
  3. 아이폰에서는 iCloud 계정은 유지한 채 **App Store 계정만** 전환 (설정 → 내 이름 → 미디어 및 구입 항목에서 로그아웃 후 미국 계정 재로그인). 결제 방법에 "None(없음)"이 표시되면 선택해 무료 등록
  4. Muse 앱(개발사: Meta Platforms, Inc. 확인) 설치 후 기존 Muse 계정으로 로그인, 필요 시 Windscribe 미국 서버 연결
  5. 작업 후 다시 설정에서 로그아웃 → 한국 Apple 계정으로 복귀 (Muse 앱은 유지됨)
  - 주의: "설정 맨 아래의 '로그아웃'은 누르지 말 것" (iCloud 계정과 App Store 계정 로그아웃 메뉴 구분 필요)
  - 확인 사항: 스토어 국가는 화면 언어가 아니라 계정의 '국가/지역'으로 판단해야 하며, VPN을 통한 이용 시 초대·사용량 승계 여부는 실제 로그인 후 확인 필요.
- **CLI 기반 AI 에이전트 연결 개념**: Gemini Pro 구독 시 "오르카"(불명, 추정상 멀티 에이전트/오케스트레이션 도구)에 연결 가능하지만 "거의 안 쓰인다"는 평가. Gemini는 브라우저 로그인 방식으로는 연결이 안 되고 CLI(터미널 환경)로 연결해야 하며, 이 경우 "안티그래비티"로 잡힐 수 있음. 안티그래비티는 구글이 내놓은 개발도구로 VSCode와 유사한 형태이며 VSCode에 Gemini 에이전트가 탑재된 것으로 이해하면 된다는 설명.
- **에이전트 역할 분담 사례**: 클로드에게는 제미나이로 원고 작업을 맡기고, 코덱스에게는 코딩 작업을 맡기는 식으로 여러 AI를 역할별로 연결해서 사용 중이라는 공유(P43).

## 추천·자료

- **Muse (메타의 개인 AI 에이전트)**: PC를 켜지 않아도 클라우드에서 작업을 수행하는 에이전트. 회의록 양식→워드 문서 생성, 행사 초대장 웹페이지 생성, 예산관리 시트(엑셀, 자동 합계) 생성, 포스터 이미지 생성, 메일함 뉴스레터 필터링(+매주 월요일 9시 자동 알림 예약) 등 실사용 예시 공유됨. 폰 앱, 왓츠앱에서도 이어서 대화 가능.
- **Windscribe**: 무료 VPN, 이메일 인증 시 매달 10GB 무료 제공. 미국 IP 우회가 필요한 가입 작업에 활용.
- **Browserling**: 가상 브라우저를 VNC처럼 열어주는 서비스. 무료 체험(3분)으로 Mac Tahoe 환경 실행 가능, 지역 제한 서비스 가입 우회용으로 활용.
- **Gemini Spark**: 미국 IP의 가상 PC를 열어주는 서비스로, 지역 제한 서비스(Muse 등) 가입 시 VPN 대안으로 활용 가능.
