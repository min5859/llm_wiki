# AI 요약

## 추천·자료

- **MongoDB Atlas Agent Engine** (public preview, 9/29 공개): 실행·memory·retrieval·governance를 한 layer로 묶어 production agent 운영 기반 제공. Atlas 사용 팀이면 데이터와 agent 실행을 같은 환경에서 관리 가능한지 검토할 만함.
- **Honeycomb AI Ecosystem** (early access, 9/29 공개): agent fleet의 failure rate·latency·cost를 개별 conversation 단위까지 추적하는 observability 도구. agent 수가 늘 때 성능 저하/비용 증가 원인을 실행 대화까지 추적하는 용도.
- **Airia의 Claude Enterprise용 inference hooks** (GA 전환): prompt나 연결된 tool 결과를 Claude가 처리하기 전에 조직 정책 위반 여부를 실시간 차단. MCP server·skill·plugin 경로까지 정책 적용 가능.
- **OpenAI Dots**: always-on AI agent로, 질문 응답을 넘어 실제 업무를 지속적으로 맡기는 제품 (9/29 DevDay 공개).
- **Codex Cloud (ChatGPT Enterprise)**: desktop·web·mobile 간 공유되는 cloud environment에서 Codex 작업을 이어갈 수 있음. 각 task는 격리된 workspace에서 진행, 기기를 꺼도 계속 작동.
