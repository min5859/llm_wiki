# AI 요약

## 인사이트·노하우

### AI 모델 동향 (2026-08-13 기준)
- **Grok 4.6** (xAI, 8/12 공개): 장기 실행 에이전트·코딩·지식 작업 특화. Artificial Analysis Index 61점, GPT-5.6 Sol과 동급 언급. 가격은 Grok 4.5와 동일(입력 $2 / 출력 $6 per 1M tokens). Cursor·Grok Build에서 즉시 사용 가능, 첫 주 2배 사용량 제공.
- **DeepSeek V4-Pro-0813** (GA): 1.6T total / 49B active, 1M 컨텍스트. 에이전트·코딩 성능 향상. 가격 약 $0.435 / $0.87 per 1M tokens. API·OpenRouter에서 사용 가능.
- 채팅 반응: 딥시크 프로는 "싼데 결과물도 나쁘지 않고", 그록 4.6은 "페이블급" 찬양이 있다는 언급. 다만 아직 충분히 써본 사람은 적어 체감 평가는 초기 단계.
- AI 경쟁 축이 **장기 실행 에이전트 성능**과 **가성비 플래그십** 쪽으로 이동 중이라는 정리.

### Cursor / Codex / Claude 사용 패턴
- **Cursor 커맨드코드 $1 플랜**을 "진짜 대혜자"로 평가. 여러 계정 구독($1 × 5, $1 × 10 ≈ $100 어치) 전략도 언급됨.
- Cursor 사용 방식: Cursor 앱 안에서 쓰는 경우와, **프록시를 돌려 다른 하네스에 얹어 쓰는** 경우 둘 다 존재.
- Claude 대비 Codex에 대한 불만·이탈 의사 다수: "클로드는 진짜 해준 적이 한손에 꼽을 정도", "이미 클로드 결제를 끊었", "여차하면 코덱스 간다" 등. 반면 Codex는 "코덱스 초기화 됩니다 .. 코갓" 수준의 긍정 반응.
- **Herdr + Mushi + Codex Remote** 조합으로 자동화를 돌리면 "꿀"이라는 평가.

### 모바일·원격 개발 스택
- 추천 조합 정리:
  1. **Codex APP + Remote** → GPT 구독 시
  2. **Moshi + Herdr** → 클로드 등 기타 구독 시
- **Moshi**(모바일 SSH 앱) 체감 장점: Termius 대비 터미널 밀림·글자 밀림 없음. 간단 사용은 무료로 가능(mosh 기능은 유료). Herdr을 불러와 원격 작업 가능.
- 단점·주의:
  - **Codex Remote**: 배터리 소모 큼.
  - **Windows Herdr**: 느리고 리소스 많이 먹음 → "이 작업만 끝나면 안 써야지" 수준의 불만.
  - 일부 사용자는 Tailscale과 함께 쓰는 환경(폰에서 AdGuard + Tailscale 조합은 귀찮다는 의견도 있음).
- 대안·이견:
  - Moshi → **Colie**로 갈아탄 사례(매번 herdr 입력이 번거로웠다는 이유).
  - SSH는 **Terminus**, Moshi는 mosh 빼고 장점을 못 느껴 다시 지운 사례도 있음.

### Twitch AI 학습 opt-out
- Twitch 스트리머 콘텐츠가 Amazon AI 학습에 **기본 포함(opt-out 방식)**.
- 설정 경로: `Settings → Security and Privacy → Training for Generative AI`

### Blacksmith (CI/테스트) 시사점
- AI가 코드를 더 많이 만들수록 **테스트·검증·관측성·보안** 인프라 가치도 함께 커진다는 관점.
