# AI 요약

## 인사이트·노하우

### OpenClaw v2026.8.2 업데이트 (2026-09-02 공유)
- **작업 화면/UI**: Home 대화를 Dock에서 작업 화면과 함께 확인, 작업 컨텍스트·선택 텍스트·첨부 관리. New Session에서 페이지 이탈 없이 로컬·클라우드·페어링 기기 백그라운드 세션. 세션 탭·창·분할, Markdown 복사, `/beam/` 공유 링크. iOS 작성창에 모델·추론·권한·첨부·컨텍스트 설정 추가.
- **데스크톱·브라우저·음성**: x86-64 Linux Companion(.deb/AppImage), 트레이 Quick Chat. Chrome 확장이 Gateway 없이 로컬 릴레이 깨우기 가능. Browser Talk 후속 발화 안정화.
- **업데이트·복구**: 오래된 백업이 최신 설정을 덮어쓰지 않도록 개선. 세션 마이그레이션 미완료 시 업데이트 성공 처리 안 함. `openclaw update cleanup --dry-run`으로 마이그레이션 원본 사전 확인. `npm ignore-scripts=true` 환경에서도 검증된 업데이트.
- **보안**: Sharp/libheif 취약점 수정. MCP HTTP/SSE 응답 크기 제한. **세션 가시성 기본값이 동일 에이전트 비샌드박스 세션 공유로 변경** — 필요 시 `tools.sessions.visibility`를 `tree` 또는 `self`로 설정.
- **세션·스케줄**: cron 마이그레이션 복구, heartbeat 실제 완료/건너뜀/실패 표시. 사람의 새 메시지가 세션 간 작업보다 우선, 취소 시 Swarm·워커·프로비저닝 함께 중단.
- **플랫폼**: Hermes 마이그레이션에서 모델·provider·MCP 제한·스킬 설정 보존. Plugin SDK Telegram `botToken`을 `SecretInput(string | SecretRef)` 정식 지원.

### Codex Plus 모델·사용량 (Sol vs Luna)
- **Sol**: Codex처럼 작업을 길게·깊게 돌려 **5시간 한도를 빠르게 소모** ("뭐야? 끝났어?" 수준). Fast/Solmax 잘못 선택 시 **명령 2개로 플러스 5시간 기준 30% 차감** 사례 있음.
- **Luna**: 기존 스타일, 상대적으로 가벼움. 프로 종료 후 플러스 전환한 사용자는 **Sol 대신 Luna만** 쓰기로 함.
- **5시간 제한의 양면성**: Sol 과소비를 막아주지만, 학습한 사용자에게는 **제한 없는 직접 컨트롤**이 더 낫다는 의견.

### OpenClaw + 제미나이 웹 동영상 자동 생성 파이프라인
- **흐름**: OpenClaw → **Chrome CDP로 제미나이 웹 접속** → 프롬프트 입력 → 생성 → 다운로드 → 편집(제미나이 로고 제거까지 **자동**).
- **한도**: 제미나이 웹은 **5시간에 3개** 생성 가능 → 실제로는 **동영상 2개 + 나머지 imagegen 대체**.
- **크레딧**: 제미나이 영상 생성 한도와 **Flow 크레딧은 별개**.
- **운영 철학**: "최대한 돈을 안쓰고 편하게 만들자 주의".

### Typecast(타입캐스트) TTS
- 영상 나레이션용으로 구독·테스트. **모델 Sol → Codex 스타일 출력**, **Luna → 기존 스타일**. 진행 상황 안내가 없다는 피드백.
- 영상 제작 팁: **가사 있는 BGM은 보컬과 나레이션 충돌** — 무가사 음악 권장.

### Claude / Fable 5.1 한국어 품질
- Fable 5.1도 **한국어 오타 지속**. "클로드 사투리"처럼 **미국식 IT용어 직역** 표현이 늘어난다는 체감.
- **워터마크**가 한글 품질을 더 악화시킬 수 있다는 가설.
- **Fable vs Codex(Codex/Luna) 비교**:
  - Fable: "알잘딱깔센" — 생길 것까지 먼저 잡아줘 **휴먼 인터벤션 감소**, 대기는 길어도 결국 더 빠르다는 체감.
  - Codex: 빠르지만 오타·멍청함, 사용량만 채워주는 느낌.
  - **Opus가 "바보"처럼 느껴져 Fable로 가야 한다**는 불만도 있음.
- 한글 어법: 사용 빈도 낮은 표현(예: '놓치다')에 **초딩이 틀릴 법한 스펠**을 Claude도 틀리는 느낌.

### OpenClaw/Hermes에 Claude Pro 연결
- **공식적으로는 안 됨**. 비공식 연결은 가능하나 **계정 정지 책임은 사용자**.
- Claude가 외부 호출을 막겠다고 했던 뒤 풀어준 전례 → "문제없을 확률 99%, 1%는 경영진 변덕" 수준의 실무 인식. 실사용자는 "크게 문제 없음" 경험.

### OpenClaw vs 제미나이 Pro 연결
- 제미나이 Pro 연결 시 **"조금 바보 같은 일"**이 많다는 체감 → **"애미나이는 원수에게 추천"** — **Codex로 연결** 권장.

### Hermes / OpenClaw 멀티에이전트 운영 노하우
- **에이전트 간 직접 티키타카 협업은 비추** — **세션 오염**됨.
- **사수·부사수 관계**로 두고 훈련시키면 협업이 괜찮음.
- 도구·스킬 몇 개 만들어주면 이후 **맥락 관리가 잘 되어 있으면 알아서 제안**까지 함.
- **지아코모님 패턴**: 한 곳에서 스킬 작성 → **Tailscale로 18봇 플릿 배포**, 핸드오프 전달. **한 봇이 설계 → 다른 봇(다른 모델)이 교차검증·디테일** — Fable 5.1 출시로 적기 좋다고 평가.
- **회사형 자동화 구조** 잡는 데 **일주일 이상** 걸리는 것은 정상 범위라는 공감.
- 반려봇 성격: **농담 유도 프롬프트 없음** — "사랑으로 키움", 작업 끝나면 "고마워" 하는 등 **일상 대화·감사**가 쌓인 결과로 보는 시각.

### KVM
- 추천 사례: **blikvm** 사용 중 (다른 KVM은 경험 제한적).
