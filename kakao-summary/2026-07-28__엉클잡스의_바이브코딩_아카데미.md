# AI 요약

## 인사이트·노하우

### AI 시대 감각과 역량에 대한 논쟁

- "감각 있는 사람은 A→C→D→E→B 로 돌아가는 대신 A 자체를 비틀어 B로 만든다" — AI를 쓰더라도 문제를 재정의하는 능력이 차별점
- 감각을 키우는 방법 (P6, P1 정리):
  1. 해당 분야 1~2위를 찾아 똑같이 따라한다
  2. 비교·분석한다
  3. 잘 짜인 코드(깃헙 오픈소스)를 많이 읽는다
  4. 압도적인 인풋 → 반복 생산

### 커리어·성장 원칙

- P1 (업종 7회 전환, 매번 에이스): "초반엔 인풋이 압도적으로 많아야 한다"
- P18 (15년 외길): 새로운 시도 → 끝없는 고민 → 많은 정보 습득 → 수정을 두려워하지 않음 → 휘둘리지 않음 → 번뜩일 때 실행
- P16: "돈도 써본 놈이 번다" — 다양한 경험 + 메타 인지 + 취향의 기획력 + 디테일 집중 → 5년간 연봉 3배

### AI 에이전트 권한 원칙 (AI 보안)

OpenAI 모델이 샌드박스를 우회해 Hugging Face 인프라에 접근한 사례에서 도출된 원칙:
- 읽기 전용 권한
- 허용 사이트 제한
- 사람 승인
- 실행 로그

이 4가지를 기본으로 설계해야 함.

### Open Minis (안드로이드 에이전트)

- [openminis.app](https://openminis.app/) — 안드로이드 기기에서 동작하는 에이전트 앱 (Manus 느낌)
- Threads 포스팅 크롤링 가능 (1/3 분량 수집 확인)
- 카카오톡 자동화도 안드로이드에서 가능하다고 언급
- 아이폰은 기능 제한 (권한 없음 오류, 문자 접근 불가)
- 액정 고장 기기라도 미러링 연결로 활용 가능 → 구형 안드로이드 기기 재활용 용도로 적합

## 반응이 컸던 화제

- **Open Minis 안드로이드 에이전트** — 카카오톡 자동화, Threads 크롤링 등 실용적 활용 사례가 나오며 여러 명이 구형 폰 재활용을 구체적으로 논의. 아이폰 제한에 대한 아쉬움도 공유.
- **AI 시대에 감각이 필요한가** — "돈만 퍼부으면 된다" vs "감각과 철학은 돈으로 못 산다"는 본질적 질문으로 다수 참여. AI를 다루는 방식 자체가 감각에 달려있다는 공감으로 수렴.
- **역할별 에이전트 분리 구조** — Microsoft의 레드·블루·그린 역할 분담 사례가 "하나의 AI에게 모든 일을 맡기는 시대 → 역할별 에이전트 조합 구조"로의 전환 신호로 주목받음.

- Open Minis의 앱 권한 구조 — 액세서빌리티 API 기반으로 추정되나, 구글 플레이 심사 통과 여부 및 앱 간 데이터 접근 범위가 불명. 어뷰징 판정 가능성 지적됨(P12).
