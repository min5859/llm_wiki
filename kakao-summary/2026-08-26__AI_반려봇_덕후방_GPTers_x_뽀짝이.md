# AI 요약

## 인사이트·노하우

- **로컬 LLM + 하네스가 클라우드 단독 호출보다 나을 수 있음 (의료 데이터 맥락)**
  - 원인/맥락: 의료기록은 상용 클라우드(GPT)에 넣을 수 없어 로컬로 처리 시도.
  - 시도: Qwen 3.8 27B에 "너는 모자라니까 하네스를 만들어야 한다"는 식의 주입·자체 평가로 하네스를 갖춤. 반면 GPT는 하네스 없이 그냥 시킴.
  - 결과: 공정 비교는 아니지만, 하네스 없는 GPT보다 결과가 잘 나오기 시작했다고 함.
  - 기기: M4 Max, RAM 128GB. 27B를 빡세게 돌리면 고온 경고가 하루 1회 이상, 쿨러 추가 주문함.

- **Apple Silicon 로컬 LLM 성능·체급 감각**
  - LM Studio 기준 Mac Studio 첫 토큰 생성: M5 Max가 M1 Max 대비 약 **10.7배**, M4 Max 대비 약 **2.8배** (대화 중 인용 수치).
  - M6 Mac mini: 파라미터 큰 모델을 새로 돌릴 체급은 아니고, **동일 모델 기준 응답 속도가 약 40% 빨라짐**.
  - 교육스토어 가격 참고(2026-08-26): M6 깡통(16GB/256GB) **1,329,000원**, M5 Pro 깡통(24GB/512GB) **2,809,000원**부터.

- **Hermes 세팅 오류**
  - 증상: 세팅 오류가 끊임없이 발생, 고쳐도 반복.
  - 해결/판단: 커뮤니티 응답으로 **"삐빅 정상입니다"** — 지속적 오류가 흔한 편으로 보임.

- **Codex(티보 코덱스) 사용량 리셋**
  - 2026-08-26 전후 여러 명이 사용량이 리셋됐다고 확인. 얼마 안 썼는데도 리셋되는 사례도 있음.
  - 리셋 공지를 놓치는 패턴도 관측됨: "아, 말하는거 깜빡했다" (말 안 하고 리셋).

- **Codex 성능/동작 이슈 (2026-08-26 전후)**
  - 증상 1: **147 버전부터** MacBook에서 업데이트 후 제대로 동작 안 함·멈춤.
  - 증상 2: 진행이 버벅이고 느림이 **2일째** 지속.
  - 여러 명이 동시에 겪는 것으로 보아 개별 환경만의 문제는 아닐 가능성.

- **AI 회의록·녹취 서비스 실사용 노하우**
  - Proud Note(별도 디바이스, 25~28만원대): 기기를 샀지만 실제로는 **휴대폰 녹음 + Proud 앱**만 쓰는 사례가 있음 — 하드웨어 메리트 재검토 필요.
  - 무료 한도(예: 300분)를 여러 서비스에 나눠 쓰는 전략이 언급됨.

- **Upstage Solar Pro 4 (ox alpha 등)**
  - 코딩은 시도 안 했으나, 지시 수행·맥락 유지가 기대 이상.
  - ox alpha 등에서 인기 모델만 쓰는 사용자가 적어 **무료인데도 빠르고 쾌적**하다는 평.
