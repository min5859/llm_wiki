# AI 요약

## 인사이트·노하우

- **Codex 리셋권 자동 실행 스킬**: 만료 60초 전 자동 리셋 + 만료 시간 조회 기능. Hermes 에 설치 가능. 리셋권 조회 오류 시 Codex 버전 미업데이트가 원인이었음 (최신 버전 업데이트로 해결). 현재 macOS 전용, 윈도우 지원 예정.

- **Opus 5 사용량**: Fable 5의 약 25% 저렴(테스트 기준), Opus 4.8 대비로는 더 빠르게 소진. Superpowers 하네스와 궁합이 맞지 않을 수 있어 하네스를 제거하거나 경량화하는 것이 권장됨. "점점 하네스를 얇게 가져가는 추세"

- **하네스·스킬 vs MCP·API 신선도**: 하네스와 스킬은 시간이 지나면 유지보수가 필요하지만, MCP·API는 배포자 측에서 서버를 업데이트하므로 신선도 유지가 상대적으로 용이.

- **국내 ERP 생태계 구조**:
  - 더존이 특허 진입장벽을 높게 유지해 경쟁사의 API·외부연동 개발이 어려운 구조
  - 이카운트: 인원 무제한 월 4만원(회사 추가 시 1만원), API 공개 중(매입·매출 전표 입력 위주). 회계 자료 추출은 웹에서만 가능
  - 영림원 ERP: API 업체별 별도 개발 비용 청구, AS 평가 낮음
  - 세무 기장 업무 자동화는 이카운트→원장 추출→더존/세무사랑 업로드 컨버전 지점이 실질적 자동화 포인트

- **AI 에이전트 기반 세무 자동화 방향 수정**: 더존 headless API를 자체 개발하려다 이카운트 + 이카운트 API 활용으로 방향 전환. 단, 세무대리인 실무는 더존/세무사랑이 표준이므로 이카운트 원장→세무 소프트웨어 업로드 컨버전 자동화가 핵심.
