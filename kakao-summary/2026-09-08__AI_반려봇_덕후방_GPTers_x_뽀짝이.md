# 🐱 AI 반려봇 덕후방 | GPTers x 뽀짝이 — 2026-09-08 지식 정리

## 인사이트·노하우

### Codex / ChatGPT 사용량 주간 초기화(리셋)
- **대략적인 시각**: 한국시간 **오전 10~11시** 전후. 미국 서부시간 기준으로 계산하면 이 시간대에 맞춰짐.
- **개인차·딜레이**: 정확히 동시에 안 되는 경우가 많음. ("시간차인가봐요" / "잘생긴 사람 순입니다!")
- **티보(Tibo) X(트위터) 발언과의 관계**: 티보가 X에서 입을 열면 곧 리셋 분위기가 조성되는 편. 리셋 직전에 **초기화권(한도)을 아껴 두는 것**이 유리하다는 공감대가 있음. ("티보가 x에서 입 털땐 초기화권 자제하는게 좋긴하네요")
- **리셋 직후 운영**: 리셋 확인되면 **패스트(Fast) 모드 멈추기** — 남은 한도를 불필요하게 태우지 않기 위함. ("100이다! 다들 패스트 멈춰 ~~")
- **Plus 플랜 리셋 불일치**: 같은 날 주간 초기화 때 **Plus는 늦게 또는 안 되는 사례**가 다수 보고됨. X에도 "plus 왜 리셋 안해주냐" 글이 올라온 상태. 이후 일부는 Plus도 초기화됨.
- **5시간 한도**: 주간 리셋와 별도로 **5시간 롤링 한도**도 돌아옴. ("다섯시간 한도가 돌아왔네요")

### 아스트라(Astra) 토큰·한도 소모
- **ChatGPT Plus + 웹 Work 모드 + astra / 매우 높음** 실측: **42분 작업 → 주간 사용량 63% 소모** (한 방에 2/3 가량).
- **20x 요금제**도 아스트라 사용 시 빠르게 소진됨. ("20x도 녹아내려요")
- 실무적 시사: 아스트라를 기본으로 쓸지, 고급 작업에만 쓸지는 **남은 토큰·한도 예산**에 따라 달라짐.

### Hermes + 텔레그램 + 멀티 에이전트 모델 전략
- **정답 없는 트레이드오프**로 정리됨:
  - 한도가 넉넉하면 → 아스트라를 메인으로 써도 됨.
  - 아껴야 하면 → 사용 시점을 조절하거나, 메인 아래 **하위(저렴한) 모델 서브에이전트**를 붙이는 방식.
- 한 참가자(P22) 방식: **페르소나·역할별 서브에이전트를 직접 쪼개지 않음**. 덩치 큰 작업은 클로드·GPT·코덱스가 **서브에이전트를 알아서 만들고 진행**하므로, 사람이 모델 계층을 micromanage 하지 않음. 코덱스도 필요 시 서브에이전트를 자동 생성.

### 멀티 도구·크론 정리 (헤르메스·오픈클로·클로드코드·GPT 혼용)
- **원인**: 여러 에이전트·크론·프로그램이 섞이면 "어떤 크론이 어디에 걸려 있고, 어디서 만들었는지" 파악이 어려움.
- **정리법 제안**:
  - 모든 작업 결과·맥락을 **GitHub에 올리는 규칙** — 어디서 만들었든 추적 가능.
  - 크론은 **대시보드에서 한눈에 보는 방식**이 편하다는 의견 (구체 도구명은 불명).

### 코덱스 ↔ 클로드코드 설정 혼입 실패 사례
- **원인**: 설정 **「가져오기」를 생각 없이 실행** → 클로드코드용 설정이 코덱스로 딸려옴 (경로 등 우회 설정 포함).
- **결과**: 한동안 **코덱스 성능 저하**.
- **해결**: **한땀한땀 수동으로 되돌림**.

### 텔레그램 장애 시 대응 (2026-09-08 당일 반복)
- **현상**: 텔레그램 GUI·봇이 여러 차례 불안정. 슬랙은 정상 동작하는 경우도 있음.
- **대응 패턴**:
  - 슬랙 등 **대체 채널** 우선 사용.
  - 급하면 **터미널(CLI)** 로 직접 조작.
  - 텔레그램 봇 6개가 묶여 있던 경우: 장애 시 **비상 대화 웹페이지**를 아스트라가 즉석 제작. **Tailscale** 연결 시 어디서든 접속 가능.
  - 복구 후 **대기 중이던 명령 큐가 쌓였으면 삭제**해도 됨.
- **아이러니**: 웹페이지 완성 직후 텔레그램 서버가 살아남.

### 푸시 알림·웹앱 동작
- **홈화면 웹앱(PWA)**: 브라우저를 **켜 둔 상태가 아니면 알림이 안 올 수 있다**는 질문·우려가 있음 (확정 답변은 대화에 없음).
- 텔레그램에 봇/채널을 추가해 **알람 수신**하는 방식도 사용 중.

### 카쫀쿠(과거 프로모션) 관련
- **1+1 Plus 5개 + Pro 5개** 등 대량 구매 사례. 당시는 "카톡에서만 되는 거 아냐?" 식의 의심이 많았으나, 지금 보면 **역대급 혜자 이벤트**로 회자됨.
- **Plus는 가족 양도 불가** — 양도 가능할 줄 알고 샀으나 못 씀.
- Plus 용도에 대한 회의: "플러스는 어디쓰죠..."

### 향후 모델 소식 (채팅 언급 수준)
- 아스트라 다음 모델명 **「bel」** — 학습 완료 언급.
- **GPT6 sol / luna / terra** 출시 기대 언급. 아스트라는 최상위 모델이라 초기화·한도 이슈가 두드러진다는 맥락.
