## 인사이트·노하우

### AI 도구·세션 관리
- **도구를 자주 바꾸면 세션 이관이 애매해진다** — 파일은 그대로여도, 하던 작업·세션 맥락이 꼬이기 쉽다.
- **집중해서 작업할 때만 장애가 나는 체감** — 클로드는 8/24(태평양 기준) 새벽에 Opus 5·Fable 5 등 여러 모델 오류가 이어졌고, 낮에는 로그인·Claude Code 구독 연결도 잠깐 막혔다가 복구됨. 에이전트를 매일 쓰는 경우 **모델보다 먼저 [상태 페이지](https://status.claude.com/)를 보는 습관**이 유용하다는 공통 인사이트.

### Cursor / Composer / 터미널 모델 역할 분담
- **대규모·메인 작업** → 터미널에서 다른 모델 사용이 낫다는 실무 의견.
- **Cursor의 Grok·Composer** → 서브에이전트 역할.
- **Fable·프런티어급 탑티어 모델** → 오케스트레이터로 쓰면 체감상 더 안정적.
- Cursor **안의 클로드 모델**은 썩 별로라는 개인 체감.
- Composer는 당분간 **「3존버」**(기다리는 쪽)이고, **Grok 4.6**으로 웬만한 건 처리한다는 사용 패턴.
- 세션을 무지막지하게 돌릴 게 아니면 **Cursor(모바일 포함)** 가 딱 맞고, 유지보수 작업에서 삶의 질이 올랐다는 경험담.

### `/goal` 사용감
- `/goal`이 「귀찮아도 강제로 무조건 하게 되는」 기능인지 질문이 나왔고, 답은 **「그라모 골 아파지지요」** 수준 — 완전 강제라기보다 목표 지속·완수 압박에 가깝다는 뉘앙스.

### 맥 → 리눅스 클립보드 공유 (`ssh-clipboard`)
- **원인/배경**: SSH로 리눅스 서버 작업 시 텍스트만 되고 이미지·파일 붙여넣기가 안 되는 불편.
- **해결**: 오픈소스 **`ssh-clipboard`** — 맥에서 `cmd+C` 한 번으로 **이미지·파일까지** 리눅스 서버에 붙여넣기 가능.
- **테스트**: Tailscale로 맥북을 디바이스에 묶어 실사용 확인.

### Z-Pack 이미지 제작 Harness (강의 소개에서 나온 방법론)
- 단순 이미지 생성기가 아니라, **승인된 스타일·레퍼런스 기준으로 프롬프트를 컴파일**하고 결과·작업 기준을 **외부 워크스페이스에 안전 보관**.
- 마음에 안 드는 이미지를 **덧칠하거나 이전 후보를 무작정 재사용**하지 않고, 필요 시 **새 생성 체인으로 재시작**.
- 스타일, 비율, 오브젝트 스케일, 구도, 조명, 재질 등 **구성 요소를 각각 확인·관리**.

### 헤르메스(Hermes) VPS 운영
- **「헤르메스를 VPS에 두고 코딩·웹개발 메인으로 쓰는 게 무리인가?」** → **가능하다**는 답(복수 참가자 동의).

### 개인 에이전트·AI 업계 맥락 (뉴스 브리핑에서 공유된 요점)
- **Instinct**: 메일·메신저·달력·화면·위치 등 광범위 권한 + 약관 논란(영구·취소 불가 사용, 학습 활용, 사용자 대신 약속 체결 등). 핵심 질문은 「무엇을 하냐」보다 **「메일함 열쇠를 누구에게 주냐」**.
- **ChatGPT Work**: 코딩 밖 사무 업무 위임용이지만, 오픈AI 내부 98% 코덱스 사용 vs 조직 구독 17%·개인 1% 미만 — **에이전트 부족보다 코딩 외 영역 손이 안 가는 게 병목**.
- **GPT 5.6 Sol**: 입력 $4/1M, 출력 $20/1M (각 20%·33% 인하), **2026-11-21까지** 유지.
- **앨라배마 검찰**: 가드레일 제거 사이버 모델이 격리망 밖 허깅페이스 침해 관련 오픈AI 조사.
- **허깅페이스**: 130억 달러 규모 매각 협상 보도(미확정).

## 반응이 컸던 화제

- **Cursor vs Composer vs 터미널 모델 워크플로** — 여러 명이 모델 역할 분담(서브에이전트·오케스트레이터)·실사용 모델(Grok 4.6)·Cursor 내 클로드 체감 등을 나눔. 실무 도구 선택과 생산성에 직결되는 주제라 참여가 이어짐.
- **「취저」 투두앱 UI** — 개발자 취향에 끌리는 UI라는 반응. P2가 비슷하게 만들겠다고 함.
- **ssh-clipboard** — 맥↔리눅스 이미지·파일 붙여넣기 가능이라는 실용 팁으로 공유됨.

## 자동화·시스템 적용 후보

- **3계층 에이전트 패턴**: 터미널(메인·대규모) + Cursor Grok/Composer(서브) + Fable/프런티어(오케스트레이터).
- **Z-Pack식 이미지 파이프라인**: 레퍼런스·스타일 컴파일 → 외부 워크스페이스 보관 → 실패 시 덧칠 대신 **새 생성 체인** — 일관된 비주얼 에셋 제작에 이식 가능.
- **`/goal` + Cursor** — 짧은 세션·모바일 환경에서 목표 지속 실행 루프(강제성은 불명, 완수 압박 도구로 쓰는 인상).
- **ssh-clipboard + Tailscale** — 원격 서버 작업 시 클립보드·파일 전달 자동화 스택.

## 질문·미해결

- **`/goal`이 정확히 어떤 강제성을 갖는지** — 「골 아파지지요」 정도의 느슨한 답만 있고, 메커니즘·한계는 대화에서 확정되지 않음.
- **Z-Pack 강의 참여 링크** — 금요일 전 유튜브 라이브 URL 공지 예정, 아직 미정.
