# AI 요약

## 인사이트·노하우

- **Codex 계정 1개로 OpenClaw 여러 개 운용 가능**
  - 실측 사례: Codex–OpenClaw 프로필 5개를 각각 운용 중이라는 답변이 있음.
  - Codex 계정을 여러 컴퓨터(최대 5대)에서 쓴 경험도 언급됨. (OpenClaw는 아니었지만 동일 계정 다중 사용 가능성을 시사)
  - 다중 인스턴스 운용 시 권장: **각각 이름을 붙여 페르소나를 분리**할 것. 나중에 헷갈리지 않음.
  - Tailscale로 외부 접속·공유는 가능하지만, **페르소나 분리는 유지**하는 편이 좋다는 조언.
  - "이름 있으면 애정도 생겨요 잘키우게 됩니다" — 에이전트에 이름·역할을 부여하면 운영 품질이 올라간다는 실무 감각.

- **멀티 에이전트·봇 간 협업 설계 방향**
  - 맥미니 새 셋업을 계기로 **봇 간 인수인계·협업 방식을 체계화**하려는 논의가 있음.
  - 관심 주제: 분업·협업, 보고·상호평가, 가치·우선순위 정렬, 일하는 방식 학습.
  - 회사에 에이전트를 "동료"로 도입할 때의 **기술적 시도 + 조직원 동기부여**도 세미나 후보 주제.

- **로컬 TTS (맥)**
  - 맥에서 쓸 만한 로컬 TTS 모델을 찾는 질문이 있었으나, 이 대화 안에서는 **구체 모델명·설정은 공유되지 않음**. (스터디에서 풀어볼 예정이라는 언급만 있음)

- **Claude 사용량/초기화 이슈**
  - 본인만 Claude 사용량이 500 수준으로 보이고 옆 사람은 정상이라는 짧은 언급. **원인·해결 과정은 없음**.
