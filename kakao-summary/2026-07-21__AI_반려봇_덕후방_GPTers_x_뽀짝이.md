# AI 요약

## 인사이트·노하우

- **키미(Kimi) 신규 구독 차단 우회**: 키미 신규 가입이 막혔을 때 OpenRouter API를 통해 사용 가능. 직접 구독이 아닌 API 경유로 이용.
  - 단, "API로 사고 까지 쓰면 GPT보다 저렴하지 않다"는 의견 있음 (비용 우위 불확실).
- **일시적 차단 패턴**: "K2 때도 그랬다"는 경험담 — 한국 서비스의 신규 가입 차단은 일시적인 경우가 많음.
- **Codex 토큰 미적립 버그**: "자동 코딩이 깨져서 codex 토큰이 안 달리고 있다" — 복원이 어렵다는 언급. 원인·해결책 미확정(미해결 참조).

## 추천·자료

- **OpenRouter**: 미국 호스팅 기반 LLM API 집약 서비스. 키미 등 직접 접근이 어려운 모델을 API로 우회 이용할 때 유용. 미국 서버 경유라는 지역적 이점도 언급됨.
- **GPT-5.6 Sol / Terra**: 토큰 소모 후 자동 충전이 잘 된다는 실사용 후기. 현재 활발히 쓰이는 모델 티어.

## 반응이 컸던 화제

- **AI 바이럴 마케팅 + 모델 정체 은폐**: 키미가 "너 누구냐" 물으면 "Claude"라고 답한다는 사례 — Claude 기반임을 숨기지 않는(혹은 숨기지 못하는) 구현과, AI 업계의 상호 모방(수노 유튜브 음원 학습, 책 무단 학습 이슈)으로 대화가 이어짐. 업계 전반의 저작권·모방 관행에 대한 공감대 형성.

## 질문·미해결

- **Codex 토큰 미적립 문제**: "자동 코딩이 깨져서 codex 토큰이 안 달리고 있다 — 망가지는 건 한순간인데 복원은 왜 안 되지" → 원인·해결 방법 불명, 후속 조사 필요.
- **키미 OpenRouter 경유 실제 비용**: GPT 대비 저렴하다는 주장과 "그렇지 않다"는 반론이 교차 — 정확한 비교 수치 미확인.
