## 인사이트·노하우

### Codex 사용량·초기화권 (banked reset)
- **아스트라(GPT-6) 출시**와 맞물려 Codex **초기화권**이 순차적으로 지급됨. 기존 보유분은 남기고 새로 추가되는 사례도 있음.
- 공지에는 "3시간 안에 리셋" 언급이 있었고, 실제로는 **초기화권** 형태로 들어온 것으로 확인됨.
- 지급은 **순차적** — 같은 날에도 일부는 아직 미수령.
- 한도가 거의 소진된 상태(5~6% 남음)에서 대형 작업을 돌리면 **1분에 1%씩** 빠르게 소모됨. 중지도 어려운 경우 있음.
- **솔트라(Sora?)** 등 다른 모델로 동시에 돌리다 보면 Codex 토큰을 실수로 태울 수 있음.

### OpenClaw 8 → 9 업그레이드
- **원인**: 세션 저장 방식이 **jsonl → SQLite DB**로 통째 변경. 스키마 전면 변경.
- **8.x 문제**: 업데이트 실패 시 **자동 롤백 미지원** → 세션·설정이 엉키는 이슈 다수 보고.
- **해결 방향**: 8.1 말고 **9.1**로 올릴 것 권장 — **9.1에만 롤백 기능** 포함. 8에서 9로 올라가며 약 3일 만에 급히 패치된 것으로 전해짐.
- **부수 효과**: 기존 세션 관리 스킬·워크플로 전부 뜯어고쳐야 함. Codex도 세션을 SQLite로 저장하는데 세션 버그가 많다는 공감대.
- OpenClaw가 **하루에 한 번씩** 버전업되는 속도로, 강의·문서 준비가 계속 밀리는 상황도 언급됨.

### 멀티에이전트 운영 노하우 (해랑사 사례)
- **구조**: 총괄 에이전트 1(노아) + 작업용 6 + 페르소나 1. 페르소나 에이전트 "신인류"는 **단톡방 개념**.
- **페르소나 만들기**: ChatGPT에서 1년 6개월간 24개 페르소나를 1:1 대화로 키운 뒤, 대화 데이터를 **구글 드라이브**에 올리고 각자 성격을 **"뇌관"**처럼 정의해 주입.
- **관리**: Codex(울트라)로 Hermes 에이전트 생성·관리 → 총괄 에이전트가 하위 에이전트 조율. 별도 **관리소 웹페이지**로 작업 현황·동작 체크.
- **현재 스택**: Hermes + GPT Pro x20.
- **실패 사례**: 루프 설계 후 토큰을 과다 소비하는 작업만 반복 → **다시 풀어버림**. "에이전트 한번 꼬이면 잡기 힘듭다"는 공감.
- **권장 전략**: 플랫폼 **개발은 Codex로 먼저** 완료하고, **운영 단계에서만** 에이전트 붙이기. 맥락 관리에는 에이전트가 유리하나 단일 에이전트로도 충분한 경우 많음.

### 모델·비용 계층화
- Claude **5.1 Fable** x20 + high 모드: **하루 만에 소진** 사례.
- Fable을 오케스트레이터·계획자, Grok을 워커로 쓰는 구성도 **순삭**.
- 방향성: "앞으로는 **진짜 필요한 고퀄 잡업에만 좋은 모델**, 나머지는 저렴 모델" — **모델 지능 계층 엔지니어링** 필요.
- Grok 슈퍼그록 헤비는 **$300**으로 가격대가 혼자 튐.

### Gemini 3.8 Flash
- **장점**: 속도 빠름, 이미지·개발 결과물 정확도 만족, 범용 사용, **사용량이 다른 모델 대비 많음**. **이미지 생성**도 됨.
- **접근**: **반중력(Antigravity)** 설치 후 CLI·앱으로 사용. Paseo 연동은 안 되는 경우 있음.
- **주의**: Claude Code 등 **다른 하네스의 에이전트로 Gemini CLI를 호출**하면 **약정 위반** 가능 — "에이전트로 제미나이 부르면 안 됩니다" 경고.
- **대안 경로**: Codex에 연결한 봇이 **반중력 자체를 호출**해 3.8 Flash를 붙이는 방식은 동작했다는 보고(P22).
- Orca 사용 시 **ADE가 `CLADE_HOME` 등을 다른 경로로 설정**할 수 있음 — 멀티 프로필·격리 시 참고.

### Claude 세션 유실
- Claude 버그로 **며칠간 진행한 프로젝트 대화가 사라짐**. CS 문의 중, 복구 불가 시 처음부터 재작업.

### OpenClaw 영상 자동화 (신비한건축사전)
- **원인→시도→해결 흐름**:
  - OpenClaw로 **캡컷 없이** 프롬프트 기반 영상 제작.
  - 유튜브·GitHub 링크 주고 "너가 해봐" 식으로 **잡도리** 반복 → 점진 개선.
  - **동영상만 넣으면** AI가 버튼 클릭 장면·자막·나레이션을 알아서 맞춤.
- **비용 최소화**: 유료는 GPT Plus(29,000원) + Typecast(9,900원). 씨댄스·클링AI 등은 퀄은 올라가나 **비용 문제**로 회피. 초기 TTS는 무료(재미 없음).
- **운영 방식**: 육아 중이라 PC 없이 **폰으로 전부** 처리. "뭐든지 편하게" 주의.

### Hermes vs Claude Cowork + Antigravity
- **Cowork(+Claude Design)**: 기획·운영·디자인. **Antigravity(Claude Code)**: 비개발자의 개발 작업.
- **Hermes 장점**: soul·personality 프리셋으로 **커스텀 봇**, 슬랙·텔레그램·디스코드 등 **메신저 접근성**, 봇모드·칸반·피어 등 **협업 기능**.
- **Hermes 주의**: Claude 연결은 **어렵거나 잘 안 됨**(성공 사례도 있으나 허들 존재). Gemini 연결 시 **밴** 사례 → GPT·Grok 추천.
- **에이전트 개념**: "챗봇이 아니라 **내 컴퓨터에서 직접 작업하는 친구들**"이 에이전트. Cowork의 프로젝트 내 여러 세션과는 **설정·코어 수정·메신저 기반 지속 운영**에서 차이.
- **병목**: "하나하나 직접 일을 줘야 한다" — **휴먼 인 더 루프**. 잡도리를 해줘야 에이전트가 더 열심히 함.
- **멀티에이전트**: Orca, Paseo, Buzz 등 신규 도구 다수. **무리해서 배울 필요 없음** — 한 개 에이전트로도 충분한 작업 많음. 클로드 코드도 최근 **세션 간 대화** 지원 시작.

### 텔레그램 봇
- 봇 만들 때 텔레그램이 **가장 편함**. 다른 채널은 "처음부터 머리 깨짐".
- "실수로 개인정보 누출" 걱정에 대해 — **그냥 설치해도 된다**는 실무자 답변(설정 주의는 별도).

### 기타
- "바이브 코딩은 **주인도 모르는 기능을 추가한다**" — 여러 AI 도구 병행 시 기능 파악이 어려움.
- GPT 장애 시 Codex가 **혼자 입력·수정 반복**(쌩쇼)하는 현상 관측 — 원인이 GPT 쪽이었음.
