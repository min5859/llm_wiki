# AI 요약

## 인사이트·노하우

### OpenClaw 8.2 — 텔레그램 미니앱·대시보드
- **8.2 출시** 후 새 대시보드 명령어가 추가됐다는 피드백이 있음. 버그 수정 여부는 당일 대화에서 확인되지 않음.
- 방향성 비교: **헤르메스(Hermes)** 는 독자 앱 방향, **오픈클로(OpenClaw)** 는 **텔레그램 미니앱**으로 기존 웹 대시보드 기능을 옮기는 시도로 언급됨.
- API 추가 시 채팅창에 **암호화된 key를 보안 입력**하라는 UI가 뜨고, 패스워드 입력 폼처럼 동작한다는 관측. 민감 정보를 일반 채팅 텍스트와 분리하는 패턴으로 참고 가능.

### 헤르메스 + 구글(Gemini) 연동 — OAuth 차단 함정
- **구독 계정으로 구글 OAuth 연동 → 차단**된다는 경고가 여러 명에서 반복됨.
- **OAuth로 연결하면 차단**, **API 키로 연결하면 차단 안 됨** — 다만 일반 사용자는 API 토큰 비용을 감당하기 어려워 실질 대안이 아님.
- 실제 사례: OAuth 연결로 **3개 계정 차단** 경험 공유.
- **제미나이(Gemini) 2.5 플래시 무료**로 헤르메스에 붙이는 방식은, 구독 사용량이 빠지는 게 아니라 **만든 API 키의 무료 한도**를 쓰는 것으로 보이며, OAuth 경로는 여전히 위험.
- 실무 권장안(대화 합의에 가까움):
  - 헤르메스는 **코덱스(Codex) / GPT 플러스 구독**이 최소 비용·성능 균형.
  - **제미나이 OAuth 직결은 피할 것** — “제미나이 바로 계정차단”.
  - 구글 **버텍스(Vertex)** 도 OAuth 연결 시 차단 사례 언급.
- 헤르메스는 **윈도우 미지원** 상태로도 언급됨.

### 구독 vs API 가치·토큰 소모
- **클로드(Claude) $200 구독**은 API로 치면 **$4,000 이상 가치**라는 체감(직접 API 사용 경험자 기준 월 평균 약 20배).
- **Claude Max 20**이 실제로 20배가 아니라는 인식 + 미국 **집단소송** 언급.
- **Max 5**에서 **Fable 5.1 low**로 간단한 작업도 한 번에 **5~10%** 소모한다는 실측.
- $100 플랜도 고강도 사용(매일 서비스 제작, 다채널 운영) 시 금방 소진되는 사례 공유.

### Claude 부분 장애 (2026-09-03 저녁)
- **오픈클로 + 클로드 CLI**: 정상.
- **파세오(Paseo)에서 클로드**: 동작 안 함.
- **소넷(Sonnet)**: 정상.
- **오퍼스(Opus) 등 상위 모델**: 문제 발생 (“클로드 터짐”).
- 같은 시각 **코덱스(Codex)·그록(Grok)** 도 불안정 — 그록 영상 생성 중단, Grok Build 문제 안내.

### 그록(Grok) 프로모션
- 안드로이드 **슈퍼그록(SuperGrok)** 행사는 계정·플랫폼마다 다르게 노출.
- 일반적으로 **이전에 프로모션 받지 않은 계정**에 뜨는 패턴.
- 당일 관측: **3개월 49,000원** 이벤트가 일부 계정에仍 표시.

### 콘텐츠·채널 운영
- 채널명이 **“양산 쇼츠”** 느낌이면 거부감이 생길 수 있고, **채널명만 바꿔도 조회수에 영향** 가능하다는 피드백.
- 다채널 운영 사례: X, 인스타, 링크드인, 쓰레드, 유튜브, 네이버 블로그, 티스토리, 페이스북 페이지 — **“코튼(콘텐츠) 관리가 어렵다”**는 실무 고충.
