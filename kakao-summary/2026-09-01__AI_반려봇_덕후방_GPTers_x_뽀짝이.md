# 카카오톡 대화 정리 — GPTers x 뽀짝이 (2026-09-01)

## 인사이트·노하우

### OpenClaw 8.1 대규모 업데이트 — 공통 장애 패턴
- **규모**: 933명 기여자, 16,000개 이상 PR 반영. 설치·메시징·메모리·스킬·자동화·앱·플러그인·보안 전면 개편으로 "아예 새 도구" 수준.
- **메모리 경로 변경**: 이전 `memory` 폴더 → `main` 폴더로 이전. 업데이트 후 **초기화·이전 기억 소실** 다수 발생.
- **파일 구조 변경**: 스킬 위치·md 파일 위치가 달라짐. `soul.md` 신규 등장. 커스텀 스킬(유튜브 숏츠 제작 등) **전량 소실** 사례 있음.
- **SQLite 전환 마이그레이션 불완전**: 클로드 봇 연결 끊김. **oauth list 누락**이 원인인 경우 확인됨. 자동 마이그레이션이 외부 커스텀 설정을 다 못 가져감.
- **에이전트 수와 인식 문제**: 에이전트가 많을수록 OpenClaw가 인식 못 하는 현상. 3개 vs 15개(세션 608개) 등 규모에 따라 복구 난이도 급증.
- **게이트웨이 중단**: 업데이트 시도 중 게이트웨이 멈춤 빈번. 자동 게이트웨이 재시작·재부팅 설정을 해도 해결 안 되는 사례 있음.
- **텔레그램**: 터미널 문제는 잡혔는데 메시지 송수신 불가 — 별도 복구 필요.
- **UI**: 기본 대시보드 UI 대폭 변경. 작업시간·토큰 사용량 표시 추가. **btw(사이드 채팅)** 으로 작업 중 병행 대화 가능해짐.

### 복구 워크플로 (실제 해결 경위)
1. **원인**: 8.1 업데이트 → 메모리/스킬/oauth/ownership 누락·경로 변경·SQLite 마이그레이션 실패.
2. **시도**:
   - GPT·Claude·루나(모델)에게 물어보며 단계별 복구.
   - 롤백(7.1-2) — 게이트웨이 멈춤 시 Hermes가 롤백 성공 사례.
   - 삭제 후 `2026.07.1-2` 재설치 제안 — 맥락·기억 보존 필요하면 비권장.
   - 자동 게이트웨이 재시작·재부팅 — 효과 없었던 사례.
3. **해결**:
   - **`ownership` 추가** 후 오류마다 AI에게 물으며 점진 복구 (P3, 루나 활용).
   - **Codex를 해당 머신에 로그인**해 OpenClaw 복구·업데이트 위임 — "GPT한테 물어보며 망치다가 백업부터 만들자"는 잘못된 제안도 받음 → Codex가 더 나음.
   - **OpenClaw ↔ Hermes 상호 복구**: "오픈클로 업데이트 → 헤르메스가 해결, 헤르메스 업데이트 → 오픈클로가 해결."
   - 에이전트 많을 때 **Codex로 마이그레이션**이 수동보다 빠름.

### 업데이트 타이밍·비용 함정
- **Codex/OpenClaw 초기화**: 주말에 될 가능성 높음. 평일 초기화 시 크레딧 소모가 커서 주말에 몰리는 패턴으로 추정 ("티보가 주말에 일시킨다").
- **업데이트 전략**: "업데이트는 먼저 얻어맞는 사람들 보고 나서" — hotfix(예: 2.0.1) 나올 때까지 대기. **7.1은 비교적 안정적**이었음. 강의·워크숍 직전에는 업데이트 보류.
- **Hermes API 비용 폭탄**: OpenClaw 죽은 상태에서 Hermes(API)로 "살려내!" 반복 → **복구만 $200** 소모 사례. Hermes는 **크론 자동화만** API로 돌리고, 복구·코딩은 **OpenClaw + Codex(구독)** 가 맞음. "헤르메스만 api로 쓰실 이유가 없는데 뭔가 잘못쓰고 계신 거 같네요."
- **OpenAI 새벽 장애**: ChatGPT/X 공지 — 새벽 OpenAI 다운이 OpenClaw·Hermes 무반응과 겹침.

### macOS·SSH 환경
- **맥 GUI 권한 허용** 팝업을 SSH-only 사용자가 못 보고 **한 달간 업데이트 불가** 사례. GUI에서 권한 허용 확인 필요.
- **Mac mini 재부팅 시**: OpenClaw·Hermes 전부 죽음 → **IP-KVM** 원격 복구 수요.

### Codex vs Claude 요금제 "20X" 차이 (팩트 확인됨)
- **Codex Pro 20X**: 주간 사용량 한도가 거의 정확히 20배. Pro $100/$200은 **5시간 단위 제한 없음**, 주간 한도 중심.
- **Claude $200 "20X"**: **5시간 한도**에만 20배 적용. **주간 한도는 $100 대비 약 2배** — 가격표만 보면 Codex처럼 4배 늘어나는 것으로 오해하기 쉬움.

### AI 이미지·영상 제작
- **GPT 광고 소재 이미지**: 프롬프트대로 잘 나오나 **어디서 본 듯한 얼굴** — "레퍼런스를 주면 무조건 그 레퍼 따라갑니다."
- **롱폼/영상**: 페이퍼 스타일은 구체적 생성 능력 약한 모델에 유리. image gen으로 생성 후 넘기는 편이 깔끔. Remotion식 편집 vs 모델 생성 방식은 결과 품질 차이.
- **Gemini Notebook**: 유사 산출물 기준 "더 낫겠네요" 평가 (P3).

### IP-KVM (NanoKVM Go)
- OpenClaw·Hermes **하드웨어 수준 원격 제어**·화면 기록·OCR 연동 아이디어.
- **보안 논란**: 설명서에 없던 **마이크 장치** 발견, 중국으로 정보 전송 의혹. 백도어 논쟁. ipKVM 대안 많고 가격 차이 크지 않음 — "그냥 좀 더 비싼 kvm 쓰면 돼요."
