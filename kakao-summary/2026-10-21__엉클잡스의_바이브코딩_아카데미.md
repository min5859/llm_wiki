🔥 영끌맨 AI 뉴스 아침 브리핑 2026.10.21 (수)
오늘의 흐름을 한 줄로 보면, Google은 Gemini의 Personal Intelligence를 Android Auto 차량 안으로 넓혔고, OpenAI는 ChatGPT에 locked chats를, API에 12-hour prompt caching을 더했으며, Anthropic은 Claude Enterprise의 Inference hooks를 beta에서 꺼냈어요.
━━━━━━━━━━━━ 1️⃣ Gemini, Android Auto·Google built-in 차량에서 Personal Intelligence rollout Google이 10월 20일 공식 blog에서 Gemini를 전 세계 Android Auto와 Google built-in 차량에서 쓸 수 있다고 밝히면서, 허락을 받으면 Gmail과 Google Calendar를 포함한 Workspace, Google Photos, Google Maps, YouTube, Search 정보를 연결해 운전 중 말로 한 질문에 맞춤 답을 주는 Personal Intelligence를 rollout한다고 알렸어요. Android Auto에서 먼저 시작하고 Google built-in 차량에는 앞으로 몇 달 안에 들어오며, Gemini app에서 이미 켜 둔 사용자는 차에서도 그대로 이어져요. 👉 볼 포인트 app은 사용자가 직접 켜기 전까지 연결되지 않고 Gemini settings에서 언제든 끌 수 있으며, Google built-in 차량은 phone을 연결한 채 차 안에 있을 때만 개인 맞춤 답을 보여 줘요. 대상은 18세 이상 eligible 개인 Google 계정이고, Workspace business·enterprise·education 사용자와 European Economic Area, 스위스, 영국, 나이지리아는 대상이 아니에요. 🔗 <https://blog.google/products-and-platforms/platforms/android/android-auto-cars-with-google-built-in-gemini-personal-intelligence/>
━━━━━━━━━━━━ 2️⃣ ChatGPT locked chats, 고른 대화를 PIN 뒤에 숨기기 OpenAI가 10월 20일 ChatGPT release notes에서 locked chats를 소개했어요. 고른 대화를 계정에 남겨 둔 채 일반 chat history, pinned chats, search에서 숨기고, 다시 열 때는 4자리 account PIN이나 지원되는 device authentication을 거치게 하는 기능이에요. Free, Go, Plus, Pro와 Enterprise, Edu workspace에 web, iOS·Android app, macOS·Windows용 ChatGPT desktop app으로 순차 제공돼요. 👉 볼 포인트 chat의 more options(•••) menu에서 Lock chat을 고르면 되고, retention과 model-improvement 설정은 그대로 유지돼요. Enterprise·Edu에서는 조직의 retention 정책과 compliance 요건이 계속 적용되고, locked chats도 OpenAI Compliance Platform의 conversation message logs에 포함돼요. 🔗 <https://help.openai.com/en/articles/6825453-chatgpt-release-notes> 🔗 <https://help.openai.com/en/articles/10128477-chatgpt-enterprise-and-edu-release-notes>
━━━━━━━━━━━━ 3️⃣ OpenAI API, 12-hour prompt caching 선택 가능 OpenAI API changelog의 10월 20일 항목에 따르면, prompt cache를 12시간 유지하도록 고를 수 있게 되면서 공유 instructions, tools, context를 더 오래 cache에 두고 몇 시간 간격으로 들어오는 request에도 더 낮은 cached-input 요금을 받을 수 있어요. 12-hour cache write 요금은 input token 가격의 2.5배예요. 👉 볼 포인트 prompt caching guide 기준 GPT-5.6 이후 model은 Responses API에서 prompt_cache_options.ttl을 "12h"로 주면 최소 12시간 lifetime이 적용되고, 기본값 "30m"의 write 요금은 1.25배예요. 이후 read 요금은 lifetime과 상관없이 대부분의 model에서 일반 input의 0.1배, GPT-6.1 Sol에서 0.05배이고, explicit breakpoint마다 prompt_cache_breakpoint.ttl로 lifetime을 따로 정할 수도 있어요. 🔗 <https://developers.openai.com/api/docs/changelog> 🔗 <https://developers.openai.com/api/docs/guides/prompt-caching>
━━━━━━━━━━━━ 4️⃣ Claude Enterprise의 Inference hooks, beta 종료 Anthropic이 10월 20일 Claude Platform release notes에서 Claude Enterprise 조직의 Inference hooks가 beta를 벗어났다고 밝혔어요. 👉 볼 포인트 대상은 Claude Enterprise 조직이고, release notes의 Inference hooks 항목은 Claude Platform Docs의 Inference hooks 문서(manage-claude/inference-hooks)로 바로 이어져요. 🔗 <https://platform.claude.com/docs/en/release-notes/overview>
━━━━━━━━━━━━ 🛠 오늘 해볼 것 ChatGPT에 남겨 두되 목록에서는 숨기고 싶은 대화가 있다면 chat의 more options(•••) menu에 Lock chat이 보이는지 확인해 보세요. GPT-5.6 이후 model로 몇 시간 간격의 반복 작업을 돌린다면 Responses API request에 prompt_cache_options.ttl을 "12h"로 넣고, write 2.5배와 read 0.1배 요금을 기본값 "30m"과 비교해 보세요.
🌱 오늘의 한 줄 Gemini는 차 안에서 내 Google app 정보를 쓰기 시작했고, ChatGPT와 OpenAI API는 대화를 숨기는 방식과 cache를 유지하는 시간을 사용자가 고르게 했어요.
