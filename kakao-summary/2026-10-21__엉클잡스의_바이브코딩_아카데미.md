# AI 요약

## 인사이트·노하우
- **AI 브라우저 `aside`(어사이드) vs `ego`(에고라이트) 비교**
  - `aside`: 차츰 가벼워지고 있으나 여전히 살짝 무거운 느낌이 있음. 브라우저 제어는 깔끔함.
  - `ego`(lite, 베타버전): '스페이스'라는 별도 격리 공간을 제공하지만, `aside`만큼 제어를 깔끔하게 하지는 못하는 느낌.
- **실무 AX(AI 전환) 구축 수준과 도구 조합**
  - 고도화된 로컬/자체 구축은 환자 개인정보 보호 등 특수 전문직 환경이나 빡빡한 사내 보안망에서 필요한 것이며, 일반적인 환경에서는 "`aside`(어사이드)와 클로드만으로 AX 무리 없다"는 의견.
  - 작업 실패 대안 사례: 코덱스(Codex)가 토큰을 78% 소모하고도 처리하지 못한 작업을 `aside`에 클로드(Claude)를 연결해 2시간 만에 해결함.
  - 추천 조합: "터미널에서 클로드코드, 브라우저에 어사이드"
- **OpenAI API 12시간 프롬프트 캐싱(Prompt Caching) 설정 및 요금 구조**
  - GPT-5.6 이후 모델에서 Responses API 사용 시 `prompt_cache_options.ttl`을 `"12h"`로 설정하면 최소 12시간 동안 캐시가 유지됨 (`prompt_cache_breakpoint.ttl`로 개별 breakpoint마다 별도 지정 가능).
  - 요금 비교:
    - Write 요금: 기본값 `"30m"`은 일반 input의 1.25배, `"12h"`는 2.5배.
    - Read 요금: TTL과 무관하게 대부분 모델에서 일반 input의 0.1배, GPT-6.1 Sol에서는 0.05배.
  - 몇 시간 간격으로 실행되는 반복 작업에서 공유 instructions, tools, context를 캐싱할 때 비용 절감 가능.
- **ChatGPT `locked chats` (대화 잠금) 기능과 기업 컴플라이언스 주의점**
  - 대화의 `more options(•••)` 메뉴에서 `Lock chat`을 선택하면 일반 채팅 내역, 고정 채팅, 검색에서 숨겨지고 4자리 계정 PIN 또는 기기 인증으로만 열람 가능.
  - 단, retention 및 model-improvement 설정은 그대로 유지되며, Enterprise·Edu 환경에서는 조직의 retention 정책과 OpenAI Compliance Platform의 대화 메시지 로그에 여전히 포함됨.

## 추천·자료
- **`aside`(어사이드)**: AI 브라우저 도구. 클로드와 연동하여 복잡한 웹 작업을 처리하거나 자동차보험 비교·갱신 같은 일상 웹 태스크에 유용함.
- **`ego`(에고라이트)**: '스페이스'라는 격리된 작업 공간을 제공하는 AI 브라우저(lite/베타 버전).
- **`tsrs`**: Cloudflare와 VoidZero가 공개한 Rust 기반 TypeScript 타입 검사기. TypeScript 팀과 협업하며 TS 7.0 대비 최대 8배 빠르고 메모리를 70% 덜 사용함 (실제 마이그레이션 사례에서 약 5배 속도 향상 보고).
- **`filee`**: 한국 개발자가 만든 무료 파일 변환기로, HWP(한글) 파일 변환 작업에 유용함.
- **`ChatGPT for Kakao`**: 카카오톡 채팅방에 추가해 `@ChatGPT` 멘션이나 `/이미지`, `/예약`, `/운세`, `/뉴스` 등의 명령어로 쓸 수 있는 챗봇 서비스 (채팅 내용은 학습되지 않으며, 이용자별 동의 필요).
