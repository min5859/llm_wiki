## 인사이트·노하우

- **GPT-6 Astra 체감 품질**: 참가자들은 Sol 대비 “한 단계 급을 달리하는” 수준, “페이블 처음 맛본 느낌”으로 평가. Sol은 느리고 답답했으나 Astra는 **속도·지능·간결함**이 동시에 나아졌다는 공통 인상. 마이그레이션처럼 Sol이 헛발질하던 작업도 Astra가 우선 “되게” 만들어 준 사례가 있음.
- **토큰·한도 관리**: Astra는 만족도는 높지만 **토큰이 빠르게 소모**됨. 회사 작업 하나 마무리에 **주간 이용 한도의 약 10%**가 한 번에 줄어든 사례. 비용 부담이 커서 “대표님께 무릎 꿇고 추가 결제” 같은 반응도 있음.
- **권장 워크플로(실사용자 제안)**:
  - **기획·문제 접근**: Astra
  - **실행**: 가능하면 Astra, 다만 토큰 절약을 위해 **서브에이전트에 실행을 떼어 맡기고** 본체 Astra는 설계·기획 위주로 쓰자는 의견 (“서브에이전트 떼로 시켜야 될 것 같아요 … 설계랑 기획만 시킥”).
- **Claude Code Max → Codex 전환**: Astra 체험 후 **Claude Code Max를 다운그레이드하고 Codex를 올리겠다**는 실제 행동이 여러 명에서 나옴. Astra 만족도가 Claude 구독 재조정으로 이어진 패턴.
- **ChatGPT + webMCP**: “지피티 사이트 + webmcp면 코덱스 안에서 웹서비스 만들듯” — 브라우저 ChatGPT 환경에서 webMCP를 쓰면 Codex식 웹서비스 개발에 가깝게 할 수 있다는 사용 인상.
- **원격·모바일 활용**: ChatGPT는 원격 연결이 되어 **모바일에서 결과 확인**이 편하고, 개발자가 직접 붙잡는 시간을 줄여 준다는 체감.
- **Codex 초기화권(리셋권) 모바일 사용**:
  - 상황: 맥북에 Codex를 켜 둔 채 **어사이드(Aside)로 원격 지시** → Codex 한도 소진 → 어사이드에서 초기화권 사용 요청했으나 이미 소진되어 불가.
  - 해결: **모바일 크롬에서 ChatGPT(gpt) 사이트 접속**으로 초기화권 사용 가능 — 실제로 즉시 성공한 사례 있음.
