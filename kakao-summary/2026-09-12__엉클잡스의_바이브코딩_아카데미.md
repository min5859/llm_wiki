# AI 요약

## 인사이트·노하우

- **0.9.0 테마 시인성 문제 → 터미널 원인**
  - 0.9.0 사용 중 테마 가독성이 떨어졌다고 느꼈으나, 원인은 앱 테마가 아니라 **터미널**이었음.
  - 해결 방향: **iTerm2** 또는 **ghostty**로 교체 검토.

- **Codex + ComfyUI로 1분 영상 로컬 제작 (라네즈 화장품 광고형)**
  - 전체 로컬 작업. **MiniMax H3**로 1분 영상을 **한 번에** 생성.
  - **Codex**가 ComfyUI 워크플로우를 직접 작성·**최적화**.
  - 후처리 스택:
    - 업스케일: **SeedVR2**
    - 배경음: **MiniMax Music3**
    - 나레이션: **Qwen3-TTS**
  - GPU: **RTX 4090** (DGX 아님).
  - 참고 실측: **3080 10GB**에서는 10초를 넘기면 VRAM 부족으로 실패했던 사례가 있음 → 1분 단일 생성은 4090급 + 워크플로우 최적화가 전제로 보임.
  - 평: 광고 바로 투입은 아직 부족하나, 로컬 1분 영상까지 나온 수준은 만족스러움.

- **Codex + Astra + Blender + GPT 실사화 파이프라인**
  - Codex에서 **Astra 모델**로 서울 북촌한옥마을 **블렌더 모델링 → 렌더링**.
  - 완성 렌더 이미지를 **GPT로 실사화(photorealistic 변환)** 하는 2단계 워크플로.

- **로컬 LLM에 대한 실무적 판단 + 대안 구조**
  - 로컬 LLM 단독 사용은 비추천 쪽:
    - 파인튜닝 어렵고 응답 느림.
    - 맥북 팬 돌아가며 기다리는 것보다 **클라우드 코딩 에이전트(클로드코드) 한도가 풀릴 때까지 기다리는 게 더 빠를 수 있음** → 구독 추가가 나을 수 있다는 견해.
  - 반면, 한국어 LLM 리더보드 1등 모델 제작자 **이승유** 강의에서 제시된 방향:
    - DeepSeek·Qwen·GLM을 **내 PC에 안 깔고** 굴리는 방법.
    - 로컬 LLM 전문가도 정작 로컬 단독은 안 쓰고, **클로드코드를 총괄 오케스트레이터로 두고 저렴한 모델 여러 개에 잡일을 위임** → **토큰 비용 약 10배 절감** 주장.
  - 요지: "로컬 LLM만" vs "클라우드 오케스트레이션 + 저가 모델 분업"은 다른 전략.

- **Tailscale 체감 사례**
  - 올림픽공원 **소마미술관** 전시장에서 Tailscale의 유용함을 체감.
  - 맥락: 전시 공간에서 AI 관련 환경/접속을 목격한 경험과 연결됨(구체적 설정·트러블슈팅 단계는 대화에 없음).

- **ComfyUI 워크플로우를 Codex로 뽑기**
  - "컴피 뽑는 게 쉽지 않다"는 공감이 있었고, 이번 사례에서는 Codex로 워크플로우 생성·최적화가 실제로 가능했음이 확인됨.
