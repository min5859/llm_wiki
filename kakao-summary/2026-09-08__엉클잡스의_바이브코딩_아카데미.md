# AI 요약

제공된 카카오톡 대화만 기준으로, 장기 지식으로 남길 만한 내용을 카테고리별로 정리했습니다.

## 인사이트·노하우

- **GPT Pro 사용량 소진 속도**: "30분에 10%씩 사라지는 gpt pro" — Pro 플랜 한도가 생각보다 빠르게 줄어든다는 관측. 중첩 서브에이전트 가동이 원인일 가능성도 언급됨.
- **Codex 리셋(초기화) 시그널**: 대화 중 "코덱스 리셋 시그널"이 떴다는 소식 → 이후 **순차적으로 초기화가 적용**됐다는 확인. 참가자들은 남은 초기화권을 소진하는 쪽으로 대응.
- **CodexBar류 실시간 연동 툴의 트레이드오프**: 편하지만 **메모리를 꽤 잡아먹는다** — "편한데는 다 이유가 있다"는 실사용 관찰.
- **윈도우용 CodexBar 확보 경로**:
  - 원인: macOS용 CodexBar와 유사한 **윈도우 상태표시줄 모니터** 필요.
  - 시도: "윈도우용 코덱스바 만들어줘 ~하고 레포 던져보세용" — AI에 레포를 넘겨 커스텀 빌드.
  - 해결: [Win-CodexBar](https://github.com/nesszer/Win-CodexBar) 등 **이미 배포된 GitHub 레포**가 존재. 다만 "나한테 맞춰서 해야 할 뿐"이라 **포크·수정 후 개인용으로 쓰는 패턴**이 일반적.
- **CodexBar를 쓰는 이유(한 참가자 사례)**: CLI 대신 데스크톱 앱 사용, **아이디를 번갈아 쓰는** 환경 → 상태표시줄에 한눈에 보이되 방해받지 않는 UI가 맞음. 모바일 연동까지 붙이려는 계획도 있음.
- **GPT 사용량·플랜 운영 노하우**:
  - Ultra를 **딱 1회** 써보면 **50%가 순삭** → 이후 Light·Medium만 사용하는 전략.
  - 한도 100% 풀충 상태는 **포모(FOMO)**를 유발 — "갖고만 있어도 만능감·전능감" → **일부러 안 쓰는** 사람도 있음.
- **Gemini 사용 경험(작업 vs 보고)**:
  - 코딩·에이전트 작업(Aside + Gemini, Fast 모드): 사용량 급소진, 품질 불만 — "정신병자같습니다", "타버린듯".
  - 비유: "모든지 긍정적인데 tangible한 건 하나도 얘기 못하는 외국계 컨설팅펌 임원".
  - 반면 **만들기보다 보고·정리** 쪽에서는 새 관점·의사결정자용 표현을 잘 찾아온다 — "작업만 안시키면.. 조은 친구".
  - 과거(작년 중후반) 주력이었으나 현재는 신뢰도 하락; "버릴게 없음... 삼대장, 사대장 다 써야함" — **용도별 멀티 모델** 전략.

## 반응이 컸던 화제

- **Codex 리셋·초기화권**: "코덱스 리셋 시그널" → 순차 초기화 확인 → "갓덱스", "내 차례를 다오" 등 **집단적 환호**. 한도/리셋 이벤트에 대한 공감·기대가 큼.
- **GPT Pro·Codex 사용량·포모**: 30분 10% 소진, Ultra 1회 50% 순삭, 풀충 오너의 "안 쓰겠다" — **할당량 psychology**와 실제 소진 속도가 동시에 논의됨.
- **Gemini 품질·용도 논쟁**: 코딩/에이전트에 쓰면 실망 vs 보고·관점 제시에는 유용 — **참가 다수·비유·공감**이 이어진 주제.

## 자동화·시스템 적용 후보

- **하이퍼 커넥션 스택(한 참가자 구성)**:
  - 집 **맥미니** ↔ **핀란드 VPS** 연결
  - **그록봇(Grokbot) 안 VM** 가동
  - **Windows** 원격 연동으로 Aside(에이전트)에 작업 위임
  - **herdr 0.9.0** 터미널 통합으로 "제각각 다른 OS·디바이스"를 한 창에 묶는 패턴 — "앞으로 대세"라는 전망.
- **CodexBar 개인화 워크플로**: GitHub에 공개된 CodexBar 계열 레포를 골라 **본인 계정·앱 사용 패턴에 맞게 수정** → 상태표시줄 모니터링 → (계획) 모바일 연동.
- **LLM 할당량 운영**: Ultra는 실험 1회만, 일상은 Light/Medium; 서브에이전트 중첩 시 Pro 한도 급감 가능 — **에이전트 병렬도와 플랜 선택**을 같이 설계.
- **모델 역할 분리**: 코딩·구현 → Codex/GPT 계열; 보고·관점·표현 → Gemini 등 — "삼대장, 사대장 다 써야함".

## 질문·미해결
