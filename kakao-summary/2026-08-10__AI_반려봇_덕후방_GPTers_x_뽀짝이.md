# AI 요약

## 인사이트·노하우

### ChatGPT 대화 내역 유실·불러오기 실패
- **증상**: 지피티와의 대화가 거의 일주일치 뭉텅이로 날아감.
- **시도·판단**: 가끔 대화가 안 불러와질 때는 인터넷 이슈인 경우도 있음. 다른 사례에서는 채팅 내역이 아예 날아간 적도 있다는 보고.
- **해결·조치**: 새로고침해도 계속 안 나타나면 **ChatGPT에 직접 문의** 필요.

### ChatGPT Plus($20) 이미지·디자인 수정 사용량
- **$20 Plus** 요금제에서 이미지 디자인 수정을 여러 번 사용했을 때 주간 사용량 약 **15%** 소모 (초기 3% 사용 후 추가 수정).
- 맥락: 달력으로 누락 물품 기록·처리 등 실무용으로 “쓸만하다”는 평.

### Tailscale + OpenClaw 대시보드 원격 접속
- **원인·맥락**: Openminis 등 iPhone 전용 터미널형 도구를 쓰기 어려운 환경(아이폰 없음 등).
- **해결**: **Tailscale**로 OpenClaw 대시보드를 연결해 사용. 텔레그램보다 더 자주 쓰는 수준까지 올라갔다는 경험담.

### Openminis(안드로이드) — 은행 앱 탐지·거래정지
- **원인**: 플레이스토어 앱이 아닌데 권한이 많은 앱을 설치하면, **하나은행 등 은행 앱이 탐지**해 거래정지.
- **해결**: **은행 방문**해서 풀어야 하는 사례 보고. 안드로이드에서 플레이스토어 외 설치 시 특히 위험.
- **대조**: iPhone에서는 별 문제 없이 사용 중이라는 보고. 클로드 인증도 바로 되었다는 경험도 있음.
- **교훈**: 권한·설치 경로를 잘 확인해야 함.

### AI 영상 생성 — Grok Imagine vs Higgsfield vs 덕테이프 GPT
- **Grok Imagine**: 영상 생성 중 **가장 저렴**. 단, **싸게 쓰려면 CLI가 아니라 웹에서 Grok이 제공하는 에이전트**를 써야 함.
- **Higgsfield**: CLI에서 작업을 끝내고 싶다면 Grok보다 **비싼 편**이지만 CLI 워크플로에 맞음.
- **나노바나나 vs 덕테이프 GPT**: 덕테이프 GPT는 수정을 많이 하면 **“지글지글”** 거리는 문제가 자주 거슬림. 나노바나나는 조금 단조로워지는 대신 **지글거림 없이 스타일 유지**가 쉽다.
- 실제 사례: 뽀피터스 신곡 MV를 **나노바나나2 + Grok Imagine 1.5**로 제작.

### OpenClaw + Codex로 외부 툴 없이 숏츠 동영상 제작
- **환경**: 10세대 인텔 i5, **GPU 없음**에서도 동작.
- **구성**: 이미지·TTS 모두 **외부 툴 없이** OpenClaw(에이전트 Sol) + Codex. TTS는 **Codex TTS**로 자동 처리되는 것 같다는 경험.
- **프롬프트 예**: “햄버거를 그리머스가 맛있게 먹고 평가하는 30초 동영상으로 제작해줘”
- **품질**: 자막 **싱크**만 아쉽고 나머지는 괜찮음. 싱크 수정 요청 시 잘 고쳐준다는 보고.
- **사용량**: 주간 사용량 **6%** → 반복 테스트 후 **2%**로 완성. 수정은 **1%** 수준.
- **평**: “제가 대단한 게 아니라 Sol이 똑똑한 것”. 숏츠 자동제작을 목표로 계속 테스트 중.

### OpenClaw 에이전트 — Sol vs Luna
- **Sol**: 응답·작업 품질이 똑똑하다는 평이 반복.
- **Luna**: **토큰을 아낀다고 답변이 짧게** 세팅되어 있는 것으로 알려짐. 실사용에서도 응답이 매우 짧게 온다는 경험.

### 로컬 LLM 하드웨어·모델 실사용 범위
- **RTX 5090**: **Gemma 31B** 정도가 한계(그럭저럭 사용 가능 수준). 가끔 ComfyUI·wiki 가공 등 소소한 용도.
- **DGX Spark** (로컬 사용자 2명 보고):
  - 음성 테스트: Whisper 등 + LLM은 **Qwen 32B MoE**, **Qwen3-Coder-30B-A3B** 등.
  - **120B** 테스트해본 적 있음. **70B 파인튜닝** 시도 후 느리다고 한 대 더 구매한 사례도 있음.
  - 고객사 **보안** 요구로 로컬 사용하는 경우도 있음.
- 워크숍 셋업은 Mac Mini 새로 구매·입문자 레벨 정리 예정(DGX Spark가 아닌 이유로 논의).

### MT5 / C++ → cTrader / Python 전환 검토
- MT5 때문에 **C++** 공부 중이지만 “못 해먹겠어서” **cTrader**로 갈아탈 계획. “파이썬이 먹힌다”해서 선택.

### 디아블로 2 — 봇·봇-투-봇 오케스트레이션 역사
- **D2NT**, **D2DS** 시대(약 20년 전)부터 봇이 돌아갔고, **2010년 전후**부터는 봇 하나가 방 파서 콜하면 다른 봇들이 들어와 **풀방 → 자동 사냥** 패턴이 있었다는 회고.
- “**봇 투 봇의 원조가 D2가 아닐까**” 하는 의견.
- 저장소는 **JavaScript 기반** ([GitHub 링크](https://github.com/tyson0828/d2nt/tree/master/D2NT3.1_NTBot4.2_40)).
- 현대적 응용 아이디어: “D2 사냥을 가장 효율적으로 하는 방법을 찾고 하네스 잡아서 수수햄딘으로 자동사냥”, 캐릭터마다 하네스를 깎아야 한다는 농담·아이디어.

### 에이전트 취미·생활 패턴
- OpenClaw·에이전트 작업이 OTT 게임·술자리를 줄이는 쪽으로 바뀐다는 공감. 일 중에도 텔레그램·SSH로 에이전트를 굴리는 사례.
- **컴-컴, 컴-폰** 묶으면 재밌다는 팁.
