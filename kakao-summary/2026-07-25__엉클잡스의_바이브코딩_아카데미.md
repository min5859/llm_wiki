# AI 요약

## 인사이트·노하우

- **Claude Opus 5 추론 레벨 팁**: 추론 레벨을 `medium`으로 설정하면 속도도 빠르고 성능도 높음. "미디움이 속도도 빠른데 훨씬 나은 것 같습니다". 클로드코드에서 `opus5 + 추론 medium`으로 아티팩트 초안 먼저 요청하면 이전보다 세련된 결과물 획득 가능. 팀 플랜 사용자라면 클로드코드 내 아티팩트 뷰어가 내부 의사결정 도구로 유용.

- **CLAUDE.md (Context Engineering) 정리 지침**: Anthropic이 Opus 5 출시에 맞춰 Context Engineering 블로그 발행. 핵심 3줄 요약:
  1. CLAUDE.md를 열고 중복·겹치는 내용을 줄여라
  2. 폴더 구조, 프레임워크 목록, 아키텍처 개요를 지워라
  3. 클코에서 `/doctor`를 돌려라

- **GPT-5.6(Codex) 과잉 검증 이슈**: "gpt 5.6이 전반적으로 이상해져서 하네스를 뚫고 검증만 파고 있다"는 보고 있음. 하네스 구축자들도 인지한 문제. Codex의 특성으로 "다른 LLM은 돌다리를 두들기며 가는데 코덱스는 돌다리를 두드렸다가 핥았다가 민물인지 바닷물인지 오만 검증"을 함. sol medium 이하 모델 사용 권장.

- **Codex로 GUI 개발 시 워크플로 권장 순서**:
  1. 소넷5로 기본 기능 먼저 구현 (약 30분)
  2. UI는 레퍼런스 이미지를 제공하거나 Codex 플러그인 "이미지→코드 스킬" 활용
  3. 기능 완성 후 디자인 별도 개선
  - "기능만 잘되면 디자인은 언제든 손보면 된다"

- **한글 폴더명 주의사항**: 한글 폴더명을 쓰면 일부 환경에서 폴더명이 작대기(`----`)로 깨지는 문제 발생. 유사한 이름끼리 구분 불가 상태가 됨. 영문 폴더명이 사실상 국룰. 단, 로컬 전용(배포 없음) 프로젝트는 한글도 무방.

- **Codex에서 `cc switch`**: 알트론쿠(불명) 등 다른 모델 키를 Claude Code에서 사용할 때 `cc switch` 명령으로 모델을 껐다 켤 수 있음.

- **Codex "최종" 루프 주의**: "최종"이라 표시해 놓고 수 시간~10시간 돌다가 결과물을 못 쓰는 경우가 있음. 토큰이 아깝다면 진행 감이 없을 때 스톱 버튼 누르고 재접근 권장.
