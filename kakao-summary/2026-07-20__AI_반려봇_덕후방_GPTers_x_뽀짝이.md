- **DeepSeek API 피크 요금제 변경 (2026-07 중순 시행)**
  - 피크 시간대 가격 = 정규 가격 × 2배
  - 피크 시간대 (UTC 기준): 01:00~04:00, 06:00~10:00
  - KST 환산: 오전 09:00~12:00, 오후 14:00~18:00 — **한국 직장 근무시간이 피크타임에 해당**
  - 피크 외 시간 활용 시 여전히 비용 효율 유지 가능

- **중국 AI 모델 사용 전략 (커뮤니티 합의)**
  - 중국 모델은 메인이 아닌 서브로 사용 권장
  - 구독제가 아닌 API 종량제로 돌려야 할 때 적합 (에이전트 백엔드 등)
  - Hermes, 오픈클로(OpenClaw)의 서브 모델로 DeepSeek 연동하는 패턴 활용
  - 개인 비서/민감 데이터 용도는 미국 모델 권장

- **Hermes에 Claude/GPT 구독 연동 가능 여부**
  - GPT 구독: 연동 가능
  - Claude 구독: 불가 — "추가 사용량(API)으로만 허용"

- **오픈클로(OpenClaw) 도입 실사례 — 중소기업 전사 적용**
  - 슬랙에 에이전트 탑재 + 회사 가이드·결정사항 업로드 → 직원이 대표 대신 에이전트에게 질문
  - 회의 전부 녹음·전사 후 에이전트에 입력 → 2주 전 회의 결정사항도 즉시 검색 가능
  - "대표가 일일이 답하던 병목이 사라진" 효과
  - 비개발자의 초기 설치 난관: 유튜브·구글링으로 5주 삽질 → 오프라인 강의 첫날 하루 만에 해결

## 자동화·시스템 적용 후보

- **회의 녹음·전사 → 에이전트 메모리 패턴**
  회의를 전부 녹음·전사하여 에이전트(슬랙 봇 등)에 업로드해두면, 과거 결정사항을 팀원이 직접 검색하는 대신 에이전트에게 질의 가능. 대표·담당자 병목 해소.

- **사내 가이드·결정사항 에이전트 RAG 구성**
  회사 운영 가이드와 의사결정 이력을 에이전트 지식베이스에 연동하면 반복 문의 감소. 오픈클로 + 슬랙 연동이 검증된 스택.
