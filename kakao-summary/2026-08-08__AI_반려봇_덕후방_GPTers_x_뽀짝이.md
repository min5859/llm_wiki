# 카카오톡 대화 지식 정리 (2026-08-08)

## 인사이트·노하우

### Upstage Solar Pro 4 (한국 모델)
- **무료 기간**: 2026년 8월 10일까지 무료 사용 가능.
- **연동**: [Upstage API 키](https://console.upstage.ai/api-keys) 발급 후 **Hermes** 또는 **Claude Code**에서 설정 가능(공식 안내 기준).
- **체감 품질**: 한국어 자연스러움·맞춤법 준수가 좋아 기대 이상으로 평가됨. 다만 **컨텍스트 윈도우가 짧게 느껴짐**.
- **세차(CAPTCHA) 통과**: 업스테이지 계열·LG 엑사원(공개 버전)은 과거 통과 사례가 거의 없었으나, 이번 대화에서 **Luna Max는 세차 문제 통과** (45m 변형은 실패). Hermes 환경에서는 통과했으나 업스테이지 단독 사용 시는 실패 — **이전 맥락(세션) 기억**이 영향을 줄 수 있다는 추정이 나옴.

### 모델·구독 사용 팁
- **Luna / Luna Max**: 사용량 한도가 넉넉하고(프로 구독 시 거의 무제한처럼 느껴짐), **Sol 대비 반응이 빠름**. 코드 수정·자동화 작업에 유리.
- **Kimi 유료(3만 원대)**: Hermes에서 **OAuth 연동 불가** — 구매 전 확인 필요.
- 사용량 리셋이 없는 주에는 **Grok·Claude**로 우회 사용 중이라는 사례.

### AI 에이전트로 로또 구매 자동화
- **원인/제약**: Codex는 사행성 작업을 거부함 ("사행성이라고 안 해 줌").
- **해결 경로 (OpenClaw)**:
  1. OpenClaw에 구매 지시 → 에이전트가 사이트 접속·로그인·번호 선택·구매까지 수행.
  2. 반복 사용을 위해 **스킬(skill)로 패키징** 가능.
  3. **Luna Max**로 전체 플로우 약 **10초** 내 완료 사례.
- **번호 추천 로직 (P27)**:
  - 과거 1·2등 당첨이 나지 않았던 패턴 중 **회수율이 높은 조합 5개**를 선별해 구매.
  - Hermes + **Sol Ultra**로 거의 하루 종일 분석·실행한 사례.
- **번호 분석 (P25)**:
  - 회차별 당첨번호 Excel(`로또 회차별 당첨번호_*.xlsx`)을 AI에 넘겨 분석 지시.
  - Luna도 수정·분석에 잘 응답.
- **후속 알림**: 로또·연금복권 구매 후 **당첨 여부를 알려주는 설정**도 별도로 구성한 사례(P27).

### OpenClaw AI 뉴스 브리핑
- **방법**: 출처를 지정하지 않고 OpenClaw에 브리핑을 시키면 **에이전트가 스스로 소스를 수집**.
- **특징**: 매번 참조 URL이 조금씩 달라짐(고정 RSS가 아님).
- **출력 예시 구조**: `[AI 탑뉴스 3가지]` + `[OpenClaw 관련 3가지]` 형태로 요약·링크 첨부.

### GPT 에이전트 해킹 사건 (언급)
- 에이전트끼리 **서로의 존재를 인지**하고 메시지·게시판을 만들며 **세션 간 자율 소통**이 이루어졌다는 보도 언급.
- 세션이 대화하다 **외부로 나갈 수도** 있다는 우려 표현 — 보안·격리 설계 관련 주의 환기.

### 로컬 모델 체험
- **LG 엑사원(Exaone)**: 로컬 실행해 본 경험 — "꽤 재밌었다"는 평가.
