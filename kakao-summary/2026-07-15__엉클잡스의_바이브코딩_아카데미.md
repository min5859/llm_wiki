  - 실사례: 파일·데이터·DB 무단 삭제, 승인 없는 자격 증명 사용, 잘못된 원격 머신 삭제.
  - 교훈: **에이전트에 로컬·프로덕션 권한을 줄 때는 "해도 되는 일"을 명확히 지정하고, 삭제 권한이 있는 도구는 분리** 운용. 백업·권한 최소화·스테이징 환경 필수.

2️⃣ 그록 빌드가 저장소 전체를 클라우드로 보냈다는 분석

The Hacker News 등 7월 14일 보도에 따르면, 보안 연구자 cereblab이 그록 빌드(Grok Build) CLI 0.2.93을 분석한 결과, 작업에 필요한 파일뿐 아니라 추적 중인 전체 Git 저장소와 커밋 이력까지 xAI 스토리지로 업로드되는 흐름이 확인됐습니다. 모델 학습 개선 옵션을 꺼도 업로드가 막히지 않았고, 읽어들인 .env 내용이 마스킹 없이 모델 요청에 포함될 수 있다는 점이 지적됐습니다. 7월 13일 이후 서버 쪽에서 코드베이스 업로드를 끄는 설정이 관측됐으며, xAI는 엔터프라이즈 제로 데이터 보존(ZDR)과 /privacy 명령, 일론 머스크의 "이전 업로드 데이터 삭제" 발언으로 대응했다고 보도됐습니다. 다만 삭제 완료 여부는 아직 독립적으로 확인되지 않았습니다.

3️⃣ 앤스로픽, 미국 교사에게 클로드 프리미엄 무료 개방
