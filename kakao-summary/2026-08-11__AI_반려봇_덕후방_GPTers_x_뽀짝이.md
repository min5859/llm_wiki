## 인사이트·노하우

### 주간 사용량(토큰) 리셋 주기
- 당일(8/11) 아침에 **주간 사용량이 리셋**됨. 참가자들은 리셋 직후·직전에 사용량을 소진하거나 아껴 쓰는 패턴을 공유.
- **「리셋권」**은 대략 **매주 13일 새벽**에 맞춰 주는 것으로 보이며, **8/13이 마지막**일 수 있다는 언급이 있음.
- 실사용 비율 공유: 리셋 시점에 **29%**, **55%** 사용 후 초기화 등 — 스터디 일정 때문에 남겨두는 경우도 있음.
- **교훈**: 리셋 전에 토큰을 많이 남기면 아까움. 반대로 **Ouroboros·Autoresearch** 같은 루프형 하네스는 개인 구독 토큰으로 크게 돌리면 **주간 한도가 금방 0%**가 됨 → 방학·여유 사용량이 있을 때 밀린 테스트 등에 **가끔** 쓰는 식이 현실적.

### Ouroboros (에이전트 루프 하네스)
- **소크라테스식 인터뷰**(여러 질문) 후 **루프**를 돌려주는 하네스.
- **기획·테스트·개발**을 연속 위임 가능. 막막할 때 유용하지만 **토큰 소모가 큼**.
- 개인 구독에서는 Autoresearch와 함께 대규모 실행 시 주간 한도를 빠르게 소진.

### OpenClaw만으로 유튜브 숏츠 제작 (생성형 영상이 아님)
- **원인/오해**: 「GPT로 영상이 가능했나?」「Codex가 가능한가?」 — 생성형 영상 API(Sora 등)를 쓴 것이 **아님**.
- **실제 방식** (P6 정리):
  - 가상 화면을 백그라운드에서 띄우고 **렌더링 후 녹화**하는 방식 → **화면 녹화와 유사**.
  - 영상 개수·길이가 많아도 **무료**로 제작 가능 (생성형 영상과 다름).
  - GPT·Claude 등 **어떤 에이전트든** 같은 방식으로 가능.
- **구체적 워크플로** (P1):
  1. 상황·아이디어를 OpenClaw에 전달
  2. OpenClaw가 **이미지 생성 + 자막 삽입**
  3. **윈도우 기본 화면 녹화**로 캡처
  4. 인포그래픽은 인터넷에서 다운로드, 숏츠 아이디어는 인터넷 참고
- **철학**: 「**한계를 미리 설정하지 마세요**」「**일단 시켜보세요**」「**진정한 바이브코딩은 코드를 안 보는 것**」
- 실측: 주간 한도 **2%** 사용으로 다수 숏츠 제작, 조회수 1000 돌파 언급.

### OpenMINIs 활용 (헬스 코칭)
- **PT 쌤** 역할로 사용 중.
- **매일 운동량·활동 데이터**를 가져와 「잔소리」 요청 — 헬스 데이터 연동 활용 사례.
- iPad Air 4·모바일 설치 가능 여부는 대화 중 **미확정**.

### 행사 사진 자동 업로드 + 얼굴 모자이크
- **구글 드라이브**에 사진·주제를 올려두면 **오후 1시 30분**에 자동 업로드.
- 행사 운영 대행 맥락에서 **얼굴 인식 → 자동 모자이크**에 집중 구현.
- **로컬 모델** 사용 시 개인정보 유출 우려를 줄일 수 있다는 조언 (P48).

### Slack 앱 토큰 발급이 극단적으로 단순해짐
- **manifest 붙여넣기만** 하면 **토큰 2개가 즉시** 발급 — 「**5초컷**」「**핵당황**」 수준.
- 약 3개월 전만 해도 설정·강의가 필요했던 것과 대비되어, 과거에 수동으로 했던 사람들이 당황하는 반응.
- 게시판 API 연결 등 후속 작업은 별도.
