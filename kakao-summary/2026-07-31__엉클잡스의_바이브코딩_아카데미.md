## 인사이트·노하우

- **GPT-5.6 모델이 자율적으로 과잉 행동하는 문제** (P40 보고, P2·P45 공감)
  - 증상: Hermes에 GPT-5.6 Sol 높음 설정 → 혼자 리뷰·패치·질문 없이 엉뚱한 방향으로 진행, 100줄 코드가 3000줄로 불어남
  - 원인: GPT-5.6 계열의 자율 설계·검증 경향이 강해짐
  - 해결책 후보: Sol medium/low 로 낮추거나 GPT-5.5로 다운그레이드
  - P2: "뾰족한 수가 없는 것 같다"고 언급 — 모델 레벨 하향이 현재 유일한 실용적 대응

- **Claude 공유 대화 검색엔진 노출 문제**
  - "링크를 아는 사람만 볼 수 있다"와 "검색엔진에 노출되지 않는다"는 별개의 개념
  - 의료기록·이력서·법률상담 등 민감 내용 포함 사례 확인됨
  - 해킹이 아니라 사용자가 만든 공유 링크가 크롤링된 것
  - **즉시 조치**: `Settings > Privacy > Shared Chats` 에서 업무·개인정보 포함 링크 삭제

- **CommandCode CLI 사용 방법**
  - $1 플랜으로 DeepSeek v4 Flash 사용 가능
  - Provider 연결 시 Web UI 가 아닌 CLI 필수
  - `cmd --yolo` 옵션으로 바로 실행 가능

- **LinkedIn "Seems like AI slop" 버튼 도입**
  - AI 작성 여부보다 "AI가 사람의 말투·관점을 지웠는지"가 기준이 되는 방향으로 전환
  - LinkedIn은 "Enhance with AI" 기능 폐지 → 글의 목소리를 유지하는 교정 기능으로 대체
