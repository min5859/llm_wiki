# AI 요약

## 인사이트·노하우

- **Second Claude Code (SCC)**: unclejobs가 AI workflow 전용으로 다듬는 프로젝트. 기존 Claude Code를 포크·커스터마이즈한 형태로 이해하면 됨.
- **Claude Code 5시간 한도 소진 시 이어하기**
  - Claude Code **안에서** 다른 에이전트로 전환하는 방법은 없음 → 별도 터미널에서 다른 에이전트를 열고 이어가야 함.
  - **실용 해법**: 설계·구현·문서화가 잘 되어 있으면, 다른 툴에 컨텍스트를 복사해 붙이면 대부분 이어서 작업해 준다.
  - **같은 세션 내 이어가기**: CCS(Second Claude Code 계열)로 새로 켜고 `resume`을 테스트해 보라는 조언. (확정된 공식 절차는 아니고, 시험 필요)
- **터미널 `pi` 사용 팁**
  - 가볍고 빠르다는 평. extension만 설치한 형태.
  - vision 지원 모델은 **스크린샷** 또는 **이미지 URL**을 주면 읽어 준다. (드래그·드롭 외에 URL 전달도 가능)
  - 맥: `Control+V`로 클립보드 이미지 붙여넣기 가능. (윈도: `Alt+V`)
- **하네스(omp/Omo) 특성**
  - P2 평: "현존 최강 하네스"이지만 느리다. 딥한 작업은 밤에 돌리는 용도.
  - **DAG 플로우**로 작업을 시키면 특히 좋다는 실사용 의견.
  - **비개발·입문자**: 아무것도 모른 상태에서 뭔가 하겠다면 Omo가 훨씬 낫다.
  - **개발·보안·QA 등 개념이 있는 사람**: 어떤 하네스를 쓰든 "그 맛"이 비슷하다. 네이티브 CLI 쪽 선호가 많음.
  - **성향 매칭**: "몇 줄 쓰고 딸깍"을 좋아하고 AI에게 말 많이 하는 걸 싫어하면 → **Omo 네이티브**가 맞을 수 있다. 하네스마다 철학이 달라서 결국 "나는 어떤 인간인가"를 깨닫게 된다는 공감.
  - **입문 권장**: 일단 **네이티브 하네스로 시작**하는 게 맞다는 의견.
- **바이브코더 성장 단계** (P2 정리)
  1. **초보** — 무료 또는 월 $20. 개발 비친숙·AI 입문. 데스크톱앱/앱, Chat → Cowork.
  2. **중수** — 월 $100~200. 생산성 체감, 데스크톱앱 → IDE. VS Code/Cursor에서 Claude Code, 하네스 CLI 찍먹.
  3. **고수** — 월 $200+·API 과금. IDE 포기, 터미널 전주. Herdr로 다중 세션. 하네스를 골라 쓰는 단계.
- **다중 세션 운영**
  - 세션 10개+ 운영 사례: 업무별(광고, 콘텐츠, 쇼핑라이브 기획, 월간 마감, 마케팅 자동화 등)로 세션 분리.
  - **단일 에이전트**면 PASEO도 괜찮지만, **다중 세션**이면 PASEO는 버리고 **Moshi 연동** 또는 **Herdr + Collie** 조합을 권장.
  - **Tailscale** 연동 시 웹으로 세션 확인 가능.
  - 모바일로 10개+ 세션은 눈이 아프다 → 급할 때만 모바일 사용이 현실적.
- **Codex 앱·모바일 조합**: "Codex + 모바일이면 컴퓨터 앞에 앉을 이유가 사라진다" 수준의 호평. 타이핑·복붙이 귀찮으면 **Codex extension**으로 처리.
- **브라우저 원격 조작**: Orca까지 안 가도, **Chrome extension ChatGPT**로 브라우저 use 가능.
- **Claude Code auto mode 기본값 전환 보도** (TechCrunch, 공식 미확인): 기존 프로젝트의 **승인·권한 확인 지점**과 팀 사용 정책을 재점검해야 한다는 실무 변수. 공식 원문 확인 전 보도이므로 주의.
- **대규모 지식 증류** (HF 블로그): 자체 모델 경량화·비용 절감 팀은 재현 조건, 하드웨어, 비용 가정, 라이선스를 원문에서 확인하는 것이 좋다.

## 추천·자료

- **[second-claude-code](https://github.com/unclejobs-ai/second-claude-code)** — unclejobs의 AI workflow 전용 Claude Code 포크. SCC의 정체와 방향을 볼 때.

- **Herdr + Collie** — 다중 에이전트 세션(5~10개+) 동시 운영 시 PASEO 대안.
- **Codex 앱** (+ 모바일) — 컴퓨터 앞에 앉지 않고 작업 이어가기. 생산성 극대화 사례로 여러 명 호평.
- **CLIProxyAPI** — 맥락 불명, "갓" 수준으로 짧게 추천만 등장. API 프록시·멀티 모델 연동 맥락으로 추정되지만 원문에서 용도 미설명 → **불명**.
- **윤자동 AI 강사 모집** — AI 강사 커리어 전환 희망자에게 추천. 평일 풀타임 참여 필요(퇴사·커리어 전환 각오 필요).

## 반응이 커던 화제

- **하네스 비교 (omp/Omo vs senpai vs opencode vs PASEO)** — "뭐가 더 좋다"는 없고 써봐야 알지만, 비개발 입문 vs 개발 경험자·성향(말하기 vs 딸깍)에 따라 갈림. omp 구독·전환 의지도 함께 나옴.
- **다중 세션 운영 (10개+)** — PASEO 한계, Herdr·Moshi·Tailscale 대안, 모바일 불편함까지 실무 토론.
- **바이브코더 성장 단계** (초보→중수→고수, 비용·도구 변화) — "누가 내 일기 써놨니" 반응. 공감·자기 서사와 맞닿아 반응 큼.
- **Codex 앱 + 모바일** — 저녁 시간대 강한 호평, extension·브라우저 use까지 후속.

## 자동화·시스템 적용 후보

- **입문 학습 플로우**: 채팅 → (Codex/Claude) Cowork → Claude Code/Codex → 유명 하네스 찍먹.
- **omp DAG 플로우** — 복잡·딥 작업을 노드/플로우로 쪼개 밤에 돌리는 패턴.
- **업무별 세션 분리** — 광고·콘텐츠·기획·마감·마케팅 자동화 등 도메인별 에이전트 세션 운영.
- **Herdr + Collie + Tailscale** — 다중 세션 모니터링·웹 확인 스택.
- **한도 소진 시 컨텍스트 이관** — 설계/구현/문서를 잘 쌓아 두고 다른 에이전트로 붙여넣기 이어가기.
- **Codex extension / Chrome ChatGPT extension** — 핸드폰·원격에서 타이핑·복붙 최소화.

## 질문·미해결

- Claude Code **내에서** 세션 한도 후 다른 에이전트 전환 → **불가**, 별도 터미널·다른 툴 필요로 정리됨. `/model`은 맥락만 있고 한도 우회 해법은 아님.
- CCS `resume`으로 **같은 세션 이어가기** — 테스트 필요, 확정 절차 아님.
- **gjc**를 Codex 앱에 엮어 쓰고 싶다는 발언 — gjc 정체·연동 방법 **불명**, 답 없음.
- **Orca**와 Chrome ChatGPT extension의 관계·선택 — Orca까지 안 가도 extension으로 브라우저 use 가능하다는 답만, Orca 자체 비교는 미완.
- Claude Code **auto mode 기본값 전환** — TechCrunch 보도만, Anthropic 공식·적용 범위 **미확인**.
- omp가 senpai보다 "좋은지" — 절대 우열 없음, **사용자 성향·개발 지식 수준**에 따른 선택 문제로 수렴.
