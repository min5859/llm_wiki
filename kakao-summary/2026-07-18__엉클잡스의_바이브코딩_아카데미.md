# AI 요약

## 인사이트·노하우

- **파쿠리(ぱくり)** — 일본어로 "복제"라는 뜻. 기존 서비스·UI를 AI로 클론 제작하는 바이브코딩 실천 기법. 강의 참여자들이 "다음날 아침부터 하루종일 파쿠리" 할 정도로 즉각 실전 적용되는 접근.

- **aside CLI + MCP 조합** — aside를 codex 형태 CLI로 붙이면 슬랙·MD 저장 등 기존 워크플로와 그대로 연결되며, 웹에서 본 내용을 즉시 옵시디언으로 지식화하는 용도로도 활용 가능. MCP도 지원.

- **터미널 앱 vs 에이전트 코딩툴 구분**
  - Wave = 터미널 앱 (컨테이너 역할)
  - GJC(가재코드), OMP(Oh My Posh 계열 추정) = 터미널 안에서 돌아가는 에이전트 코딩툴
  - "자기 하네스에 맞는 도구 선택"이 핵심

- **가재코드 핵심 기능 = 딥 인터뷰** — 아이디어가 모호할 때 쓰기 좋음. 매트 폭스킬의 "그릴미독스"도 유사 계열.

- **CCS(Claude Code Shell 추정) 활용** — 여러 모델을 편하게 전환 사용할 때 더 편리하다고 언급.

- **온톨로지 = AI 정리 계약서** — 폴더 구조는 결과고, 온톨로지는 규칙. "무엇을 어디에 담을지 판별 기준을 사람이 직접 적어야 AI도 제대로 정리 가능." 바탕화면 '새 폴더 (2)' 문제가 규칙 부재 때문이라는 비유로 설명.

- **그록 SuperGrok 무료 기간 반복 사용 시 결제 수단 추적 우회** — 동일 카드/결제수단 사용 시 이미 혜택 받은 계정으로 인식되어 재적용 안 됨. 네이버페이 등 다른 결제수단 사용으로 우회 가능하다고 언급.

- **페이블(Fable) 구독 전략 변경** — 기존 개별 구독 다수 → 7월 20일부터 일부 구독제(MAX 계정 포함)에서 사용 가능으로 전환. 이전에 10개 이상 구독한 사람들은 손해 본 구조.

- **코덱스 토큰 주말 리셋** — 토큰 소진 시 주말 리셋이 확인됨. 리셋 타이밍을 워크플로에 맞춰 활용하는 패턴 존재.

## 자동화·시스템 적용 후보

- **온톨로지 기반 AI 정리 시스템** — "규칙(온톨로지)을 사람이 명시 → AI가 판별 기준에 따라 자료 분류" 워크플로. 단순 폴더 정리 위임이 아니라 분류 규칙 문서화가 선행되어야 함.

- **aside CLI + 옵시디언 연동 파이프라인** — 웹 열람 → aside CLI로 즉시 캡처 → 옵시디언 저장. CLI 특성상 기존 슬랙·MD 워크플로와 자연스럽게 연결.
