# AI 요약

## 인사이트·노하우

### 에이전트 보안 — 커넥터 연결 시 권한 관리
- 외부 서비스(캘린더·메일·문서·코드 저장소)를 에이전트에 연결할 때는 **읽기 전용부터 시작**
- 쓰기 권한은 별도 승인으로 분리, 어떤 도구가 어떤 데이터를 읽었는지 기록 필요
- PromptArmor 분석: 6주간 커넥터 2,517개 중 **37%(931개)의 기능이 변경됨** — 연결된 외부 서비스의 도구 노출 범위가 조용히 늘어날 수 있음
  - 예: Dropbox 커넥터가 노출 도구 8→24개, 쓰기 도구 3→10개로 증가

### 에이전트 루프 비용 통제 (LoopGain)
- 장시간 실행 에이전트에 "알아서 끝내겠지" 보다 먼저 넣어야 할 것:
  - 최대 반복 횟수 제한
  - 비용 상한
  - 실패 시 롤백
- 제작자 자체 벤치마크: 반복 20회 고정 대비 API 비용 **92.8% 절감** (독립 검증 미완)

### 화면 녹화 도구 선택
- 무료/오픈소스 한계 → 유료로 가야 할 경우: **Focusee**, **ScreenStudio** (화면 확대 기능 편리)
- 대안 오픈소스: **OBS** (커스터마이징 가능), **Cap** (`github.com/CapSoftware/cap`)
- 1회성 강의 영상 목적이라도 장기적으로는 유료 추천

### AI 모델 조합 활용
- 프론트엔드 Kimi + 백엔드 Claude 조합 가능 (또는 Codex 대체)
- Kimi k3는 코딩 외 글쓰기도 우수하다는 평가

### 리서치 에이전트 평가 기준
- 답변의 그럴듯함 외 추가 확인 항목: 출처 정확성, 누락 여부, 최신성, 반대 근거 처리

### VulnHunter — AI 코드 보안 검사 접근법
- 일반 정적 분석과 달리 **공격자 관점에서 진입점 → 실제 공격 경로 추적 → 수정안 제안** 방식
- 현재 구현은 Claude Opus 4.8 + Claude Code 환경 필요 (Apache 2.0)
- "보안 도구 결과도 자동 승인 금지 — 공격 경로와 수정 내용을 사람이 확인해야"
