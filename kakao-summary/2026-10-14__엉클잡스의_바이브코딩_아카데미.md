오늘의 흐름을 한 줄로 보면, Google은 Gemini 4 Argon을 API와 Gemini app으로 전 세계에 열고 macOS app에 Antigravity를 넣었고, SpaceX Super Intelligence는 Grok·Grok Bot·Cursor·X Premium을 요금제 하나로 묶었어요.

━━━━━━━━━━━━
1️⃣ Gemini 4 Argon, API와 Gemini app으로 전 세계 제공
Google이 한국시간 10월 14일 새벽 Gemini 4 Argon을 개발자와 기업에게 AI Studio와 Gemini platform의 API로 전 세계에 열었어요. Google AI Ultra 구독자는 Google Antigravity에서, Pro와 Ultra 구독자는 Gemini app과 AI Mode in Search에서 쓸 수 있고, 개발자는 Android Studio에서도 Gemini API paid tier로 바로 써 볼 수 있어요. coding, 금융, 법률, 과학처럼 여러 단계를 거치는 깊은 작업을 맡기려는 사람에게 맞아요.
👉 볼 포인트
출시 기념 가격은 입력 100만 token당 2달러, 출력 100만 token당 10달러이고 cached input token은 95% 할인돼요. Gemini API에서는 input과 output을 합쳐 1M token 한도를 지원해요. Google은 내부에서 Antigravity로 Argon을 쓴 뒤 agent가 올린 code 제출이 35% 넘게 늘고 code rollback은 3분의 1 가까이 줄었다고 밝혔어요.
🔗 <https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/>
🔗 <https://blog.google/innovation-and-ai/technology/developers-tools/build-with-gemini-4-argon/>

━━━━━━━━━━━━
2️⃣ Gemini macOS app에 Antigravity, 새 Customize menu
Google이 같은 날 Gemini macOS app에 Google Antigravity를 넣었어요. chat에서 coding agent를 띄우고 계획을 승인하면 agent가 background에서 code를 만들고 test한 뒤 검토할 준비가 되면 알려 줘서, 대화하다가 바로 prototype까지 가고 싶은 사람에게 맞아요. Mac의 Gemini app 위쪽에서 Antigravity를 누르면 시작되고, 개인 Google 계정과 조건에 맞는 업무 계정(18세 이상)에 영어로 제공돼요.
👉 볼 포인트
왼쪽 menu의 Customize에서는 Gemini의 응답 방식을 조정하고 skill과 연결 app을 한곳에서 관리해요. Instacart, OpenTable, Adobe 등 40개가 넘는 app이나 service를 연결할 수 있고, Customize는 web, mobile, Windows·macOS desktop app에서 모든 사용자 등급에 전 세계로 풀리는 중이에요. 연결 app 대부분은 미국의 영어 환경 기준이에요.
🔗 <https://blog.google/innovation-and-ai/products/gemini-app/gemini-4-argon-availability/>
🔗 <https://gemini.google/release-notes/>

━━━━━━━━━━━━
3️⃣ The X Subscription, Grok·Grok Bot·Cursor·X Premium을 요금제 하나로
SpaceX Super Intelligence가 한국시간 10월 13일 아침 공식 X 계정에서 Grok, Grok Bot, Cursor, X Premium을 한 요금제로 묶은 The X Subscription을 발표했어요. Grok은 chat·voice·image와 video 생성, Grok Bot은 일을 처리하는 AI teammate, Cursor는 local과 cloud coding agent, X는 인증 표시와 creator 도구, 광고 감소를 맡아서, 이 중 둘 이상을 따로 결제하던 사람에게 맞아요.
👉 볼 포인트
요금제는 Free(0달러), Plus(월 8달러), Premium(월 30달러), Super(월 100달러), Ultra(월 200달러) 다섯 가지이고, Premium에는 예전에 합쳐서 월 90달러였던 SuperGrok, Cursor Pro, X Premium+ 혜택이 들어가요. 유료 요금제의 Grok model 사용량은 Grok과 Cursor가 함께 쓰는 pool 하나로 묶이고 매주 다시 채워져요. 기존 구독자는 지금 요금제를 유지하거나 billing 설정에서 갈아탈 수 있고, 앞으로 며칠에 걸쳐 전 세계에 순차적으로 열려요.
🔗 <https://x.com/SpaceXSI/status/2109783335296008414>
🔗 <https://x.ai/news/x-subscription>

━━━━━━━━━━━━
4️⃣ Facebook Your algorithm, 보고 싶은 것을 내 말로
Meta가 한국시간 10월 14일 새벽 Facebook Feed와 Reels에서 보고 싶은 주제를 직접 추가하고 관리하는 Your algorithm을 내놓기 시작했어요. 게시물의 점 세 개 menu에서 들어갈 수 있어서, 추천이 마음에 안 들어 계속 넘기던 사람에게 맞아요.
👉 볼 포인트
Interested나 Not interested를 누르면 무엇이 좋았고 싫었는지 추가 질문이 올 수 있고, 내 말로 더 보고 싶은 것과 덜 보고 싶은 것을 적으면 추천이 바로 바뀌어요. Meta는 LLM이 자연어 속 관심사와 맥락, 의도를 읽어 같은 session 안에서도 추천을 실시간으로 조정한다고 설명했어요.
🔗 <https://about.fb.com/news/2026/10/introducing-your-algorithm-facebook/>

━━━━━━━━━━━━
5️⃣ OpenBMB Trident-Qwen3VL-2B, text와 image를 한 목록에서 찾는 embedding model
OpenBMB가 한국시간 10월 12일 저녁 Hugging Face에 Trident-Qwen3VL-2B를 올렸어요. text, image, text와 image를 합친 입력을 하나의 공간에 담는 multimodal embedding model이라, text 질문 하나로 text 문서, image 문서, 둘이 섞인 문서를 한 목록에서 순위 매기고 싶은 검색 system 개발자에게 맞아요.
👉 볼 포인트
Qwen3-VL-2B-Instruct를 Trident-Train data로 fine-tune했고, LoRA adapter가 이미 병합돼 있어 base model이나 PEFT 없이 바로 쓸 수 있어요. Trident 쪽 기여분과 fine-tune weight는 MIT License지만, base model의 Apache-2.0 조건도 그대로 적용돼요.
🔗 <https://huggingface.co/openbmb/Trident-Qwen3VL-2B>
