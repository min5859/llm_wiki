# AI 요약

## 인사이트·노하우

- **Claude 모델 접근 불가 버그**: Plus/Pro 플랜에서 Claude Sol(5.6 Sol)이 CLI·Codex 앱에서 사라지는 현상 발생. Terra까지만 표시되고 Sol 접근 자체가 차단되는 경우 있음. 버그로 추정되나 계정에 따라 아예 접근 불가로 고착되기도 함.
- **주간 사용량 0% 버그**: 울트라 모드로 장시간 돌린 경우 갑자기 주간 사용량이 0%로 초기화 표시되는 버그 목격. 실제 초기화 이벤트와 혼동 가능.
- **Codex Max 모드 CLI vs 앱 차이**: Codex의 `max` 티어는 CLI에는 존재하나 앱(GUI)에서는 표시되지 않음. 200달러 플랜 사용자도 앱에서는 extra high / high / ultra만 보임.
- **Sol 미디엄 추천**: "5.5보다 알잘딸깍센 느낌", "말 잘 알아들어요" — 과한 추론 없이 지시를 잘 따르는 특성. 여러 사용자가 sol medium을 실용적 선택으로 언급.
- **Orca + Gajae Code 조합**: "검증 빡세게 해줘서 너무 좋아요 / 시간이 걸리더라도 제대로 나오는게 중요". cmux 대비 프리징이 적고 안정적이라는 평가. 토큰 소모는 많음.
- **Fable + Opus + Codex 프리셋 조합**: Gajae Code에서 `combo` 프리셋으로 `fable+opus+codex` 또는 `fable+codex`를 사용. deep-interview → ralplan → ultra goal 파이프라인으로 장시간(30시간 이상) 실행 가능.

## 추천·자료

- **[oh-my-pi](https://github.com/can1357/oh-my-pi)**: model provider를 Cursor, Anthropic 등 다양하게 지원하는 도구. 역할(role)을 세분화해서 지정할 수 있는 기능 포함. 역할 정리 작업이 진행 중인 것으로 언급됨.

## 반응이 컸던 화제

- **oh-my-pi 소개**: model provider로 Cursor·Anthropic 등을 지원하고 역할 세분화 지정이 가능하다는 점에서 긍정적 반응. 직후 GitHub 링크와 역할 정리 공유로 이어짐.
- **주간 사용량 초기화 이벤트 반복**: 리셋 이벤트가 예고 없이 반복되면서 "억울한 사람 없게 리셋을 남발하는 느낌"이라는 공감대 형성. 아껴 쓰다 손해 본 사람들의 토로가 이어짐.

## 자동화·시스템 적용 후보

- **Gajae Code 장시간 파이프라인 패턴**: `deep-interview → ralplan → ultra goal` 순서로 연결해 30시간 이상 무인 실행. 리셋권 다수 확보 + 주말 활용 전략과 결합.
- **oh-my-pi 역할 세분화**: 에이전트에 역할을 세분화하여 지정하는 방식 — 다른 멀티에이전트 시스템 설계에 참고 가능한 패턴.
