# AI 요약

## 인사이트·노하우

### AI 모델·도구 역할 분담 (실사용자 경험)
- **기획·설계·UI/UX**: 클로드(페이블)가 더 낫다는 의견이 다수. P20이 “기획·설계는 코덱스, 구현은 Opus 4.6, 검수는 페이블” 워크플로를 물었으나, **반대** 의견이 나옴 — “거꾸로요”(P12).
- **백엔드·워커형 코딩**: 코덱스가 유리하다는 체감(P10). “말 잘 듣는” 작업은 그록(“공 줏어오는 강아지 느낌”).
- **추론이 필요한 구역**: 프론티어 모델이 잘한다는 점은 “어쨌든 증명된 내용”(P12). 다만 체감·말투 선호는 개인차가 큼.
- **유지보수·고객 요구 반영**: 그록이 “최고”(P18) — 월 2,000원 단위 외주 3건 병행 경험.
- **기능 개발**: 페이블 솔(Fable sol) 권장(P18). 설계는 페이블, 구현은 GPT sol xhigh 조합도 언급(P17).
- **그록 API 부재 시**: Kimi API로 대체 사용 중(P12).
- **그록 빌더 vs 일반 그록**: 빌더로 쓰면 “큰일납니다” — “우리 엄마한테 개발 맡기는 꼴”이지만 “엄마가 시키는 건 잘해줍니다”(P18). P10도 그록빌더의 그록은 일반 그록과 다르게 느껴진다고 함.
- **제미나이(Gemini)**: 코딩 시키면 “마음이 아플” 정도(P10). 구독 이미지 생성 퀄리티는 API 대비 떨어져 고민(P17). 다만 **구글 미팅 녹화 셔틀** 용도로는 쓸 만함 — “재미나이는 빼세요”(P18).
- **Agy vs 클로드 소넷**: 동일 문제를 Agy에 시키면 세션 대화기록이 남지 않고 실패, 소넷은 바로 원인 찾음 — “이 정도나 차이가 난다”(P15). Agy는 “부족하지만 조은 친구”, “구글검색은 잘하는”(P23).

### 구독·비용 판단
- **연간 구독 회피 원칙**: “제 1원칙 절대 연간구독을 하지마라 / 제 2원칙 1원칙을 잊지마라”(P10) — 그쫀쿠·카쫀쿠는 예외적으로 탑승.
- **슈퍼그록(SuperGrok)**: 월 30만 원이면 맥미니 구매와 비교 고민(P17). 그록봇은 슈퍼그록에 포함되는지 변화가 빠름 — 무료 체험 정책도 바뀐 듯(P17).
- **그록 사용량 구조**: 그록빌더, 커서그록, 그록봇이 **따로** 잡힘 — 토큰(사용량)이 많은 게 장점(P10).
- **그쫀쿠 경제성**: “돈을 더 번 게 아닙니다. 하지만 연간 300만 원을 아꼈습니다”(P10).
- **zcode 1억 토큰 이벤트**: 매일 수량 소진 시까지 — 팝업은 뜨지만 “오늘 건 끝났다”로 종료(P15, P16). 번개 이벤트 성격.

### 보안 (Claude 세션 탈취)
- **원인**: infostealer가 비밀번호·2FA를 뚫는 게 아니라 **이미 로그인된 브라우저 세션**을 복사해 사용량을 태움.
- **대응**: 해당 계정 로그아웃, 저장된 결제 수단 삭제, 무단 요금 환불(Anthropic 공지). 악성코드가 Claude에서 설치된 정황은 없음.
- **실행 팁**: 브라우저로 Claude 쓸 때 결제 수단 갑자기 사라졌는지 확인 → infostealer 의심 시 **로그인 전 그 컴퓨터부터 검사**.

### 신규 모델·출시 체감
- **Claude Fable 5.1**: 출시 직후 **느리다**는 체감(P12) — “방금 나와서 그런가”.
- **Fable 5.1 가격**: 일반 작업 Fable 5 대비 약 25% 저렴, highly agentic 작업 최대 약 45% 절감, 캐시 읽기 75% 인하($0.25/MTok). 입력 $10·출력 $50/MTok 유지.

- **그록 4.7**: **9/12 출시** 예고(P18).

### 자동화·에이전트 관점
- **Aside + 그록봇**: 그록봇에 Aside 붙여 자동화 실험 중 — “엄마 aside 키고 작업해줘” 수준이지만 점진 개선(P18).
- **Aside 진입장벽**: 브라우저 에이전트화보다 **그록봇으로 인한 라이트 유저 전환**이 더 큰 요인일 수 있음(P10).
- **그록봇 성숙도**: “좋아지고 있습니다”가 정확한 표현(P10). 플러그인 결합 시너지 있으나 아직 성숙 전 — “기대감에 매수했으나 사용감은 제가 맛본 툴 중 최고라 아주 기대”(P10).

### 업계·전략 관찰 (참고 수준)

### 프롬프팅·도구 선택 일반론
