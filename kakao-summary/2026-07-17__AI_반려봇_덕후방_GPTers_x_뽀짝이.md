# AI 요약

## 인사이트·노하우

### 헤르메스 실시간 웹훅 연동 (n8n 우회 패턴)
- **문제**: 헤르메스 단독 웹훅 세팅은 인증·포트·라우팅·터널 설정이 복잡
- **해결**: 이미 쓰던 **n8n의 SSH 노드**로 우회해 간소화
- **추가 포인트**: 헤르메스가 도커 컨테이너로 보호돼 있어 **서버가 아닌 컨테이너에 직접 명령**을 넣어야 호출 성공
- **운영 구성**: 호스팅어 VPS 상시 구동 → 개인 PC 없이 24시간 신호 대기·자동 응답 에이전트 운영
- **실전 데모**: 탈리 폼 제출 → 웹훅 수신 → 헤르메스가 CRM 정보 정리 + 이메일 초안 자동 생성

### OpenClaw + GPT-5.6 연동
- 5.6이 "오래 일하는" 특성으로 오히려 OpenClaw 환경이 더 적합하다는 실사용 소감
- **Codex 환경**에서는 5.6이 잘 동작함
- 즉각적인 작업에는 5.5가 나을 수 있고, 5.6은 "조련(잡도리)"이 필요하다는 평

### 클라르나 AI 부메랑 사례 (실패 교훈)
- 2024년 AI 챗봇 1개 = 상담원 700명 대체 발표 → 1년 만에 철회
- 원인: 화난 고객 대응 실패 + 환각으로 수수료·환불 정책 거짓 안내 → 고객 만족도 급락
- 결과: 사람 재채용, 재채용 비용 + 높아진 연봉 요구로 더 비싼 값을 치름

### 포드 품질검사 AI 대체 실패
- 숙련 엔지니어의 미세한 품질 감각은 **문서화·매뉴얼화가 불가능** → AI 학습 데이터 부재
- AI 품질검사 도입 후 리콜 급증 → 숙련 엔지니어 350명 재채용으로 리콜 비용 절감
