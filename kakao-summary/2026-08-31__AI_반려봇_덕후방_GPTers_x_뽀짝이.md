# 카카오톡 대화 정리 — GPTers x 뽀짝이 (2026-08-31)

## 인사이트·노하우

### Codex 사용 한도·리셋
- **5시간 세션 한도**가 Plus와 Pro 사이의 실질적 업그레이드 동인으로 체감됨. 문서 작성만으로 42% 소모, 제미나이로 동영상 2개·사진 3장 제작에 45% 소모 등 사례 다수.
- **리셋 타이밍**: 8/31 오전 10~11시경(실제 초기화는 11:26 전후) 관측. 주말에도 리셋이 잦고, “내일 리셋 예고” 소문도 있음. **티보형 인저리타임**(시간대 차) 때문에 정확한 시각은 사용자마다 다를 수 있음.
- **한도 소진 시**: 자동으로 **루나(Luna)** 모델로 전환됨.
- **요금제별 차이**: Pro 유저는 한도가 다르게 느껴짐. 일부는 5.3 spark만 제한, Pro 20x는 리셋 확인.
- **모델 선택 팁**
  - **울트라 ≠ 더 똑똑함**. “에이전트 사용”·속도 목적. 어려운 작업은 문서상 **맥스(Max)** 권장.
  - 한도를 빨리 쓸 때: 울트라로 병렬 작업, 완료된 건 일반 세팅으로 복귀.
  - 한도 1자릿수일 때 fast 끄는 등 타이밍 조절.
- **리소스 과부하**: 터미널·클로드·IDE·피그마에 울트라·맥스 동시 가동 시 PC 멈춤 → **리소스 모니터링을 요청**하며 돌리는 것이 실용적.
- **실사용 예**: sol high fast로 비트코인 자동매매 개선 — 명령 한 번에 12% 소모, 에이전트가 전략 검증·불량 전략 경고까지 수행.

### OpenClaw vs Hermes — 병행 운영 패턴
- **정답 없음**. 입맛에 맞게 여러 마리 키우는 경우가 많음.
- **P12 패턴**: OpenClaw + Codex(평상시 업무·조사), Hermes + Claude(실행). PC 한 대에 둘 다 설치, **텔레그램**으로 사용.
- **P16 패턴**: 둘 다 씀. 업그레이드·장애 시 **반대쪽 에이전트로 서로 고침** — “오픈클로로 헤르메스 고치고, 헤르메스로 오픈클로 고치고”.
- OpenClaw 헤르메스에는 울트라 개념 없음 → 서브에이전트로 처리량을 늘리는 쪽.

### AI 영상 제작
- 곡성 숏츠: **드론 촬영 + AI 편집 + 수제 편집** 혼합. 해당 공간은 공사로 당분간 사용 불가 → 워케이션 세부 변경 공지 예정.
- 고비용 **플로우(Flow)** 대신 저렴한 AI 자동화 대안을 쓰는 사례. 9월 플로우 크레딧 생기면 재도전 예정.
- 제미나이 vs GPT: 동영상 2개에 제미나이 5시간 한도 45%, GPT는 주간 2% — 용도별 소모량 차이 큼.

### 카카오톡·에이전트 연동
- 카톡방에 에이전트 넣기: **가능하나 험난한 길**. 뽀짝이(OpenClaw)는 **슬랙 전용**, 카톡은 불안정.
- 경로: **카카오cli** → **에이전트메신저**로 갈아탄 사례(불안정하다고 언급).
- **Aside 실험용 카카오톡 스킬**(macOS): 채팅방 목록·대화 내역·키워드 검색 가능, **메시지 전송 불가**. 전체 디스크 접근 권한 필요, **시크릿 모드 미지원**. Windows 버전은 “곧” 예고.

### 그록(Grok) 봇
- 요금제 인하 후 **파일 전송이 안 되는 경우** 발생(예전에는 됐음).
- 슈퍼그록헤비는 영상 대량 제작이 아니면 과비용.
- 웬만한 요금제에서 기능 사용 가능하다는 관측.

### 오프라인 해커톤·모임
- OpenAI 게임 해커톤: **콘센트 부족**이 반복 이슈.
- 실전 준비물: **멀티탭·핫스팟·대용량 배터리** — 맥북은 배터리만으로는 금방 소진.

### 기타
- 긴 Codex 작업 돌리는 동안 **NAS 데이터 정리**를 에이전트에 맡기는 활용 사례.
