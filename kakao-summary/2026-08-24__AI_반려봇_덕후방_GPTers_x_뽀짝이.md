## 인사이트·노하우

### Claude/Codex 사용량 리셋 타이밍
- **혼선**: "터보형(티보형)"이 초기화해 준다는 말과 실제 리셋 시각이 맞지 않아, 월요일 vs **화요일 새벽 6시** 설이 오갔음.
- **0% 이후에도 작업 지속**: 한도가 0%로 표시된 뒤에도 이미 돌아가던 작업은 멈추지 않고 계속 진행됨(예: Sol 모델로 30분 이상, 1/5 단계 표시와 별개로 구동).
- **리셋 후 주의**: 리셋 직전에 "리셋권"을 쓰면 낭비 — 실제로 오전 9시대경 리셋 완료 보고가 여럿 있었음.
- **이중 리셋 없음**: 운영 측 확인으로 "추가 초기화는 없다"는 답이 있었음.

### Claude 서버 장애(529) 대응
- **원인**: [status.claude.com](https://status.claude.com/) 기준 529(서버 과부하)가 오후에 집중 발생.
- **증상**: 일부 모델/계정만 먹통, **Opus 4.8·Sonnet 5는 동작**하는 사례 보고.
- **시도→완화**: 장애 중에는 **"please continue"를 반복 전송**하는 수밖에 없다는 실무 팁.
- **부수 효과**: 서버 과부하 당일 사용량이 비정상적으로 빨리 소진됐다는 체감 다수 — "장애 났으면 토큰 리셋해 달라"는 반응도 있었으나 공식 보상 여부는 불명.

### OpenClaw로 ERP 입력 자동화(제조·구매 실사용 사례)
- **적용 범위**: 사내이동 자재, 구매, 거래명세서 OCR→ERP 입력, 현장 자재불출, 품목등록, 일부 생산입고.
- **왜 OpenClaw인가**: API로 안 되는 항목을 **웹 UI 조작**으로 처리해야 해서 선택. UI가 바뀌어도 **어느 정도는 적응**한다고 함.
- **연동**: 바로빌 등 외부 업체 API로 **세금계산서·통장·카드내역** 연동 가능하다는 경험 공유.

### Odoo 도입 관련 실무 정보
- **한국형 모듈**: Odoo는 오픈소스이지만, **한국 지사·파트너가 판매하는 유료 모듈**로 로컬라이제이션(세금계산서 등)이 가능할 수 있음 — 전부 처음부터 커스터마이징은 아닐 수 있음.
- **세금계산서 모듈**: `l10n_kr_etax_invoice`(Odoo 19) — **$200(서버 1 copy 설치금 추정, 월 구독 아님)**. 세금계산서 **프린팅 기능은 모듈 설명에 없음** → 미팅 시 확인 필요.
- **원가·재고**: 표준 모듈로 어느 정도 구현되는지는 **파트너 미팅에서 확인 예정** — 회계 실무자 입장에선 "다 만든다"는 부담이 큼.
- **SAP 경험 없는 당사자 조언**: "왠만한 건 다 만드셔야 할 겁니다" + 한국형 모듈 사면 **딸깍** 가능할 수도.

### Aside(크롬 AI 에이전트) 로그인·과금 함정
- **자동 구독 로그인은 아님**: 설치만 했는데 Claude 구독으로 붙은 것처럼 보였으나, 실제로는 **로그인을 까먹었거나 다음·다음으로 연결한 경우**가 많음.
- **반례**: GPT 구독 연결된 줄 알았는데 **Aside 무료 티어만 소진**하고 있었던 사례.
- **확인 방법**: 사용 시 **프로바이더 아이콘**에서 어떤 계정/티어를 쓰는지 선택·확인 필요. "너무 편해서 다음다음 누르면 되는 수준"이라 놓치기 쉬움.

### Grok 봇 + 카카오톡(맥)
- **동작 방식**: Grok 봇 플러그인이 카카오톡 지원. **macOS Accessibility API** 사용.
- **조건**: 맥에 **카카오톡 로그인 상태**에서 동작. 포커스를 가져가지 않고 메시지 전송 가능.
- **체감**: 답변이 매우 빠름(헤르메스 대비 "정신이 좀 없다"는 표현).

### AI 구독·모델 선택 전략
- **"최강" 조합**: GPT Pro + Claude 각 **$200** — 다만 "디지털 월세" 부담 큼.
- **비용 절감 방향**: **OMP + AGENTS.md** 잘 만들어 두고 **워커는 싼 모델**; Luna 등 저가 모델을 **적재적소**에 배치; **advisory 전략** 상시 사용(아직 표본 적음).
- **로컬 실험**: Qwen 3.8 27B vs GPT 5.6 하네스 비교 중 — 프론티어 대비 **80% 수준은 아직 실사용 어렵다**는 평가.
- **딥시크**: API 가격 대폭 인상 후 Luna와 비슷한 가격대로 형성된 듯.
- **그록**: 빠르고 프로모션 많음(슈퍼그록 $10, 헤비 $100 느낌 vs 정가 $300). 개발용 평가는 갈림 — 이미지·영상엔 만족, 코딩은 Codex 유지하는 사례.

### ERP × AI 전망(채팅 내 합의·대립)
- **소멸론**: ERP 자체가 사라지기보다 **입력을 에이전트가 대신**하거나 ERP가 **에이전트에 내재화**.
- **유지론**: 정합성이 증명된 ERP를 버릴 이유 없음. 대신 **Odoo·ERPNext 같은 모듈형 ERP** 매력 상승 — 비즈니스별 미묘한 로직을 **바이브 코딩**으로 손쉽게 확장.
- **회계 현장**: 조직이 보수적이라 **기존 ERP가 오히려 편하다**는 체감도 있음.

### Aside 세미나 실사용 후기(요식업)
- 발주 데모는 끝까지 자동 주문까지는 아니었으나(**결국 주문은 수동**), **배송비 절약 쿠폰 적용** 등 이전보다 편리하고 시간·비용 절감 체감.
