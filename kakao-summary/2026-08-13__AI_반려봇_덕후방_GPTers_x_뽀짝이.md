### 맥미니 256GB 용량 확장
- **외부 SSD + 독(인클로저)**: 40Gbps 인클로저면 SSD 풀 속도 커버 가능. 1년 이상 문제없이 사용한 사례.
  - 예외: **iOS 개발 관련 파일은 외장 SSD 저장 불가** (macOS 제약).
  - OS·프로그램을 외장에 두지 않는다면 USB 역할로 충분.
- **내부 SSD 교체(분해)**: 외부와 동일 성능을 맞추려면 외부가 더 비쌈. 직접 작업 시 **마이그레이션** 필요.
- 결론 방향: 성능 동일 + 비용·작업 난이도를 함께 보면 외부 vs 내부 선택이 갈림.

### 육아 중 원격 개발 — Tailscale
- 집 PC는 못 켜고, **회사 원격 PC를 핸드폰으로 명령**.
- 회사망: 주니퍼 사용, 원래 원격은 **Palo Alto** 필요 → **Tailscale**로 우회·해결.
- "테일스케일 만세" — 육아·원격 업무 병행 시 강력 추천 경험.

### Hermes 에이전트에서 Claude CLI
- **구독 계정으로는 연결 불가** — 헤르메스에서 클로드를 안 쓰는 주된 이유.
- 우회 소문: "클로드 코드인 척" 인증으로 호출은 된다는 말 있으나 **약관 위반·계정 차단 위험**.
- 실무적 결론: 차단 감수해야 가능.
