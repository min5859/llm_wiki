# AI 요약

## 인사이트·노하우

- **AI 인터랙티브 게임을 짧은 시간에 만든 사례**: GameBuilders Seoul AI 모델을 활용해 우로보로스(Uroboros)와 어사이드(Aside)로 게임플레이 목표의 게임을 제작. 총 36시간 안에 완성했지만 실제 작업은 약 15시간. 거의 코덱스(Codex)만으로 AI와 상호작용하는 게임을 처음 만들었다는 맥락. 완성도는 낮지만 벼락치기·AI 인터랙티브 측면에서 만족.
- **제출본 vs 로컬 버전**: 제출본은 루나(Luna)가 인터랙트하고, 로컬(non-AI) 버전도 별도 존재. 여러 스테이터스(status)를 넣은 심시티(SimCity) 느낌의 구조.
- **사내 세미나에서 바이브 코딩 소개 시 주의점**: 배포는 보안성 검토 이슈가 있어 「배포해보시라」 식 권유는 피하고, 사내 정책 관련 언급만 하는 편이 안전. 실무 데모 아이템 예: 녹음 → 회의록, 열람용 HTML 보고서, 웹 자료 수집.
- **카카오톡 로컬 DB 추출**: Mac에서는 카톡 로컬 DB를 긁어 추출하는 GitHub 도구가 있다. LOCO 같은 걸 건드리지 않아 정지 확률이 거의 없다는 경험담.
- **개인용 카톡 요약 파이프라인 제안** (원인→시도→해결 흐름):
  - 목적: 개인용도로 카톡 내용 주기적 요약
  - 시도: PC 켜놓고 DB를 cron으로 긁어와 summary 후 터미널로 출력 → 텔레그램으로 전달
  - 서비스화 시: 카카오톡 TOS 위반 가능. 최근 카톡 블록 사례·TOS를 Codex에 조사·정리(`md` 출력)하라고 ask하는 방식이 제안됨
- **어사이드 vs 코덱스 컴퓨터 유즈**: 어사이드는 브라우징이 더 낫긴 하지만 토큰을 더 빨리 소모한다.
- **코덱스 5시간 세션 한도**: 5시간 한도 때문에 당장 작업이 어렵다는 공통 불만. 대응으로 세션 6개를 열어 병렬·분산 사용하는 사례도 언급.
