# AI 요약

## 인사이트·노하우

- **AI 에이전트 비용은 모델 선택보다 메모리 설계가 좌우**: 전체 대화 로그를 매번 재전달하는 방식은 토큰 소비가 급증. 권장 구조: 핵심 정보만 요약 저장 → 완료 작업은 장기 기록으로 분리 → 실행에 필요한 정보만 재로딩.
- **MCP·AI 에이전트 보안 취약점 (2026-07)**: PraisonAI(CVE-2026-61447)는 LLM 생성 Python 코드를 샌드박스 없이 실행 → 프롬프트 인젝션으로 환경변수·API Key 유출 가능. AstrBot MCP(CVE-2026-15501)는 SSRF 취약점. 점검 체크리스트: 최신 버전 업데이트 / API Key 교체 / 최소 권한 적용 / 외부 네트워크 접근 제한 / 코드 실행 환경 샌드박스 적용.
- **AI 금융 조언 한계**: "말이 매끄럽다"는 것과 "내용이 정확하다"는 것은 다름. AI는 금융 개념 설명·상품 비교·전문가 질문 작성·약관 용어 정리에 적합. 투자·세금·대출·연금처럼 되돌리기 어려운 결정은 전문가 검토 필수.
- **LinkedIn 긴 글의 41%가 AI 생성**: AI 작성 자체는 이미 차별점 아님. 직접 경험한 사례·실측 수치·실패 과정·나만의 판단이 포함된 콘텐츠가 경쟁력.
- **Claude Code 외주 → 직접 개발 전환 사례**: 초기 외주로 시작한 서비스를 Claude Code 학습 후 직접 개발로 전환한 창업자 사례 언급(국세청 연동 절세 플랫폼).

5️⃣ AI 에이전트 비용은 모델보다 메모리 설계가 좌우

AI 에이전트는 계획, 검색, 도구 호출, 검증을 반복하기 때문에 일반적인 챗봇보다 토큰 사용량이 빠르게 증가합니다.

❌ 좋지 않은 방식

핵심 정보만 요약해서 저장
