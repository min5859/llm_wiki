# AI 요약

## 인사이트·노하우

- **AI 에이전트·외부 도구 연결은 새로운 보안 경계**  
  로그인·비밀번호·“나만 볼 수 있습니다” UI 표시만으로는 실제 데이터 흐름을 보장할 수 없다. 앱 내부(리버스 엔지니어링 관점)를 보면 다루는 데이터·외부 전달 범위가 달라질 수 있다.
- **“편리하게 연결했다” 자체가 리스크**  
  AI 에이전트와 각종 도구를 연결해 쓰는 시대에는, 연결의 편리성이 곧 새로운 보안 경계가 될 수 있다는 관점이 강조되었다. (에이전트·MCP·외부 API 연동 설계 시 검토 포인트)
