## 인사이트·노하우

### 초기화권(리셋권) 지급 차이
- **플러스 요금제** 사용자 중 일부는 초기화권 **2장**을 받았고, 일부는 **미지급**.
- 미지급 사례(P26): **Cursor를 메인**으로 쓰고, Comfy 등으로 **Codex도 병행** 사용 중 → 지급 기준이 사용 패턴·메인 도구와 연관될 수 있음(원인은 대화에서 확정되지 않음).
- 초기화권은 소진 속도가 빠르다는 체감이 있음 — *"두장 순삭"*.

### Codex 대체·병행: OpenCode Zen + Muse Spark 1.3
- **원인**: Codex 크레딧이 빠르게 소진됨.
- **대안**: OpenCode Zen에서 **Muse Spark 1.3** 무료 사용.
- **체감 성능**: Grok 4.6과 비슷해 보인다는 평가.
- **캐시**: 캐시히트 **65%** 수준(대화 중 언급).
- **환경별 체감 차이**:
  - **Pi에 얹으면** 나을 것 같다는 의견.
  - **딥시크 하네스**에서는 그닥 — 속도 때문에 쓰는 용도라는 맥락.
- **GLM 5.3 f**: P40이 엉클잡스의 사용 여부·품질을 물었으나, 대화에서 직접 답변·평가는 없음.

### Astra — 실사용 후기 및 기능 변화
- 체감이 좋아 **리셋권을 소진**했다는 후기.
- 달라진 점(정리자 요약):
  1. **Async tool calling** — 도구 실행 중 AI가 다른 일도 병행.
  2. **Mid-turn steering** — 응답이 끝나기 전에도 지시 변경 가능.
  3. **Configuration update** — 기존 캐시 유지하며 추론 강도 변경.
  4. **Misalignment monitoring** — 위험 행동 감지 시 후속 실행 차단.
  5. **Instruction following** — 지시 준수 개선, 대신 확인·질문도 늘어남.
- 글쓰기: 챗에서 **「아스트라」**라고 하면 글쓰기가 개선된다는 권장.

### 피싱·사칭 주의
- **원인**: 엉클잡스 사칭 DM·링크(스레드 공유 URL 관련).
- **확인된 사실**: 엉클잡스는 **개인적으로 그런 DM을 보내지 않음**.
- **대응**: 링크 **절대 클릭 금지** — *"카카0"* 등 사칭·피싱 언급.
- **일반 주의**: 사칭자 이름(예: 김서현)은 임의로 붙일 수 있어 신원 추측은 무의미.
