## 인사이트·노하우

### Codex 리셋·리셋권
- **아스트라 도입 전**: 코덱스는 아스트라가 들어올 때까지 **매일 리셋권 1장**을 준다는 안내가 있었음. **월요일 오전 자동 리셋**도 별도로 존재.
- **아스트라 도입 후**: 아스트라가 들어오면 **리셋권 지급이 중단**됨(실측). 다만 아스트라 출시 직후 일부는 **리셋권이 추가로 1장 더** 주는 것처럼 보였고, **순차 적용**이라 사람마다 시점이 달랐음.
- **플랜 업그레이드**: Plus → Pro(×20) 업그레이드 시 **Pro 수준의 초기화(리셋)가 적용**된다는 확인(직접 경험 + 전해들은 사례). 업그레이드 직후 한도가 초기화되는 사례도 있음.
- **운영 팁**: 리셋권은 “15% 남았을 때 쓸지, 자동 초기화를 기다릴지”를 **한도·주간 리셋 시점**과 맞춰 계획적으로 쓰는 게 낫다는 공감.

### GPT-6 ASTRA 가용성·연동
- **구독 등급**: Plus에서는 선택이 안 보이고, **Pro 이상**에서 선택 가능해 보인다는 공유.
- **Hermes vs OpenClaw (신모델 반영 속도)**  
  - Hermes: 새 모델이 나오면 **선택창에 바로 노출**.  
  - OpenClaw: 기존처럼 **확인 후 업데이트**해야 등록되는 흐름. 공식 패치 전에는 **언노운모델(연결 실패)** 가능.
- **OpenClaw에서 아스트라 쓰기**  
  - 8.1에서는 실패 → **9.1 아침 업데이트** 후에도 공식 패치 필요해 보임.  
  - **로컬 패치로 밀어 넣는 건 가능**하나 번거롭다는 실측.  
  - 공식 지원 전에는 **솔(GPT)에게 강제 인식**시키는 우회도 시도됨(비공식).
- **OMP에서 Astra가 “free”로 보임**: 버그가 아니라 **공식 카탈로그에 가격이 아직 등록되지 않아** 그렇게 보이는 것으로 추정.

### ASTRA 성능·사용량(실측 후기)
- **토큰 소비**: Codex 20, **Astra High Fast**, 약 **30분 작업 → 주간 한도 7~8%** 소모 사례. “알잘딱은 좋아졌는데 토큰은 많이 쓴다”는 공통 인상.
- **체감 성능**:  
  - “페이블보다 **프론트 빼고는 모든 면에서 좋아진 듯**”  
  - 작문·말투가 나아지고 “**박사급 지능을 가진 인턴**” 같은 인상  
  - **Computer use(화면 조작)** 속도가 빨라졌다는 언급  
  - 프론트엔드/UI 작업은 여전히 약하거나 “???? 거린다”는 후기도 있음
- **강점 맥락**(요약 인용): 단발 질문보다 **브라우저·데스크톱을 오가며 여러 단계를 끝까지 밟는 긴 작업**, 장기 실행·오케스트레이션, 대규모 코드베이스 분석 등에서 반복적으로 가치가 확인된다는 정리가 공유됨.

### OpenClaw 멀티스텝·에이전트 연계 문제
- **현상**: 여러 단계 작업을 시키면 “다음 단계를 실행하겠다”고 답한 뒤 **실제 도구 호출 없이 턴 종료**가 반복됨. `AGENTS.md`에 후속 실행·완료 검증을 강제해도 개선 안 됨.
- **환경**: **GPT Sol** 사용 시, **에이전트 간 작업 연계** 때 특히 두드러짐. Hermes에서는 덜한 것 같다는 비교.
- **원인 추정**: LLM·모델별 차이 가능성. 멀티에이전트를 안 쓰면 덜하다는 사례도 있음.
- **우회·디버깅**  
  1. 텔레그램에서 멈춘 것 같으면 **“지금 어떻게 되고 있냐”고 물어보면 다시 작업**하는 경우가 있음.  
  2. 텔레그램에서 **`/verbose on`** → 작업 중 표시가 나와 상태 파악이 쉬움.  
- **미확정**: TaskFlow·hook·watchdog 등으로 **후속 실행을 보장하는 공식 권장안**은 대화에서 확정되지 않음.

### OpenClaw로 디스크 정리 시 주의
- **실패 사례**: 맥 용량 부족으로 OpenClaw에게 용량 정리를 맡겼더니 **Hermes 설치가 깨짐**.
- **권장 패턴**: “지울 만한 것 **리스트를 달라**” → **사람이 선택해서 삭제**. 에이전트가 일괄 삭제하도록 맡기지 않기.

### 카카오톡 채널 × OpenClaw
- 채널 응대를 OpenClaw 에이전트에 맡기는지에 대한 질문이 있었으나, **실제 운영 사례·안전 가이드는 대화에서 정리되지 않음**(불안감 공유 수준).
