## 인사이트·노하우

### GPT Pro 구독 — 카카오 결제 경로
- **상황**: OpenAI 공식 경로에서 GPT Pro 구독이 막힌 상태였음.
- **해결**: 카카오(카톡) 경로로 결제 가능했고, 실제 구매·사용 사례가 있음.
- **중요**: 카톡 전용이 **아님**. 카카오에서 구매한 구독도 **OpenAI 공식 사이트에서 그대로 사용** 가능 (당사자 확인: "카카오에서 구매한거 잘 쓰고 잇습니다").

### 가격·플랫폼 차이 (2026-09-11 당일 실측 언급)
- Android 쪽 구매가 **약 31** (단위·통화 불명 — 대화 맥락상 원화일 가능성) 수준으로 언급됨.
- iPhone vs Android **가격 차이**가 있어 보임 ("안드로이드가 더비싼가봅니다" / "저도 안드로로 31에 구매").
- 막힌 상태에서 **급히 필요하면** 카카오 경로로 우선 구매한 사례 있음.

### OpenAI 2026-09-10 발표 묶음 (뉴스 브리핑 요약)
같은 날 아침에 업무·API·음성·데이터·안전 연구가 한꺼번에 나온 흐름:

| 발표 | 핵심 |
|------|------|
| ChatGPT for Financial Services | ChatGPT Work + 금융 데이터(GPT-6 Astra). Morgan Stanley·Evercore 설계. Daloopa·PitchBook·LSEG·Crunchbase 내장. granular citations |
| Agents API (공개 베타) | Codex harness를 클라우드 agent로. **추가 API 수수료 없음**, 토큰·도구 사용만 과금. 예제 모델 `gpt-6-astra` |
| GPT-Live-1 API | 전이중 목소리. 뒤단 모델·도구로 작업 위임. 앞단 **분당 $0.05** |
| ChatGPT Work Data agent | Redshift·BigQuery·Snowflake 등 + Drive/SharePoint. 대화로 대시보드 생성 |
| Anthropic 무기·타격 평가 | Frontier Red Team. 전술 타격·재래식 무기 능력을 점수화한 연구 |

**실무 시사점 (브리핑 제안)**: 코딩 agent를 API로 붙이려면 Agents API 문서에서 **세션 생성 예제 한 줄**만 먼저 확인해 볼 것.

1️⃣ ChatGPT를 금융 팀에
9월 10일 OpenAI. ChatGPT for Financial Services는 ChatGPT Work에 금융 데이터와 GPT-6 Astra를 붙인 경험입니다. 설계 파트너는 Morgan Stanley와 Evercore이고, 내장 데이터는 Daloopa·PitchBook·LSEG News·Crunchbase입니다. 데이터는 OpenAI가 색인·호스트하며 granular citations로 숫자 출처를 따라가게 했습니다. 초점은 투자은행과 주식 리서치입니다.
👉 새 모델 주 옆에, 은행 워크플로를 구독 안에 넣는 쪽이 나왔습니다.
🔗 <https://openai.com/index/introducing-chatgpt-financial-services/>

━━━━━━━━━━━━
2️⃣ Agents API가 공개 베타
9월 10일 OpenAI. Codex harness를 클라우드 agent로 돌리는 Agents API를 공개 베타로 열었습니다. 추가 API 수수료는 없고 토큰·도구 사용만 냅니다. Ciridae CTO Jack Weissenberger는 평가 점수가 0.71에서 0.85로 갔고, 서브에이전트 쪽 지연은 4배 줄었다고 적혀 있습니다. 예제 모델 문자열은 `gpt-6-astra`입니다.
👉 금융 화면 옆에, Codex를 API 한 호출로 띄우는 쪽이 붙었습니다.
🔗 <https://openai.com/index/introducing-the-agents-api/>

━━━━━━━━━━━━
3️⃣ GPT-Live-1이 API로
9월 10일 OpenAI. ChatGPT에서 쓰던 전이중 목소리 모델 GPT-Live-1을 API에 올렸습니다. 들으면서 말하고, Codex와 ChatGPT Work처럼 뒤에 있는 모델·도구로 일을 넘깁니다. Speak 평가는 생각 멈춤 중 끼어들기를 이전 턴 방식 대비 거의 80% 줄였다고 했고, 앞단 목소리는 분당 $0.05입니다. 한 고객 인용은 코드 2만 3천 줄을 없앴다고 적혀 있습니다.
👉 agent API 옆에, 전화를 받는 목소리를 같은 날 연 쪽입니다.
🔗 <https://openai.com/index/introducing-gpt-live-1-in-the-api/>

━━━━━━━━━━━━
4️⃣ ChatGPT Work에 Data agent
9월 10일 OpenAI. ChatGPT Work에 Data agent를 넣었습니다. 회사 데이터에 붙어 무엇이 바뀌었는지 보고, 대화로 대시보드를 만듭니다. 연결 예는 Amazon Redshift·Datadog·Google BigQuery·ClickHouse·Databricks·MongoDB·Snowflake이고, 파일은 Google Drive와 SharePoint입니다. 용어는 Databricks Genie Ontology·dbt·GitHub·Snowflake Horizon 같은 시맨틱 층에서 옵니다.
👉 목소리 API 옆에, 창고 질의를 채팅으로 여는 쪽이 붙었습니다.
🔗 <https://openai.com/index/put-data-to-work/>

━━━━━━━━━━━━
5️⃣ Anthropic, 타격·무기를 점수로
9월 10일 Anthropic. Frontier Red Team이 전술 정보 타격과 재래식 무기 쪽 능력 평가를 공개했습니다. 계정 연결·분류와 드론 유도 같은 모의 과제이고, 같은 줄에 Threat Intelligence 보고서가 실제 오용을 이미 봤다고 적혀 있습니다. 말뭉치 135명(8%)은 모델 하나가 집 위치를 1 km 안에 두었고, 주차된 고대비 차량은 Opus 5가 발사 80%, Sonnet 5가 5%입니다. 설정 아홉에서 Opus 5는 발사 540회 중 20%에 맞췄습니다.
👉 업무 API 옆에, 킬체인을 점수로 펼친 연구 쪽이 나왔습니다.
🔗 <https://www.anthropic.com/research/intelligence-targeting-conventional-weapons-capabilities>
