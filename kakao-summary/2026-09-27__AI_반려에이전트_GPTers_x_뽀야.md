# AI 요약

## 인사이트·노하우

- **카카오톡 자동 내보내기/에이전트 연동**: 카톡 앱을 직접 쓰는 게 아니라 "태블릿 자리 하나를 먹게 하는 방법"으로 카카오 CLI(깃허브 공개)를 통해 개인 카톡 계정에 에이전트를 연결하는 방식. 맥/윈도우에서는 가능하나 리눅스는 미지원(불명 — 리눅스 지원 여부는 시도자 없음). 세컨폰이 있으면 그걸 연결하는 방법도 있음.
- **Muse AI(Meta) 가입 우회 시도 — 지역 제한 때문에 다양한 시도 발생**:
  - 기본 경로: Gemini 앱 → Spark 기능으로 원격 브라우저(미국 IP로 인식)를 열어 그 안에서 muse.ai/join 가입. 단, Gemini Spark는 Google AI Pro / Google One AI 프리미엄 등 유료 구독이 있어야 사용 가능.
  - 대안: browser-use.com 사용 — ① 가입 후 Browser 탭에서 위치를 미국으로 선택해 Launch & open ② 가상 브라우저에서 muse.ai 접속 ③ 이메일+인증코드 입력 ④ 개인정보 인증(신용카드) 요청 시 링크를 복사해 개인 브라우저에서 카드 인증 ⑤ 가상 브라우저 새로고침.
  - 실패 사례: 같은 계정으로 여러 번 반복 시도하면 "보안 및 네트워크 접근 정책 제한(PERMISSION_DENIED)"으로 막힘. 생년월일을 실수로 미성년자로 입력했다가 추가 인증 단계가 발생한 사례도 있음.
  - 지역 인식이 불안정함 — 같은 방법인데도 미국(US)으로 뜨기도 하고 대만(TW)으로 뜨기도 함. 사용 전 지역 표시를 확인하고 진행 권장.
  - Grok(super grok)으로는 안 됐다는 보고 다수. VPN(유료)으로 성공한 사례도 있음.
  - 나이 확인 단계는 사람마다 다르게 나타남 — 나이가 많으면 카드 인증 없이 그냥 통과되는 경우 있음, 반면 카드 인증을 요구받는 경우도 있음(국내카드 사용 가능 여부는 불명, 확인 안 됨).
  - 결론(참가자 P6 정리): "cli는 별도 플랜"이며, 무료로는 브라우저 사용만 가능. CLI 설치에 힘 뺄 필요 없음(무료 사용자 기준).

## 추천·자료

- **Muse AI (Meta 제작)**: 영상 생성에 특화된 AI. 나레이션·음악까지 자동으로 넣어주는 영상 제작 기능이 강점("나레이션에서 음악까지 다 넣어주네요", "실제 같은데요 와우"). 현재 미국 거주자만 이용 가능(한국 거주자는 지역 우회 필요). 무료지만 토큰 한도 있음.
- **browser-use.com**: 가상/원격 브라우저를 열어 지역(위치)을 미국 등으로 설정해 접속할 수 있게 해주는 도구. 지역 제한이 있는 서비스(Muse AI 등) 가입 우회에 사용됨.
- **카카오 CLI (GitHub)**: 개인 카카오톡 계정에 에이전트를 연결해 자동화(대화 내보내기 등)에 활용 가능한 오픈소스 도구. 정확한 저장소명/링크는 대화에서 언급되지 않음(불명).

## 의미있는 링크

- [Muse AI 가입 페이지](https://muse.ai/join) — Meta가 만든 AI 서비스(영상 생성 특화) 가입 링크. 추천 코드(A7Y6DD) 입력 시 가입자와 추천자 모두 10억 토큰 추가 지급, 가입 후 48시간 이내 코드 입력 필요.
- [Muse Code 공식 문서](https://dev.meta.ai/docs/muse-code) — Muse AI의 CLI/연동 관련 공식 문서. CLI는 무료가 아닌 별도 유료 플랜으로 확인됨.
- [browser-use.com](https://browser-use.com/) — 지역 제한 우회를 위해 가상 브라우저로 접속 위치를 변경해주는 서비스.
