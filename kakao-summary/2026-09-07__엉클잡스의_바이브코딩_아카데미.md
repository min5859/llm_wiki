# AI 요약

## 인사이트·노하우

- **Codex 업데이트 후 구버전 실행 여부 확인**
  - Codex를 쓰지 못할 때: 업데이트 후에도 **구버전이 열리는지** 확인할 것.

- **ChatGPT: Codex(코덱스)와 Chat(챗) 사용량은 별개**
  - Codex 토큰이 부족할 때 Chat의 **Astra**로 일부 작업을 옮겨 Codex(「뇌토큰」) 소비를 줄이는 전략이 언급됨.
  - Chat의 Astra는 **무제한이 아니고 주간 사용량**이 있음.
  - 실제 활용 패턴: Astra 라이트만 쓰다가, Chat 세션에서 **어드바이저(advisor) 역할**로 티키타카한 뒤 Codex 작업으로 이어가면 효율적이라는 체감.

- **모델 성향 비교 (참가자 체감)**
  - **Fable(페이블)**: 디테일을 잘 챙김.
  - **Astra(아스트라)**: 번뜩이는 크리에이티브함이 강함.
  - **Grok 4.7**: 한글 대응이 나아져 이전의 「둔탁함」이 줄고 부드러운 느낌 — 워커(worker)로 기대.

- **지역별 AI 구독·결제**
  - 나라별 가격 차이 사이트는 **앱스토어 결제와 웹 결제가 다를 수 있음** — 웹에서 별도 확인 필요.
  - GPT **필리핀(필쫀쿠) 구독**: VPN 없이도 된다는 경험(P29) vs 가이드 따라도 실패(P31) — **성공률은 개인·결제수단마다 다름**.
  - 카드 거절은 별도 해결 절차가 필요하다는 언급(아래 DC 갤 글 참고).
  - P29는 「코드 보니까」 다른 방법이 될 것 같다고 했으나 **구체 내용은 대화에 없음**.

- **Claude 단시간·종량제 사용**
  - 단기 사용: **OpenRouter**에서 종량제로 쓰는 방법 제안.
  - **코드(Claude Code 등)로 쓰고 있었다면 세션 호환**될 가능성이 높다는 답 — 기존 워크플로와 맞춰 볼 만함.

## 반응이 컸던 화제

- **Astra + Storm Race 데모** — 「우오아아아」「대박」 등 강한 호응; 시각·체험형 결과물이 인상적이었던 것으로 보임.
- **Codex vs Chat 사용량 분리·아끼기** — 「뇌토큰을 안 쓰겠다는 의지」, 「마른행주까지 쥐어짜내는」 등 공감·유머; 실무 팁으로 길게 이어짐.
- **필리핀 GPT 구독(필쫀쿠)** — VPN 필요 여부, 서브계정, 카드 거절, 해외 거주 친구 대행 등 논의가 이어졌으나 **성공·실패 사례가 갈림**.

## 자동화·시스템 적용 후보

- **2단계 AI 워크플로**: Chat(Astra)에서 세션 단위 **어드바이저·설계·티키타카** → Codex에서 구현·실행. Codex 할당량을 아끼는 패턴.
- **OpenRouter + 기존 Claude Code 세션**: 구독 대신 종량제로 단기 전환 시, 코드 기반 세션 호환을 전제로 붙여 보기.

## 질문·미해결

- **Astra를 어떻게 쓰는지** — P26은 써보고 싶다고만 했고, 이 스레드에 설정·접근 방법은 없음.
- **필리핀 GPT 구독** — P31: DC 갤 가이드·VPN 적용 후에도 실패; P29가 언급한 「코드」 방법의 **구체 내용·공유 여부** 불명.
- **서브계정·해외 친구 대행** — P30·P24 질문만 있고, 이 대화 안에서 확정 답 없음.
- **OpenRouter ↔ 현재 Claude 환경 호환** — 「코드로 쓰고 있었으면 세션 호환」 수준의 답만 있음; UI·에이전트·플러그인별 차이는 미확인.
- **Claude 계정 단기 대여 서비스** — P26 질문에 OpenRouter만 제안; 다른 대안은 없음.
