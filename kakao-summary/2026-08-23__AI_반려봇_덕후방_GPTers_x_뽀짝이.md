# 카카오톡 대화 정리 — 장기 지식

## 인사이트·노하우

### Mac mini에서 OpenClaw + Hermes 이중 운영
- **구성**: 같은 맥미니에 OpenClaw(코덱스)와 Hermes(클로드 API)를 분리해 운영.
- **역할 분담**
  - **OpenClaw**: 평소 지시·점검용. 프로 요금제 사용.
  - **Hermes**: 크론 자동화 위주. 클로드 API 종량제로 월 약 2~4만 원 수준.
  - **긴급 시**: OpenClaw 대신 Hermes로 처리.
- **대안 구성(P6)**: OpenClaw에 Claude CLI를 구독제로 연결해 사용 — “잘 씁니다”.

### 티보형(불명) 토큰 리셋 시각 추정
- 리셋 기준: **샌프란시스코(San Francisco) 기준 23:30** 언급.
- 23시경 게시 기준으로 **약 9시간 후 ~ 15시간 이내** 리셋 가능성이 높다는 추정.
- 태평양 표준시(PST) 오후 2시 언급도 있음 — 정확한 리셋 규칙은 대화에서 확정되지 않음.
- **실전 팁**: 리셋 직전에 남은 토큰을 “불태우기”로 소진하는 패턴이 공유됨. 초기화 쿠폰을 리셋 전에 쓰면 손해일 수 있음.

### 주간 사용 한도 소진 후 대안
- **에이전트 토큰**과 **웹 ChatGPT 채팅 한도**는 **별도** — 에이전트 한도를 다 써도 웹 채팅은 남을 수 있음.
- **웹 ChatGPT에서 프로젝트 접근 우회(MCP)**  
  1. 로컬 에이전트에 MCP 설정  
  2. 웹 ChatGPT에 MCP 플러그인 연결  
  3. 그 경로로 작업  
  - P11: “MCP로 쏘면 됩니다”, “Local 에이전트 mcp 설정 → 웹에 mcp 플러그인 담 → 작업 개시”
  - **주의**: 정지 가능성은 본인 책임(P11). Luna 무제한이 풀려서 가능하다는 언급이 있으나, 비즈니스 모델은 sol만 가능하고 개인 계정 Luna로는 시도 안 함.

### 광고·해상도 관련 (비전문가 수준 추론)
- 과거 쇼츠 광고가 없을 때는 **16:9 화면**으로 노출되던 시절이 있었음.
- 풀스크린·고해상도일수록 광고 경쟁력이 생길 수 있다는 추측.
- 브라우저/앱에서 **해상도 강제 조작**으로 광고를 피할 수 있는지는 **미확인** — “보유자의 영역”이라 꿀팁 공유는 없음.
- 단가는 **노출 횟수** 기준이라, 단기간 다량 노출 시 크레딧이 빨리 소모될 수 있고, 단가 자체가 크게 오르지는 않을 것 같다는 의견(P27).
