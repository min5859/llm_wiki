# AI 요약

## 인사이트·노하우

- **OpenClaw 크롤링 에이전트가 agent.md/메모리 무시하는 현상**: 컨텍스트 용량 초과가 원인일 가능성 높음. 해결 접근: 컨텍스트 용량 체크 + 검증 규칙(validation rule) 추가.
- **다크모드 작업의 실제 비용**: 컬러 정리 → 기존 컬러 재지정 → 룩앤필 깨지는 부분 재작업 → 컬러풀 확장 순서로 레거시 개선 작업이라 견적이 큼. AI 활용 시 의사결정 과정은 여전히 남지만 속도는 대폭 단축됨.
- **GPT 울트라(5.6 Ultra) 과사용 주의**: 울트라가 최고 성능이 아닐 수 있음. "너무 느리고 과함, 그냥 하면 되는 것도 생각을 너무 많이 한다"는 실사용 피드백. 추천 조합: **Terra Max** (속도+성능 균형, 범용), **Luna Max** (디자인 작업), **xhigh 이상**이어야 지시를 잘 따름, high는 토큰 절약용.
- **Gemini 업무 사용 주의**: PDF 스캔 시 타사 내부자료처럼 보이는 내용을 생성하는 문제 → 업무용 사용 기피 의견. 코딩 결과물 품질 문제도 언급.
