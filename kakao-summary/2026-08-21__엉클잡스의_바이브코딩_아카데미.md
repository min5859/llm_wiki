### AI 에이전트 인프라 트렌드 (아침 브리핑 요약)

- **모델 선택이 채팅 설정 → 비용 대시보드형 인프라로 이동**
  - Ramp의 **Router**: OpenAI·Anthropic·DeepSeek·NVIDIA·xAI 등을 한 API로 묶고, 벤치마크·난이도에 따라 모델 라우팅.
  - 2026년 말까지 라우팅 무료, 출시 크레딧 $26. 추론 토큰은 별도 과금.
  - 입력·출력·툴 호출 로그는 기본 1년 보관(끌 수 있음).

- **에이전트에 돈을 맡길 때의 안전 패턴 (바이낸스 Agent OS)**
  - ChatGPT·Codex·Claude Code·Cursor 등으로 시세 조회·주문 가능.
  - **전용 서브계정** 사용, **출금은 기본 차단**.
  - 주문마다 승인 vs 권한만 부여하고 자율 거래 — 사용자가 선택.
  - 일 한도 예시: 일반 스왑 $5만, DeFi 기본 $10만, x402 결제 하루 $20.
  - 핵심: "한도는 거래소가 아니라 넣은 돈" — 에이전트가 코드를 넘어 자금을 움직이기 시작.

- **AI 검색 이후 퍼블리셔 대응 (구글 Preferred Sources)**
  - 사이트에 버튼을 붙이면 독자가 즐겨찾기한 매체가 검색·Discover·뉴스·AI 모드·Overview에서 더 잘 노출.
  - 5월 기준 34.5만 고유 출처가 선택됨. 구글은 선호 출처 클릭이 2배라고 주장.
  - 대응책이 광고가 아니라 **독자 지정**이라는 점이 포인트.

- **웹 콘텐츠의 AI화 (Pew Research)**
  - ChatGPT 출시 이후 영문 페이지 **35%**에서 AI 작성·대폭 편집 흔적.
  - 2026년 7월 무작위 1만 페이지 기준 약 10%. `.com`은 `.edu`·`.gov`(각 ~1%)보다 약 10배 높음, `.org`는 4.6%.
  - 탐지기 오탐 가능성도 기사에 언급.
  - 시사점: "에이전트가 읽는 웹이, 점점 다른 봇이 쓴 글이 되고 있습니다."

- **메타 Pocket — 바이브코딩·소형 앱 전략**
  - 프롬프트로 작은 게임 제작 → 피드 공유·저장·리믹스. 브라질 시험 후 미국 전체 확대.
  - 기존 Gizmo 앱은 종료. "큰 모델보다, 만들어서 바로 돌리는 작은 앱을 여러 개 깔고 있습니다."

- **에이전트 응답 검증 필요 (Grok 단어 샐러드 사건)**
  - xAI Grok이 일부 사용자에게 gibberish(단어 샐러드) 응답. Grok Light·grok.com 직접 질문에서 수요일부터 관측, TechCrunch는 재현 실패.
  - xAI: 드문 일시 생성 오류, 새 채팅·재생성으로 보통 해결. X 내 Grok 계정은 정상.
  - 교훈: "에이전트에게 일을 맡기기 전에, 답이 멀쩡한 문장인지부터 봐야 하는 날."

- **실무 적용 제안 (브리핑 '오늘 해볼 것')**
  1. Ramp Router 소개를 읽고, **모델 고르기를 API 한곳으로 묶을지** 정리해 보기.
  2. 에이전트에 돈을 맡길 일이 있으면 **바이낸스 서브계정처럼 출금 막힌 칸부터** 분리.

- **Grok 봇 한글 지원**
  - 업데이트 후 **새로고침만 하면** 한글 지원 반영됨 (P40: "새로고침만 하면 올라와있어서 환장할 노릇").
