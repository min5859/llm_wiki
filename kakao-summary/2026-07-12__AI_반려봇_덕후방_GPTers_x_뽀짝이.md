# AI 요약

## 인사이트·노하우

- **GPT 5.6 모델별 체감 비교**
  - `sol xhigh`: 5.5 대비 "집중력이 올라갔다" 정도. 이전에 못 잡던 개선점을 더 잘 찾음. Fable이 언급하지 않은 부분까지 잡아서 교정.
  - `luna xhigh > terra` 라는 평이 다수. terra는 여러 지표에서 luna보다 못한 경우 있음.
  - sol 쪽에서 버그·문제 꽤 있음, OAI도 인지 중.

- **토큰 소모 팁**
  - 글/코드 작업은 토큰이 넉넉한 편, 영상/이미지 작업은 빠르게 소모됨.
  - GPT 5.6 xhigh를 여러 개 돌리는 것은 오픈클로가 "울트라 지시에 따라 이미 수행 중"인 경우가 있음 → 실제로 울트라 설정 확인 필요.

- **하네스 → 에이전트 전환 팁**
  - 코덱스/클로드코드용으로 만든 하네스를 오픈클로·헤르메스 등 에이전트에 적용 시, config 설정 변경·코드 수정으로 더 깊은 커스텀 가능.
  - 적용 방법: 해당 에이전트에게 먼저 정독시키고, 트리거 조정·상시 발동 방식을 에이전트와 상의하면서 진행.

- **Orca**: PC와 폰에서 동일 작업을 이어받을 수 있는 에이전트 도구로 언급됨.

- **오픈클로 스킬 설치 화면에서 Codex 선택 안 되는 문제**
  - 원인: 선택 UI에서 "Selected" 항목이 눈에 안 띄어서 못 찾은 것.
  - 해결: 검색창에 "Selected" 타이핑하면 넘어감.

- **Orca 세션 멈춤 문제**
  - 세션이 멈춘 상태에서 단축키 안 먹힘, 알람만 오는 현상 발생.
  - 강제 종료 후 재실행해도 멈춘 상태 그대로 유지됨 → 미해결 상태.
