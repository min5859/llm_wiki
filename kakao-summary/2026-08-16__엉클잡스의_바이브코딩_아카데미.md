# AI 요약

## 인사이트·노하우

- **코딩용 LLM 버전 선택 (4.6 vs 4.8 vs 5.0)**
  - PRD·TBD·user journey 설계 후 구현까지 묶는 작업(예: LLM wiki system)에 **4.8보다 4.6이 낫다**는 실사용 의견.
  - 4.8은 **「알 수 없는 이유로 계속 이상한 말투와 습관이 생기더니 안 고쳐져서」** 불만 — 코딩 품질·스타일 안정성 이슈로 인식.
  - 4.6도 코딩 작업을 잘 한다는 별도 확인.
  - **5.0과의 비교는 아직 안 해봤다** — 4.6 vs 5.0 우열은 이 대화에서 미정.

- **복잡 작업 vs 빠른 일처리 — 모델(또는 티어) 분리 운용**
  - **OmP**(불명 — Opus 등 상위 모델로 추정)에 **복잡한 작업**을 맡기고, **Pi**(불명 — 경량·빠른 모델로 추정)에 **빠른 일처리**를 맡기면 **「아주 좋습니다」** — 단일 모델에 모든 걸 맡기지 않는 운용 패턴.

- **셀프호스팅 Hermes vs Grok봇**
  - Hermes 구축 + 서버 파고 노가다하는 것보다 **Grok봇으로 인프라를 챙기는 편이 낫다**는 실사용자 권고.
  - 맥락: 클로드 맥스(Claude Max) 여러 인스턴스를 쓰는 환경에서, 자체 Hermes 스택 대신 관리형·봇형 경로를 택한 사례.

- **Cursor Ultra + Grok Heavy 가격·타이밍**
  - Cursor Ultra가 된 뒤 **Grok Heavy 할인 때 안 산 것**을 아쉬워함.
  - Grok Heavy 추가 비용이 **약 45만 원** 수준으로 인식 — **「45만원 추가는 쉽지않다」**.
  - 할인 타이밍을 **「한 10번 고민」**했지만 결국 못 산 케이스도 있음.

- **실제 운영 비용 감각**
  - Grok봇 + **클코 맥스 4개** 조합 사용자: **한 달 약 1,100달러**.
  - Grok봇은 **Cursor Ultra로 사용**한다고 명시.
