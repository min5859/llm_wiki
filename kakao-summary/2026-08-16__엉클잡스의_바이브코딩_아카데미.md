- **LLM 모델 선택 (코딩·기획 작업)**  
  - 맥락: LLM wiki system을 PRD·TBD·user journey 설계 후 구현하는 작업에 어떤 모델이 나은지 문의.  
  - 의견: **4.8보다 4.6이 확실히 낫다**는 경험 공유. 4.6도 코딩 작업을 잘 한다는 추가 확인.  
  - **4.6 vs 5.0** 비교는 아직 검토하지 않았다는 답변 — 결론 없음.

- **4.8 모델의 말투·습관 문제**  
  - 원인: 불명(「알 수 없는 이유로」).  
  - 증상: 이상한 말투와 습관이 생기고 **안 고쳐진다**.  
  - 해결: 대화 내 해결책 없음.

- **복잡도별 모델 분리 사용 (Opus + Pi)**  
  - 복잡한 작업 → **OmP(Opus)** 에 위임.  
  - 빠른 일처리 → **Pi** 에 위임.  
  - 이 조합을 쓰면 좋다는 실사용 팁.

- **셀프호스팅 Hermes vs Grokbot**  
  - 맥락: Hermes 구축 + 서버 파서 노가다 vs 관리형 서비스.  
  - 의견: 「헤르메스 구축하고 서버파고 노가다할바에는 그냥 **그록봇으로 인프라 챙기시는게 좋은 것 같아요**」  
  - 즉, 인프라 운영 부담을 줄이려면 자체 구축보다 Grokbot 쪽이 낫다는 경험 기반 조언.

- **구독·비용 현실감**  
  - 「45만원 추가는 쉽지않다」— 고가 플랜 업그레이드(맥락상 Cursor Ultra·Grok Heavy 등)에 대한 부담 공유.  
  - Claude Code Max 4개 기준 월 **약 1,100달러** 수준 언급.
