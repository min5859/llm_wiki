### Aside — `SOUL.md` / `AGENTS.md` 위치
- Settings 항목이 아니라 **프로필 생성 시 생기는 로컬 파일**.
- 경로: `~/.aside/u/0` (프로필 여러 개면 `u/1`, `u/2` …)
- 찾는 법: Settings → Memory → Open folder → **한 단계 위**, 또는 Finder → 이동 → 폴더로 가기 → `~/.aside/u/0`
- 프로그램 UI에서 찾지 말고, **에이전트에게 경로를 알려주고 대화로 편집**하는 방식이 현실적.

- **원인→시도→해결** 흐름: 국내 정가 부담 → 필리핀 Apple 계정으로 결제 시도 → VPN/우회 없이 **개발자 도구 콘솔에 코드 실행**으로 적용 → 실측 **202,144원** (약 10만원 절감).
- [디시인 AI 활용 마이너 갤 글](https://gall.dcinside.com/mgallery/board/view/?id=ai_utilize&no=1192) 참고.
- 국가별 구독료 비교: [OpenTheRank ChatGPT 가격](https://opentherank.com/ko/ai-pricing/chatgpt/) — 필리핀이 가장 저렴하다는 공감.

### Figma MCP 무료 티어
- 무료 계정에서 **MCP 호출 횟수 제한**이 있음 (대화 중 “6번만” 언급).
- 팀 플랜도 **프로젝트 개수 제한** 경험 공유.

### Odoo 오픈소스
- 설치보면 **전 기능이 오픈소스로 풀리지 않음** — 작업지시·회계 등은 **구독(엔터프라이즈) 필요**.

### Claude Max 사용량 급감 — 의심 원인·대응
- **증상**: Max 3계정 사용 중 체감 **3배 빠른 소진**; 페이블(Fable) 출시 이후 가속; 질문 5번이면 5시간 한도 소진 사례; **$100 추가 결제 후 10분에 40%, 20분에 65%** 소진.
- **의심 원인** (복수 병행):
  1. **병렬 서브에이전트**가 사용자 몰래 돌아가며 컨텍스트·토큰 소비 (과거 개인 경험 + “점검한다”며 병렬 시도하는 패턴).
  2. **슬랙 + OpenClaw**: 매 요청마다 **위쪽 맥락을 다시 읽는** 동작 → 6개월째 같은 방식이었는데 어제부터 급격히 악화된 건 **토큰 캐싱 기준 변경** 의심.
  3. 어제 **서버 장애 이후 소수 사용자만** 이상 — 대규모 전면 이슈는 아닐 수 있음.
  4. 페이블 **50% 이벤트 종료** 공지와 연관 가능성.
  5. 하네스·플러그인: **저장소 전체를 시작 시 밀어넣기**, 무의미한 툴콜, 플러그인 과다.
- **대응**:
  - 돌아가는 **병렬 작업 전수 확인**.
  - 병렬은 **작업 전에 반드시 확인**받기.
  - **맥락별 에이전트 분리** — 한 에이전트에 모든 일 몰아주면 병목·중첩 소비.
  - 서브에이전트는 **토큰마니드** 등으로 “쫌만 쓰기” 하면 확 줄었다는 경험.
  - 이 정도 소진이면 **사용 중단하고 원인 조사** 권장.
  - 슬랙 OpenClaw **소켓 모드** 이슈 조사 중 (당사자).

### Opus 5 vs 4.8 — 가격·체감
- API 단가: 입력 **$5 / 출력 $25** — 4.8과 **동일** (배치·캐시 단가도 동일).
- 차이: Opus 5는 **사고(thinking) 기본 ON** → 같은 요청도 **출력 토큰 증가** → 실제 청구액 상승 가능.
- 반면 “Opus 5는 **토큰 효율이 좋아져** 5 쓰는 게 더 안 닳음” vs “Fable은 그냥 녹아버림” — **작업 유형·모델별 추론 경로**에 따라 체감이 갈림.
- 실질 비용은 단가가 아니라 **“한 작업을 몇 번·얼마나 추론해서 끝내는지”** (딥식은 싸도 20달러, Opus 5는 한 번에 5달러 사례).

### Claude API 가격 정책 (구독과 유사한 패턴으로 추정)
- 최신 버전 출시 시 **기존과 가격 맞춤** → 시간이 지나면 **구버전 가격 인상 또는 지원 종료** → **API는 신규 버전이 항상 가장 저렴**. OpenAI도 비슷.

### `claude -p` vs 클코 vs ACP
- `claude -p`: **구독 모델** 안에서 처리; 클코(Claude Code) 대비 **성능·만족도 낮다**는 체감 다수.
- **ACP**: 백엔드를 **API로 띄우는 방식** → **API 토큰** 사용 (`claude -p`와 과금·동작이 다름).
- 혼자 쓰면 클코가 맞고, **팀·가족과 공유**하려면 슬랙 등에 에이전트 붙이는 구조가 필요 — 그때 슬랙은 토큰 비효율.

### OX-Alpha 프로바이더
- 성능·사용량 넉넉하다는 소문 vs **보안 우려** (개인정보·회사 코드 넣지 말 것).
- 실사용자: **중간에 계속 끊김** → 현재는 안 쓴다.

### Codex 5시간 세션·한도
- **Plus에만** 5시간 세션 **부활/적용**; **Pro는 적용 안 함** (프로 유도·몇 달 유예 추정).
- Codex Spark: **5시간 한도가 따로 있고**, UI는 5시간 한도를 보여주지만 **일주일 한도**도 존재한다는 언급.
- 원래 5시간 한도 있었는데 **Sol 출시 후 잠시 없어졌다**가 다시 돌아온 흐름.
- 8/25 밤: **Plus 한도 100% 리셋** 관측 (구성 변경 추정).

### Codex 원격 작업
- **맥북에서 맥미니 프로젝트**를 열어 원격 작업 가능 (PC 쪽 원격도 당사자는 최근에야 인지).
- 모바일에서 원격·로컬 명령 모두 가능 (기존에도 모바일은 됐다는 언급).

- **토큰 효율화 체크리스트**: 병렬 작업·슬랙 맥락 재읽기·플러그인·전체 repo 컨텍스트·유령 서브에이전트·캐싱 변경 여부.
