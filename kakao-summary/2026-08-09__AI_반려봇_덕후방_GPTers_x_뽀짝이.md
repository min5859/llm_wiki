## 인사이트·노하우

### Codex / GPT 구독 한도(초기화) 운영
- **주간 한도 리셋(「초기화」)** 이 구독마다 날짜가 달라, 커뮤니티에서 공유되는 리셋 시점(예: 월요일 테크니컬 리셋)과 겹치면 **이중 리셋**처럼 느껴질 수 있음.
- 미국 시간 월요일 리셋 → **한국 기준 화요일**일 수 있음. 개인 초기화일과 겹치면 한 주에 **3번** 굴릴 여지가 있다는 언급.
- 리셋 직전·직후에는 **타임아웃·연결 끊김**이 늘어나는 것으로 여러 명이 공감. “일부 오류라서 오늘 한번 더 리셋해주면 좋겠다”는 반응.

### Codex 장애 트러블슈팅
- **증상**: 세션에서 “다시 연결”만 반복, 요청 미전송, `stream disconnected before completion` 오류, 지속적 타임아웃.
- **시도**: 새 세션 열기, 재로그인 검토 — 일부는 동일 증상 지속.
- **관찰**: 같은 시점에도 **헤르메스 경유 Codex**·**OpenClaw + Codex**는 정상인 경우가 있어, 전면 장애보다는 **클라이언트·세션·경로별 편차** 가능성.
- **원인 추정(대화 맥락)**: 초기화·서버 이슈 복합. “고치고 있다”는 언급과 맞물려 **일시적 불안정** 구간으로 인식.

### 모델 선택: Sol / Terra / Luna (Codex 계열)
- **Terra**: 벤치마크상 GPT-5.5보다 인텔리전스는 낮지만, **5.5를 더 효율적으로 쓰는 느낌**. 5.5가 비싸서 안 쓸 때 Terra 대안.
- **Sol vs Terra (실측 비교, P25)**  
  - 크롬 익스텐션: Terra 10번 지시 → 한도 10% / Sol 2번 지시 → 5%. Sol 쪽 **복잡도·완성도**가 더 높음.  
  - 익스텐션 수정: Sol로 만든 작업을 Terra hi로 바꾸다 **5% 손실** — 모델 바꿀 때 주의.
- **운영 원칙**  
  - “간단한 건 루나, 반복·완성도 필요하면 Sol.”  
  - “Sol은 토큰을 한 번에 더 쓰지만, **다시 잡도리하는 시간·스트레스**도 비용” — 단가만으로 고르지 말 것.  
  - Sol medium도 만족스럽다는 실사용 후기.
- **계획 중인 패턴(P16)**: 반복 실행 전에 **작업 유형별 최적 모델을 계획 단계에서 구분**하도록 세팅 후, 돌려보며 디테일 조정.

### Sol로 앱·익스텐션 제작 실측
- **신규 앱**: Sol 한 번에 제작. 도구 자동 설치, **Android Studio 없이 APK 컴파일**까지.
  - 소요: 약 30분, GPT Plus 한도 **5%** (84% → 79%).
  - 결과: 디자인 제외 **기능은 대체로 구현**.
- **익스텐션**: 이전 작업 시 한도 **130%** 수준이었고, 이번엔 “양호”하다고 평가.

### CLAUDE.md ↔ AGENTS.md 멀티 에이전트 운영
- **Claude Code 전용**: `CLAUDE.md` 안에 `@AGENTS.md`(또는 `@agents.md`)를 쓰면 **내용이 인라인 병합**되어 Claude가 읽음.

  ```
  abc          ← CLAUDE.md
  @agents.md   ← 여기서 agents.md 내용(def)이 이어짐
  → Claude는 "abc\ndef"로 인식
  ```

- **권장 분리**  
  - `AGENTS.md`: 모든 에이전트 공통 규칙.  
  - `CLAUDE.md`: Claude 전용(훅, 서브에이전트·모델 설정 등). `@AGENTS.md`로 공통 규칙 임포트.
- **한계**: Codex 등 **다른 에이전트는 `@CLAUDE.md` 임포트가 안 됨**. Claude Code가 `AGENTS.md`를 기본으로 읽는지도 불확실하다는 의견.
- **Claude ↔ Codex 핸드오프**  
  - “문서로 남기라”고 시킨 뒤, 다른 에이전트에 그 문서 기반 작업 지시.  
  - 또는 Codex 쪽은 `CLAUDE.md`를 쓰지 않는 방식.
- **AGENTS.md 작성법**: 에이전트와 대화하며 규칙을 **점진적으로 추가**; 너무 길어지면 사람이 보고 **줄이기**.

### 모델·도구별 역할 감 (디자인·이미지)
- **Claude Code 이미지 생성**: “별로” — GPT API 이미지 도구 붙여 쓰는 사례가 있음.
- **HTML/UI**: Claude도 잘하지만 **대시보드에 ‘클로드 메타’**가 보인다는 공감. 시각적 완성도는 **GLM**이 더 낫다는 의견이 여럿. Kimi는 부정적.
- **혼용 주의(P46)**: 여러 모델을 섞으면 **「짬뽕」** — 스타일·컨텍스트가 뒤섞임. **하나로 쭉 가고 스킬로 다듬기**를 권장.

### LLM으로 로또 예측 — 실패 인사이트
