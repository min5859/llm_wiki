# 카카오톡 대화 정리 — 2026-09-30

## 인사이트·노하우

- **카톡 대화 자동 요약/자비스 구현 방법 논쟁**: P15가 "카톡이 제일 어렵다"며 자비스 구현 중 카톡 요약 방법을 질문.
  - P26: 톡방 내보내기 + 자체 제작 매크로 사용 중.
  - P50: 서브(부)계정 + iris + redroid 조합으로 카톡 대화 수신하는 방법을 제안. Mac 사용자는 `kakao-cli`라는 도구가 있다고 들었다고 언급(본인 미확인, 불명).
  - P31(반박 의견): "카카오톡 대화내용 내보내기가 낫다"며, 전용 API는 없고 **내보내기 → 파이썬으로 패턴 텍스트 파일 파싱 → 오늘 날짜만 전처리/분리 → AI에게 던지는 방식**을 추천. 관련 레포는 카카오톡 로그인이 필요해 서브폰(듀얼넘버) 운용이 전제됨.
  - P31 결론: 결국 전체를 저장해도 본인이 다 읽어야 하므로, "본인이 읽고 좋은 것만 가져오는 게 제일 낫다"는 실용적 견해.
  - P50 보완: 자신은 **봇이 카톡방에서 양방향 상호작용**까지 해야 해서 듀얼넘버가 필수였다는 사용 사례 구분(단방향 요약 vs 양방향 상호작용에 따라 요구사항이 달라짐).

- **OpenAI dot(닷) 초기 설정 프롬프트 예시** (P66 공유): "네가 할 수 있는것과 잘 하는것, 나한테 필요한 것들을 고민하고 생각해서 나한테 알려줘. 그리고 기존에 코덱스와 채팅, 헤르메스, 자동화예약, 슬랙, 텔레봇을 쓰고 있는데 그것과 연동하거나, 거기서 하던것들을 네가 더 잘하거나 가져올 수 있는 것들을 분석해" — 기존 자동화 스택과의 통합 가능성을 dot에게 직접 탐색시키는 프롬프트 패턴.

- **dot 사용 팁**: 프로필을 누르면 슬랙 워크스페이스에 봇으로 바로 연결 가능(단, 워크스페이스는 1곳만 연결 가능해 보임). 같은 계정이면 내용 확인 가능. 데스크탑에서 만들면 모바일에서도 사용 가능.

- **뮤즈(Meta Muse) 쇼츠 자동 제작 워크플로** (P35): 뮤즈 비디오 생성기로 영상 생성 → 뮤즈 컴퓨터(VM)에 리모션(Remotion 추정, 불명확히 "리모션"으로만 언급) 설치 → 자막과 영상을 자동 합성. "시나리오 대본 동영상 자막 편집까지 한방에 원샷"으로 처리 가능하다고 함. 오픈클로를 뮤즈 VM에 설치해 하위 에이전트까지 구성하는 실험도 진행 중.

- **muse.ai 접속 차단 이슈**: Gemini Spark 환경에서 muse.ai 도메인 접속이 막힘(P3) → 해결책으로 VPN 사용 제시(P60).

- **코덱스 초기화권 분배**: 일부에게만 추가로 초기화권(3개)이 지급된 것에 대해 "어떻게 받을 수 있냐"는 부러움 섞인 반응과 궁금증이 이어짐(P9, P20, P6, P11 등).

## 자동화·시스템 적용 후보

- **카카오톡 로그 전처리 파이프라인**: 카톡 내보내기(텍스트 파일) → 파이썬으로 패턴 파싱 → 날짜별 분리 → LLM에 전달하는 방식(P31 제안). 본 작업(현재 대화 요약 작업)과 유사한 목적의 사전 파이프라인으로 참고 가치 있음.
- **서브계정 + iris + redroid 조합**: 카톡 봇의 양방향 상호작용이 필요한 경우의 수신/연동 아키텍처 패턴(P50, Mac 미지원 환경에서는 `kakao-cli` 대안 언급).
- **dot 초기 설정 프롬프트**: 기존 자동화 스택(코덱스, 헤르메스, 슬랙, 텔레그램 봇 등) 목록을 주고 "연동하거나 더 잘할 수 있는 것을 분석해"라고 요청하는 온보딩 프롬프트 패턴 — 신규 에이전트 온보딩 시 재사용 가능.
- **뮤즈 VM + 리모션 조합 쇼츠 자동 생성 워크플로**: 시나리오→영상 생성→자막 합성을 한 번에 처리하는 파이프라인(P35).
