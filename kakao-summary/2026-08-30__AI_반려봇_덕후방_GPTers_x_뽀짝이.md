## 인사이트·노하우

### Codex(티보형) 사용량 리셋·시차
- 티보(Thibault Sottiaux)가 리셋했다고 포스트하면 **순차적으로 할당량이 다시 채워지는** 흐름으로 보임.
- 포스트에 `2:30 pm pdt`라고 적혀 있었고, 8월 미국 서부는 **PST가 아니라 PDT(UTC-7)** 기준.
  - **2:30 PM PDT → 한국시간 다음날 오전 6:30**
  - 사람들이 PST라고 말해도 실제는 PDT인 경우가 많음.
- 실측: 8/30 **오전 6:33** 경 리셋 확인.
- **5시간 롤링 제한** 때문에 리셋 직후에도 **40%만 쓴 상태**로 남는 사례 있음(전날 9%까지 쓰고 잔 경우도).
- 여러 작업을 동시에 걸어두는 패턴: *「3개까지만 할까? → 3개 되면 처음에 돌린 게 다 돌아서 다시 걸다가 몇 시간 늦어지는 마법」* — 동시 실행 수를 늘리면 완료·재시작 타이밍이 꼬여 지연됨.

### Gemini CLI / Antigravity 계정 정지 (OpenClaw 연동)
- **원인(추정)**: Antigravity·Gemini CLI·Gemini Code Assist OAuth 로그인을 **타사 에이전트(OpenClaw 등)가 exec로 스모크 테스트**하며 호출 → 약관 위반으로 정지.
- 정지 안내에 나온 위반 예:
  - *「타사 소프트웨어, 도구 또는 서비스를 사용하여 Antigravity, Gemini CLI 또는 Gemini Code Assist에 액세스하는 경우(예: Antigravity OAuth와 함께 OpenClaw 사용)」*
  - AI 개발자 도구 서비스 **재판매**
- **권장 해결 방향(안내 문구 기준)**: 제품 로그인(OAuth) 대신 **Vertex 또는 AI Studio API 키** 사용.
- **반복 위반 시 영구 징계** 가능. 이의 신청 양식은 있으나, 해제 후에도 재발 시 위험.
- GPT·Grok은 구독을 다른 에이전트에 **물려 쓰는 편이 관대**하다는 방 비교 인상.

### OpenClaw + 크롬 + Gemini 웹 UI (CLI 우회 후보)
- **시도**: OpenClaw에게 *「크롬 열고 제미나이 들어가서 네 모습 이미지 생성해서 텔레그램으로 보내줘」* — **성공**.
- 논리: CLI OAuth 연동은 감지되지만, **브라우저에 로그인된 Gemini 웹을 조작**하면 서버가 모르지 않을 수 있다는 가설 — 다만 **메인 구글 계정이라 위험 부담**으로 실사용은 자제하는 사례도 있음.
- **가족/프로 계정 5개 연결**해 분리 운영을 검토하는 사례.

### Gemini·Flow 이미지/영상 생성 실무
- Gemini 이미지: **「Mark」가 떡하니 붙는** 문제 지속.
- 한글 프롬프트보다 **영어 프롬프트**가 나은 듯 → 다음엔 영어로 넣도록 지시하는 팁.
- **Google Flow**: 비싸고, **하루 무료 할당량 약 50** 수준 언급. Flow로 만든 영상도 **워터마크 있음**(여러 명 확인).
- 워터마크: 완벽한 제거는 어렵고, 구글 검색으로 **대략 지워주는 서비스**는 있음. Flow보다 워터마크 없는 다른 구글 영상 생성 경로는 **착각이었을 수 있음**.
- 유튜브 자동화 맥락: 동영상은 **Gemini(재미나이)에 시키면 퀄이 조금 올라감** → 이미지만 Gemini로 막 만들고, 영상·나레이션은 별도.
- 영상 편집: **루나(Luna, 불명)** 로 렌더 시 PC 사양 낮으면 **솔로 30분 → 보통 10분** 수준으로 느림.
- 나레이션: **타입캐스트(Typecast)** 남성 목소리 사용 권장.
- 콘텐츠 구조(실전 피드백): *「1. 환장할 노릇의 포인트를 만든다. 2. 그래서 발상을 뒤집는다.»*
