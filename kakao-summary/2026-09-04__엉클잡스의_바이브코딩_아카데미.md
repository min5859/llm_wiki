# AI 요약

## 인사이트·노하우

### GPT-6 Astra 출시·접근
- **2026-09-03** OpenAI가 GPT-6 Astra 출시. FrontierMath Tier 4 98%, ARC-AGI-3 99.9%, ExploitBench 100%. OSWorld 2.0은 작업당 약 40분·72.6% (GPT-5.6 Sol 대비 시간 약 47% 단축).
- **허가 범위 초과 평가**: Sol 48% vs Astra **0%** — 성능과 함께 정렬·사이버 모니터링을 동시 출시한 모델.
- **가격·등급**: API 표준가 입력 $10 / 출력 $50 per MTok. 채팅방 체감은 "가격은 싼데 급은 페이블급".
- **접근 현황 (당일 10:31~10:45)**: Plus·Pro 등 일반 ChatGPT 사용자 중 다수는 **아직 UI에 Astra 미표시**. "제한된 조직" 단계이며 며칠 내 Plus·Pro·Business·Enterprise·API·AWS 확대 예정.
- **출시 혜택 관련**: 이전 모델 출시 때 쓰던 **banked reset(뱅크드 리셋)** 기대가 있었으나, 당일은 "뱅크드 리셋도 안 줌". 대신 **리셋권(리셋 티켓)** 형태로 주는 것으로 확인 — "리셋도 해주고, 리셋권도 준다"는 이중 혜택 언급.

### Fable 5.1 + 코딩 위임 (fable-advisor)
- **원인**: Fable 5.1은 "코드를 한 줄도 치지 않는" 판단·조언 모델. 입력 $10 / 출력 $50 — 타이핑까지 맡기면 **토큰 수에 비례해 비용 폭증**.
- **해결 패턴**: 판단은 Fable, 실제 코드 작성은 **GPT-5.6 Luna**에 넘기는 Claude Code 전용 플러그인 **`fable-advisor`**.
- **맥락**: 고가 모델을 오케스트레이터로만 쓰고 실행은 저렴한 코딩 모델에 위임하는 비용 최적화 워크플로.

### Moshi 맥앱 + herdr 연동
- **Moshi** (`getmoshi.app`): 터미널 대신 **챗 기반 UI**로 SSH·원격 세션 관리. "터미널 싫은 분들한테 찰떡", 한글 지원·워크스페이스 분리·IDE 느낌.
- **herdr**: Moshi 세션이 꺼져도 살아남는 도구. P10은 "세션이 꺼져도 살아남는 헛둘"이라 **herdr을 무조건** 쓴다고 함. P4도 "moshi+herdr은 사랑", 자연스러운 연동 확인.
- **무료 vs 유료**:
  - 무료: 세션 약 **20개** 제한, 앱 업데이트 시 **연결 끊김** 빈번 (P15는 이 때문에 청산).
  - 유료: "쭉 갑니다" — 세션 만료·끊김 없음 (이벤트 때 평생권 미구매 후회 언급).
- **VPS 대안**: Moshi를 VPS에 올려 자동화(grok bot, Hermes 등)하면 **실리콘 맥 구매 없이** 원격 서버만으로 운영 가능 — "집가서 맥 사야지" → "VPS 구하면 맥 필요 없겠군요"로 인식 전환.
- **실패 사례**: 앱을 자주 업데이트하면 연결 불안정 → 무료 사용자 이탈 사례.

### 그록봇(Grok bot) 플랫폼
- **2026-09-04** 당일 확인: 그록봇이 **Windows·Linux**에서도 설치 가능 (기존 맥 한정 인식 확장).
- VPS + Moshi + 그록봇 + Hermes 스택으로 원격 에이전트 자동화 언급.

## 추천·자료

- **Moshi** (`getmoshi.app`) — 맥용 챗 기반 SSH/터미널 대체 앱. 한글·워크스페이스 분리. VPS·원격 서버 자동화를 GUI로 다루고 싶을 때.
- **herdr** — Moshi(또는 SSH) 세션 유지·복구. 무료 Moshi의 끊김·세션 소멸을 보완할 때 Moshi와 함께 쓰는 조합이 채팅방에서 반복 추천됨.
- **fable-advisor** (Claude Code 플러그인) — Fable 5.1로 판단만 하고 GPT-5.6 Luna에 코딩 위임. 고가 Fable의 토큰 비용을 줄이는 실전 패턴.
- **GPT-6 Astra** — 페이블급 성능·저렴한 API 가격대. ChatGPT 앱에서 체감하려면 롤아웃 대기 필요 (당일 미표시 다수).
