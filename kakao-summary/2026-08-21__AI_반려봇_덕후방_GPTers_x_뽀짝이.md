## 인사이트·노하우

### 중국 숏폼 영상의 프롬프트·레퍼런스 제작 방식
- 국내 업체가 중국 숏폼 업체 흔적을 분석한 사례가 공유됨.
- 신규 계정 무료 크레딧을 대량 악용해 영상을 만든 뒤, 그 과정에서 남긴 프롬프트·레퍼런스 제작 노하우가 드러남.
- 이미지 레퍼런스 방식은 힉스필드(Higgsfield) 공유 방식과 유사하지만, 프롬프트 자체에는 별도 노하우가 담겨 있음.

### gpt-image-2 preview — 투명 배경 지원
- **원인/배경:** 기존에는 프롬프트로 투명 배경을 요청해도, 실제로는 크로마키 색상(그린/마젠타)을 채운 뒤 후작업으로 제거하는 방식이었을 가능성.
- **해결/변화:** `gpt-image-2` preview 버전에서 네이티브 투명 배경 이미지 생성을 지원한다고 함.
- **미해결:** 이미 나온 모델인데 왜 여전히 preview 표기인지는 불명(마이너 버전 업그레이드를 표기하지 않는 정책인지 추정만 있음).

### Claude 한국어 품질 저하 (2026년 8월 경)
- **증상:** 컨텍스트가 길어질 때 한국어 출력이 심하게 깨짐. 예: *「오히려 사람들을 갈라놓았어요」* → *「오히띌 사람들을 갈란좠음어요」* 수준의 말도 안 되는 어눌함.
- **추정 원인:** 워터마크 패치 이후 품질이 엉망이 된 것 같다는 의견(P6).
- **시도한 우회책:**
  - 영어로 출력하게 하기(P67)
  - 모델 전환: `/model claude-opus-4-8[1m]` (Opus 4.8, 1M 컨텍스트)(P67)
  - Codex로 전환(P7)
  - 스킬(skill)로 보정 시도 — [요즘IT 글](https://yozm.wishket.com/magazine/detail/3908/)에서 제안하지만, 근본적으로는 모델이 정상화되어야 할 문제라는 공감(P7)
- **관련 운영 이슈:** Claude Max 구독자도 Fable(페이블) 모델 사용 한도가 체감상 거의 반토막 수준으로 줄었다는 보고(P50). Fable 모델 자체가 비싸서 사용량이 빨리 소진되는 것도 한 요인으로 보임(P3). Claude 사용량 프로모션 기간은 **8월 말까지 연장**됨(P34).

### 원고작성 프로그램 — 말투·문구 문제 해결
- P66: 원고작성 프로그램의 말투·문구 문제를 해결함(지아코모님 도움). 구체적 해결 단계는 대화에 없음.

### NAS + 크롬 프로필 — 자동 로그인 미동기화
- **상황:** NAS에 로그인 쿠키를 저장해 두고, A/B 컴퓨터에서 번호별 크롬 프로필(1, 2, 3, 4번 등)을 열면 북마크는 따라오지만 자동 로그인이 계속 빠짐(P66).
- **상태:** 해결책 없이 질문만 남음.
