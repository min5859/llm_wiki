# AI 요약

## 인사이트·노하우
- **로컬 헤르메스(Hermes) 운용 한계**: 로컬로 구동 시 속도가 많이 느리고 실수가 잦으며 설정·튜닝("깎는 작업")에 공수가 많이 들어가므로, 메인보다는 서브 용도로 쓰거나 코덱스(Codex)·완성형 도구를 사용하는 편이 유리함.
- **뮤즈(Muse) SNS 자동 업로드 시 권한 요청 차이**: 유튜브 업로드는 최초 1회 권한 허용 후 계속 자동 실행되지만, 인스타그램 릴스는 업로드할 때마다 매번 권한 허용을 눌러줘야 하며 일부 계정은 작동하지 않는 현상이 있음. 무개입("퍼미션 없이 딸깍") 자동화가 목적이면 어사이드(Aside) 루틴을 쓰는 편이 나음.
- **뮤즈(Muse) 영상 생성 지역 제한 및 우회**: 한국 지역에서는 유료 결제를 하더라도 자체 영상 생성 기능이 작동하지 않음(영상 외 기능은 작동). 영상 생성은 미국·캐나다 지역에서만 가능하므로 VPN을 통해서만 이용 가능함. 단, 계정 차단 위험 및 신규 가입 제한 사례가 있어 주의 필요.
- **뮤즈(Muse)의 한국어 자료 검색 한계**: 한국 자료 검색 품질이 아직 부족해 범용 메인 도구로 쓰기에는 한계가 있으나, 유튜브 제작이나 주식 정보 수신 용도로는 충분히 활용 가능함.
- **AI 영상 제작 프롬프트 고도화("AI 깎기") 과정**:
  1. 초기에는 '신비한 건축사전' 등 레퍼런스 채널 스타일을 타겟으로 삼고, 노트북LM(NotebookLM)에 기존 쇼츠 영상 분석을 먼저 시킴.
  2. 분석 결과를 토대로 다른 시나리오를 작성하게 지시.
  3. "나도 저렇게 하고 싶다, 이 부분 수정해라" 식으로 피드백과 수정을 반복해 데이터를 축적하면 이후부터 AI의 산출물 품질이 안정화됨.

## 추천·자료
- **오픈클로(OpenClaw)**: 가볍고 특정 프로바이더를 타지 않아 범용 에이전트 작업에 적합하며, 뮤즈와 역할을 분담해 운용하기 좋음.
- **뮤즈(Muse)**: 자체 영상 생성 모델이 내장된 올인원 도구. 코덱스에 힉스필드(Higgsfield, 비용 높음)나 플로우(Flow, 연결 불편)를 별도로 연동하지 않아도 되며, 무료 제공 토큰량이 많아 경제적임.
- **타입캐스트(Typecast)**: 뮤즈로 생성·편집·자막 처리한 영상에 음성을 입힐 때 조합하여 사용하는 TTS 도구.
- **플로우(Flow) + 나노바나나**: 뮤즈 계정 차단 위험 때문에 우회가 부담스러울 때 대안으로 쓰는 영상 생성 구성. 힉스필드보다 품질은 아쉽지만 나노바나나가 무료여서 월 30만 원 요금제 기준 경제적으로 영상을 뽑아낼 수 있음.
- **노트북LM(NotebookLM)**: 유튜브 쇼츠 레퍼런스를 분석하고 시나리오 초안을 도출하는 초기 학습·기획 단계에 유용함.

## 자동화·시스템 적용 후보
- **뮤즈(Muse) + 타입캐스트 기반 유튜브 영상 제작 파이프라인**: 뮤즈에게 유튜브 레퍼런스 탐색 → 주제 추천 → 대본 작성 및 수정 → 자체 모델로 동영상 생성·편집·자막 처리 →유튜브 스튜디오 분석까지 일임하고, 음성만 타입캐스트로 결합하는 워크플로.
- **컴퓨터 유즈(Computer Use) 기반 유튜브 스튜디오 일일 스크래핑**: YouTube Data API(호출당 1유닛 소모)를 쓰는 대신, 매일 아침 에이전트가 컴퓨터 유즈로 직접 유튜브 스튜디오 페이지에 접속해 데이터를 스크래핑하고 일일 성장률을 체크하는 자동화 패턴.
- **어사이드(Aside) 루틴 기반 인스타 카드뉴스 자동 배포**: 뮤즈의 반복적인 권한 승인 요구를 피하기 위해, 카드뉴스 제작 및 인스타그램 자동 배포를 어사이드 루틴으로 무인화하는 방식.
