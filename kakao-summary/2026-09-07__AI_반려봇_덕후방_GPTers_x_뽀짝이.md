# 카카오톡 대화 정리 — GPT-6 Astra·구독·로컬 LLM (2026-09-07)

## 인사이트·노하우

### Astra 토큰·한도 운영
- **Astra는 Sol 대비 토큰 소비가 매우 큼.** 질문 하나에 5시간 한도 80% 소진, 1시간에 주간 한도 80% 사용, Pro 20X 기준 이틀 만에 소진 등 다수 보고.
- **Sol과 병행 시 체감:** Astra 실행 후 Sol을 쓰면 Sol 쪽은 토큰이 거의 안 먹는 것처럼 보인다는 관찰(정확한 과금 구조는 불명).
- **5시간 한도 vs 주간 한도:** Plus 사용자 기준 주간 한도보다 **5시간 롤링 한도**가 먼저 걸리는 경우가 많음.
- **인사·잡담도 소비:** OpenClaw에 Astra를 붙이면 인사 한마디에도 토큰이 크게 나간다 → **업무 시작 시 인사 없이 바로 본론**이 필요하다는 실무 팁.
- **OpenClaw + Astra 주의:** 에이전트 호출이 많아 **토큰 낭비가 극심**할 수 있음. 반면 복잡한 검증(날짜·주 변경 등 엣지케이스)은 잘 처리한다는 긍정 경험도 있음 — 용도별 분리 권장.

### 모델·작업 분업 패턴
- **Sol이 핑퐁 수정으로 못 풀던 문제 → Astra가 해결**한 사례 다수.
- **크롬 익스텐션 개발 워크플로:** 배포·웹스토어 검증은 **Sol**, 본 개발은 **Astra**.
- **한도 절약 3단 분업(P53):** 계획 수립 **SOL** → 실행 **LUNA** → 대량 처리는 **스크립트**로 LLM 호출 최소화.
- **모델 변경 시 추론 수준 테스트(P40):** 모델이 바뀔 때마다 추론 수준 테스트를 돌려 적정 수준을 맞춤. 당시 작업은 **X high** 사용 중.

### 구독·초기화권 함정
- **초기화권 사용 시 주간 한도 리셋이 즉시가 아님:** 초기화한 날로부터 **7일 뒤**에 주간 한도가 들어옴. 24시간 안에 빨리 태우려다 주간 리셋이 밀려버린 실패 사례.
- **개인 초기화 vs 전역 초기화 혼동:** Codex 한도가 리셋된 것처럼 보여도 **개인 주기 초기화**일 수 있음 — 실제로 많이 쓰지 않았는데 리셋된 것처럼 느껴지는 경우.
- **GPT 채팅에서 Astra 사용 시 Work 한도 소진(P8):** GPT 채팅으로 Astra를 쓰면 Codex/Work 한도가 같이 닳는지 문의. P20은 **Codex와 GPT 토큰이 따로 계산**된다고 한 달 전에 본 기억이 있으나, 당일 기준 여부는 **불명**.
- **요금제 구조(P23):** Pro Light = **x5**(약 16만 원), Pro = 보통 **x20**. 차이의 핵심은 Pro 모델 접근 + Codex 사용량 한도. **제한 없는 이미지 생성**은 Codex가 아니라 **Chat에서 생성할 때** 거의 무제한에 가깝다는 설명.

### 로컬 LLM·하드웨어
- **로컬 LLM 하나 두면 토큰 절약** 가능(P12).
- **맥미니 이중 구성(P49):** 64GB — Gemma4 12B(MLX) + OpenClaw(Codex 구독). 24GB — Claude API 비상용. 한쪽 장애 시 다른 쪽이 처리하는 **페일오버** 구성. Tailscale로 묶어두면 상호 복구에 유리(P14).
- **맥 2대 합치기:** [exo](https://github.com/exo-explore/exo) → 이후 MLX 쪽 개선. 비슷한 성능 기기 2대면 **용량 확대 vs 속도 향상** 중 선택. 도입 전 링크·리소스 파악 후 기대 성능을 커뮤니티에 질문하는 것을 권장(P14). **인텔 맥 지원 여부는 대화에서 미확정.**
- **P14 개인 구성:** Codex 20X + Claude 구독으로 OpenClaw·OpenMinis Aside + Claude Code로 **교차검증**. Qwen 3.8 27B는 효율 좋다는 평만 있고, 본인 하드웨어로는 제한적 활용.

### Astra 배포·접근
- **Codex Desktop / Chat 모두 순차 업데이트.** 앱 업데이트 안 해도 Astra가 보이는 경우(P48), Chat에서는 아직 없는 경우(P55) 공존 — **업데이트 후 확인** 필요.
- **Codex CLI에 Astra 추가**한 사례 문의(P48).

### 트러블�hooting 사례 (원인→해결)
- **HWP/HWPX 한글 자동변환(P40):** 보안 모듈 설정 때문에 며칠 실패 → **Astra로 1시간 만에 성공**. Pro 5X 기준 사용량 약 4%.
- **OpenClaw + Hermes 동시 운영(P11):** 일부 복구가 안 되는 문제 → **한 집(한 환경)에 같이 두면 안 될 수 있음** 경고.

### 구독 전략·비용 철학
- Plus로 가볍게 시작 → **무엇을 할지 알게 된 뒤 Pro 업그레이드**가 낫다(P41).
- 돈 내고 쓰기 시작하면 쓸 곳을 찾게 됨. AI 비용 월 70만 원 넘는 사례(P20) — 테스트·실험 비용으로 인식.
- **「프로 맛보면 플러스 못 내려간다」** — 업그레이드 후 다운그레이드 어려움(P41).
- 필리핀 등 해외 결제(「필쫀쿠」)로 Pro 약 22만 원 수준 가능하다는 언급(P15) — 공식 채널·약관 확인은 대화에 없음.

## 반응이 컸던 화제

- **Astra 토큰 폭탄·한도 고갈** — Pro 20X·초기화권·5시간 한도까지 연이은 공감. 「숨만 쉬어도 토큰 증발」「디지털 월세 난민」 등 표현이 반복됨.
