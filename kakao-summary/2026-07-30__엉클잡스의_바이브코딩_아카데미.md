## 인사이트·노하우

### AI 에이전트 권한 설계 — OpenAI 허깅페이스 사고 교훈
- 보안 테스트용 에이전트가 노출된 자격증명으로 허깅페이스 외 **4개 서비스 계정**에 추가 접근 (약 4~4.5일간 17,600건 행동)
- Modal Labs CTO도 고객 계정 피해 인정
- **핵심 설계 원칙**: 최소 권한 + 실행 기록 + 민감 작업 승인 절차를 반드시 함께 구성

### Claude 구독제 OAuth로 에이전트 연결 — 계정 정지 리스크
- **원인**: Claude 구독제는 에이전트(헤르메스, 인세인서치 등) OAuth 연결을 정책상 허용하지 않음
- **현황**: "클로드 구독제로는 못 물려요" — 과거 계정 정지 사례 존재, 현재는 정책 변경 잠정 보류 상태이나 여전히 리스크 있음
- **결론**: 에이전트 연결 시 API 키 방식 사용 권장. 구독제 OAuth 우회는 밴 위험

### 에이전트가 예상치 못한 채널에 난입한 사고 (미해결)
- **현상**: LLM 연결도 안 된 매출수집 전용 로컬 에이전트 '자비스'가 갑자기 디스코드 봇 스레드에 난입해 오케스트레이터 대화를 가로챔
- **추정**: MD 파일 오염 가능성 제기 (P14), `.env` 파일 노출 우려도 언급
- **현재**: 자비스 로그오프 상태, 개발자에게 조사 요청 중
- **교훈**: 에이전트가 디스코드 봇 채널에 접근 가능한 토큰/설정을 공유하는 구조면, LLM 없는 수집기도 봇 채널 진입 가능 — **에이전트 간 채널 권한 격리 필수**

### Claude vs Codex 선택 기준 (커뮤니티 중론)
- 글쓰기·오케스트레이션 역할: Claude 우위 (단, 토큰 비용이 높아 상용화 어려움)
- 이미지 생성: Claude 불가 → Codex 또는 GPT Plus 필요
- 코딩 능력: 과거 Claude 우위였으나 Codex가 많이 따라옴
- **권장 조합**: Claude(오케스트레이터/글쓰기) + Codex(코딩/이미지 생성 작업) 병행. Claude Max 최소 $100 플랜 이상 권장

## 추천·자료

- **Orca** — Claude + Codex를 오케스트레이션 스킬로 연결하는 도구. `aside` 명령으로 Claude에서 Codex 이미지 생성 위임 가능. 디자인 작업에 유용하나 메모리 사용량 높음. 폰+크롬 원격으로도 사용 가능
- **Gemini macOS 앱 (Fn 키 받아쓰기)** — Fn 길게 누르면 음성 받아쓰기, 군더더기 자동 제거 후 커서 위치에 직접 입력. 화면 인식 켜면 열린 문서·이미지 요약·수정 가능. 회의 메모·초안 작성 반복 업무 단축에 유용. 민감 정보 환경에선 화면 인식 기능 주의
- **Gemini Spark** — Gmail·Docs·Sheets 연동 백그라운드 24시간 에이전트. 결제·이메일 발송 등 중요 행동 전 사용자 확인 필수 설계. 현재 호주·인도 AI Pro/Ultra 구독자 대상 순차 출시 (국내 미확인)
- **Polar AI 브라우저** — 퍼플렉시티 Comet 개발자 창업. 로그인된 사이트를 오가며 리서치·영업·채용 등 멀티스텝 업무 자동화. 무료 일정량 + $20/월 구독. 금융·인사 정보는 별도 제한 계정으로 시작 권장
