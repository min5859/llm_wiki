# AI 요약

## 인사이트·노하우
- **Codex CLI `Command 'codex' not found` 오류 복구**
  - 원인: 기존 `npm` 설치 방식과 최근 바뀐 `curl` 설치 방식 혼재로 인한 PATH 꼬임(또는 `npm` 버전 교체 중 실행 파일 유실), 혹은 Windows 데스크톱 앱 업데이트 시 기존 `gpt(classic)`이 삭제되고 `codex`가 `chatgpt`(`gpt`) 앱으로 통합되면서 검색/실행 경로가 변경됨.
  - 시도 및 해결:
    1. CLI의 경우 `curl` 방식으로 재설치하면 즉시 해결됨.
    2. 코덱스 앱을 설치한 뒤 복구를 요청하면 환경변수 세팅까지 자동으로 처리해 줌.
    3. Windows 앱 사용자의 경우 `codex` 대신 `chatgpt`로 검색하여 실행(Microsoft Store 앱 연결보다 `.exe` 설치 파일로 직접 받아 실행하는 것이 안정적임).
- **Muse (`muse.ai`) 가입 시 지역 제한 우회 및 카드 인증 우편번호 입력**
  - 원인: 일반 접속 시 가입이 막히거나, 나이 확인용 카드 등록 단계에서 한국 카드에 없는 우편번호(Postal Code) 입력을 요구함.
  - 시도 및 해결:
    1. VPN을 사용하거나, **ChatGPT 웹(앱 X)에서 상단 모드를 `Work`로 설정**(또는 제미나이 스파크/스피크 활용)한 뒤 에이전트 브라우저를 통해 가입 진행(Gmail 실패 시 네이버 메일로 성공 사례 있음).
    2. 우편번호 입력란에는 선택한 국가의 임의 우편번호(예: 미국 `99553`, `AK - Alaska` 또는 영국 주소/우편번호)를 입력하면 정상 통과됨.
- **안드로이드 이어폰 마이크 상시 호출(Wake word) 구현 시 음질 저하 이슈**
  - 원인: "하이 빅스비"처럼 호출어를 감지하기 위해 이어폰 마이크를 상시 개방(Always-on) 상태로 유지하면 블루투스 오디오 프로파일 한계로 샘플링 레이트가 약 32kHz 수준으로 떨어짐.
  - 현상: 호출어 동작 자체는 가능하나 미디어 재생 음질이 저하되는 트레이드오프가 발생함.
- **Claude Max 플랜 월간 무료 API 크레딧 수령 조건**
  - Team 플랜이 아닌 개인 Max 플랜 사용자는 **조직(Organization)을 먼저 생성**해야 무료 API 크레딧을 신청·수령할 수 있음.

## 추천·자료
- **Tasker / MacroDroid**: 안드로이드 환경에서 STT(음성 인식) 등을 트리거로 삼아 다른 외부 앱(예: 유튜브 뮤직 플레이리스트 재생)의 기능을 제어·자동화할 때 유용한 자동화 도구.
- **Muse (`muse.ai`)**: 개인 AI 에이전트 서비스로, 가입 후 48시간 이내에 설정에서 추천코드를 입력하면 양측 모두 Muse 토큰 10억 개를 받을 수 있음.

## 의미있는 링크
- [Claude Max 및 Team 플랜의 월간 API 크레딧 안내](https://support.claude.com/ko/articles/17154008-max-%EB%B0%8F-team-%ED%94%8C%EB%9E%9C%EC%9D%98-%EC%9B%94%EA%B0%84-api-%ED%81%AC%EB%A0%88%EB%94%A7): Claude Max/Team 구독자에게 매월 API 크레딧(참가자 언급 기준 $100 등)을 무료 제공하는 정책 공지로, 기존 API 유료 사용자들의 큰 호응을 얻음.
- [Muse 가입 페이지](https://muse.ai/join): ChatGPT Work 모드나 VPN을 활용한 우회 가입 방법 및 추천코드 공유로 다수 참가자가 시도한 개인 AI 에이전트 가입 링크.

## 반응이 컸던 화제
- **Claude Max 플랜 월간 API 크레딧 무료 제공**: 리셋권 제공에 이어 매월 $40~$200가량 별도 지출하던 API 비용을 아낄 수 있게 되면서 "갑자기 혜자가 되었다", 플랜을 올려야겠다는 등 긍정적 반응이 이어짐.
- **Muse AI 에이전트 우회 가입 및 추천코드 공유**: ChatGPT `Work` 모드의 원격 브라우저를 이용해 지역/가입 제한을 넘고 토큰 10억 개 보상을 받으려는 가입 팁(네이버 메일 활용, 우편번호 임의 입력 등)이 활발히 공유됨.
- **Codex CLI 실종 및 `--yolo` 플래그 작동 이상**: 업데이트 이후 `codex` 명령어가 사라지거나 데스크톱 앱이 ChatGPT로 통합된 현상, 그리고 보안 강화로 인해 `--yolo` 옵션을 주어도 권한 승인을 반복 요구하는 현상에 대해 여러 사용자가 겪은 증상과 해결책을 공유함.

## 자동화·시스템 적용 후보
- **클라우드 브라우저 에이전트를 활용한 반자동 회원가입 프롬프트 패턴**
  - 지역 제한이 있거나 반복적인 가입 절차에서 인증 단계 전까지 에이전트에게 위임하는 프롬프트:
  - `"muse.ai 가입 페이지 열고 가입 진행해줘. 내가 직접 입력해야 하는 단계가 나오면 멈춰줘."` (이메일 인증이나 결제 정보 등 민감/수동 단계에서만 개입하도록 제어).

## 질문·미해결
- **단순 반복 작업용 에이전트 비교**: 단순 반복 작업을 시킬 때 Muse와 제미나이 스파크(Gemini Spark) 중 어느 쪽이 더 나은지 질문이 나왔으나 직접적인 성능 비교 답변은 나오지 않음.
- **Codex `--yolo` 권한 확인 반복 및 네트워크 차단 문제**: `codex --yolo` 실행 시에도 보안이 강화되어 계속 권한을 물어보는 현상과 네트워크 제한 차단 현상에 대해 명확한 우회/해결법이 확인되지 않음.
- **취미용 멀티플레이 게임 개발 서버 선택**: 메이플스토리 월드(메월) 서버를 활용할지, 개인 서버로 먼저 개발 후 멀티플레이를 붙일지에 대한 질문(메월 서버 개발이 매우 힘들다는 경험담만 공유되고 결론은 미정).
- **Claude Max 무료 API 크레딧 신청 방식**: 별도 신청형인지 여부에 대한 마지막 질문([P7])에 아직 답변이 달리지 않음(앞선 대화에서는 "신청들 하세요", "조직 먼저 생성하셔야 합니다"라고 언급됨).
