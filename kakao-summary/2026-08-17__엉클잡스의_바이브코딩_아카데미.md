### 그쫀쿠(SuperGrok Heavy + Cursor Ultra) 가입·결제

- **가입이 막힐 때 우회 방법** (P16, 실제 성공 사례)
  - 원인: 정확한 원인은 불명. 당사자도 *"막히기보다는 뭔가 로직이 있는 것 같은데 방법을 설명을 못하겠다"*고 표현.
  - 시도→해결: **폰 사파리로 링크를 연 뒤, 노트북 웹으로 이어서 진행**하니 갑자기 됨. 위키 링크를 눌러 모바일로 열고 노트북 웹으로 가져가는 흐름.
- **3개월 → 1년 전환** (대화 당시 아직 가능하다는 보고)
  - 경로: **결제 관리** 메뉴 (P1: *"밑에 결제 관리에 들어가야함돠"*). 플랜 변경 화면에서 1년 **$3,000** 표시 (P18).
  - 조건: **새벽에 3개월 결제한 사람만** 1년 전환 옵션이 보일 수 있음 (P18, P21). $300만 보이는 경우는 이 조건 미충족 가능성.
  - 일반 Heavy 결제는 **$300**으로만 뜨는 사례도 있음 (P21).
- **결제 수단**: **네이버페이 결제 가능** (P1, P16 실사용 확인).
- **이벤트 상태**: 대화 시점(2026-08-17) 기준 **그록 1년 기습 이벤트는 종료**. *"다들 끝났다고 했을 때 전 했어가지고"* (P16) — 타이밍 의존적.
- **환불 전제**: P1 — *"이놈들 말 바꿔서 커서랑 분리 정책 들어가면 바로 환불 갑니다"*. 이미 구독한 사람만 해당된다는 맥락.
- **사용량 구조**: **Grok Builder 사용량과 Cursor 사용량은 별개** (P1, 15:54 확인). *"미쳐따…"* 수준으로 혜자로 인식.

### 구독·도구 조합 팁

- **연간 결제 원칙과 예외** (P1)
  - 원칙: *"연간 구독은 절대 하지 말라"*.
  - 예외: 블프 때 **GLM**, 이번 **그쫀쿠**는 연간 결제해도 *"킹정"* — Cursor Ultra만 포함돼도 **Claude Code Max 1개 취소** 가능해서 가성비 인정 (P9).
- **그쫀쿠 실사용 조합** (P1): Grok 4.6 + Cursor Composer 3. *"확실히 커서 위에 그록 4.6은 다르다"*. DeepSeek(딥시기)와 병행하면 든든하다는 경험.
- **Cursor 모델 선택 UI** (P24): 목록에 보이는 모델은 일부뿐, **상세 설정으로 들어가면 더 많은 모델**(Kimi 3 등) 노출.
- **iOS**: 모바일 Cursor 사용 권장 (P16 — *"ios는 모바일커서 긔긔싱해보셔용"*).
- **Claude Code 모바일 + Aside**: 클코 모바일로 Aside 앱과 병행 사용 언급 (P16, P19). Aside가 *"요즘 떡상해서 보기 좋다"*는 맥락.

### AI 모델 경쟁 구도 (당사자 관찰)

- **중국 모델 상승** (P1): GLM 5.3, DeepSeek V4 Pro 0813, Kimi K3 사용 경험상 *"중국 모델들이 이제 엄청 올라오고"*.
- **경쟁 축**: Grok 4.6 + Cursor Composer 3 vs OpenAI Luna 80% 할인 vs Claude — *"클로드 해자 moat 유지가 굉장히 힘들지 않나"* (P1).
- **Claude 포지션** (P9): 극 하이엔드로 가고 xAI(일론) 쪽과 연계 필요. 5월 Colossus 임대 등 *"모종의 거래"* 추정.
- **일론 머스크 ↔ Anthropic**: 직접 까지는 않고, *"페이블5는 진짜 좋은 모델인데, 그록 4.7은 역대급"* 식 트윗 (P1).
- **Opus 품질 이슈 추정** (P1, P16): Opus가 DC인사이드 등 커뮤니티 데이터로 대량 학습됐다는 이야기 → *"좀 많이 이상해짐"*. 반면 P16은 *"요즘 오퍼스 미안하다고 잘하더라"* — 시기별 체감 차이.
- **Cursor Ultra 토큰량**: P9 — *"울트라가 그렇게 토큰이 많지는 않은데, 클코 맥스 + 보조 조합으로 치면 클코 맥스 4개 정도 쓰던 게 하나로 줄어들 것 같다"*.
