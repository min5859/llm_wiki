# AI 요약

## 인사이트·노하우

- **뉴스 자동화 중단 사유**: 당사자(P1) 서버·인프라가 카센타 수리에 들어갔고, **전력망 이슈로 샷다운** 상태. 무인 시간에 몰(설치 장소)에 가서 복구 예정 — **내일부터 가동** 목표.
- **다운타임 대비 아이디어**: 메인 자동화가 멈출 때 **공폰 + 별도 번호**로 채팅방에 응답하는 봇을 두는 방안이 논의됨. P2는 **루나**와 **딥시기**(불명)면 충분할 것 같다고 함. P1도 귀찮아서 미구현이지만 조만간 하겠다고 함.
- **헛둘(Hudl) 멀티 세션**: P2 평가 — **에이전트 세션 여러 개를 켜고 세션 간 응답**하는 용도에 딱 맞고, **클로드보다 세션 간 응답이 더 잘 된다**고 함. P1은 **파일뷰** 플러그인과 **세션간응답** 플러그인만 설치했고, 현재 **“맴속 일등”**으로 쓰는 중.
- **세컨드 클로드 코드(SCC) 하네스**: P1이 **세컨클코 하네스**에 만족 — **리서치 능력**이 좋았고, **PDCA 철학**도 좋다고 함. **업무형·콘텐츠형 하네스**는 일반인에게 코딩보다 실용적이라는 관점.
- **“부리는 기술”**: AI를 비서·잡도리에 **부려먹는 맛**이 핵심 가치. P1 표현 — **“부려보는 기술”**, **“5만원으로 모텔 대신 리조트 감성”** (저비용으로 높은 체감 가치).

## 추천·자료

- **헛둘(Hudl)** — 멀티 에이전트 세션 운영·세션 간 응답에 적합. 플러그인 예: 파일뷰, 세션간응답. 이 대화에서는 클로드 대비 세션 간 협업 체감이 더 좋다는 실사용 평가.
- **세컨드 클로드 코드(SCC)** — P2가 **scc**로 이름 변경. **딥 인터뷰** 기능으로 비서·코치·매니저형으로 확장 예정. P1은 리서치·PDCA·업무/콘텐츠 하네스 관점에서 추천.
- **루나** — 공폰 백업 응답봇 후보로 언급. 메인 자동화 다운 시 채팅 응답용.

## 반응이 커던 화제

- **헛둘 vs 클로드(세션 간 응답)** — 멀티 세션·세션 간 협업에서 헛둘이 더 낫다는 공감과 “맴속 일등” 평가. 실사용 비교 맥락이라 반응이 큼.
- **SCC 하네스와 일반인 UX** — 코딩보다 **업무·콘텐츠형 하네스**, PDCA, 리서치가 일반인에게 더 맞다는 논의. “누구나 쓸 수 있게” 지점을 노린다는 P2 발언.
- **“부리는 기술”** — 비서·잡도리에 AI를 부려먹는 체감 가치가 반복 유머·호응으로 이어짐.

## 자동화·시스템 적용 후보

- **공폰 백업 응답 채널**: 메인 서버/뉴스봇 다운 시 공폰·별도 번호·루나(또는 유사)로 채팅방 응답 — 가용성 패턴.
- **헛둘 멀티 세션 워크플로**: 파일뷰 + 세션간응답 플러그인으로 병렬 에이전트 세션 운영.
- **SCC 딥 인터뷰 확장**: 비서·코치·매니저 역할 — PDCA·리서치 하네스를 비개발자 업무에 적용하는 방향.

## 질문·미해결

- **“딥시기”**가 정확히 무엇인지 불명 (루나와 함께 백업봇 구성 요소로만 언급).
- 헛둘 **플러그인 전체 목록**은 많다고만 하고, 이 대화에서 확정된 설치는 파일뷰·세션간응답 두 가지만.
- SCC **딥 인터뷰** 기능의 구체 스펙·출시 시점은 대화에 없음.
