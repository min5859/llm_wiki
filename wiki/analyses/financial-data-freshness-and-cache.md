# 재무 데이터 신선도·장애 대체와 일일 캐시 설계

같은 점수식도 재무 기준기간·확정 여부·계산 기준이 다르면 다른 결과를 낸다. 재무 원자료와 시세의 갱신 주기를 분리하고, 보완 실패 시 허용할 구자료의 범위와 출처를 명시한다. 반복된 소스 비교와 매수 입력의 핵심 수정이므로 범용 분석으로 수집한다. 아래 구현·검증 결과는 세션 보고이며 이번 수집에서 API나 코드를 재검증하지 않았다.

## 핵심 내용

### 점수 차이는 가중치보다 입력 기준부터 확인한다

점수 차이를 기술·재무·리포트로 분해한 뒤 같은 종목의 기준기간·결측·집계 방식을 대조한다. 10/16 동일 69종목 중 56종목은 같은 점수였고, 다른 13종목 중 12종목은 재무, 1종목은 기술 입력 차이였다. 일부 KIS 재무비율 응답 자체가 2024년에 머물러 있었으며 모든 종목의 연도를 잘못 선택한 문제는 아니었다.

최신 확정 자료가 있는지와 높은 점수를 주는지는 별개다. 연간 ROE·부채비율, 최근 4개 확정 분기의 EPS, 연결/별도 기준을 맞춘다. 연도 표기만 바꾸거나 예상치를 확정값으로 넣지 않는다. 입력 기준이 달라지면 점수식·컷이 같아도 버전을 구분한다([[scoring-version-comparison-methodology]]).

### 주 소스 유지와 제한적인 장애 대체

최종 구현은 최신 KIS 재무를 우선하고, 뒤처진 일부 종목만 Naver 확정 연간 재무·최근 4개 확정 분기 EPS로 보완한다. 시세·거래량·주문은 KIS를 유지한다. 보완은 전체가 유효할 때 반영하고 중간 실패 시 원래 KIS 자료로 되돌려, 서로 다른 출처의 값이 반쯤 섞인 상태를 방지한다.

초기의 ‘보완 실패 시 종목 제외’ 정책은 후속 수정으로 바뀌었다. Naver 재무 실패 시 필수값·기간 계산이 정상이고 기준연도보다 한 해 뒤처진 범위까지의 KIS 자료를 허용하고 구자료 사용을 기록한다. 세션 당시에는 2024년 연간 자료가 해당했다. 더 오래된 자료·누락·기간 오류까지 허용하거나 모든 입력에 무제한 구자료 대체를 적용하지 않는다. Naver 리포트 점수 실패와 계좌 잔고 신선도는 별도 정책이다([[trading-api-failure-handling]]).

### 재무 응답만 일일 캐시하고 가격 파생값은 재계산한다

공시 수치는 주로 분기·연간 보고서나 정정 공시 때 바뀌지만 시세는 계속 변한다. 최종 구현은 재무 API의 정상 응답만 파일에 저장해 같은 한국시간 날짜 안에서 프로세스 재시작 후에도 재사용하고 다음 날 첫 조회에서 갱신한다. 이는 재무를 매일 새로 공시받는다는 뜻은 아니다.

주가는 매 수집마다 조회하고 현재 가격으로 PER·PBR을 다시 계산한다. 실패 응답이나 손상된 캐시는 재사용하지 않고 재조회하며, 캐시 저장 실패가 원래 수집을 중단시키지 않도록 한다. 하루 동안의 공시·정정 반영이 다음 갱신까지 늦어질 수 있다는 갱신 주기의 한계도 구분한다.

세션은 한국시간 자정 경계·재시작·손상·저장 실패·동시 실행 테스트 통과를 보고했다. 실제 3종목 재조회에서 재무 API 호출은 11회→0회, 주가는 3종목 모두 재조회됐고 점수·선택 결과는 같았다. 작은 표본의 동등성 확인이며 모든 종목·기간을 보증하지 않는다.

## DART 대조와 미완료 범위

3종목 직접 조회 중 HT로보틱스의 2025년 ROE 1.95%·부채비율 101.02%는 Naver 보완값과 일치했다고 보고됐다. 삼성전자 ROE는 DART 10.783%·KIS 10.85%로 달라, 공식 출처라는 이유만으로 계산 기준 대조 없이 교체하지 않는다. EPS 대조와 DART 자동 보완 연결은 미완료다.

실적 개선·영업현금흐름은 페이퍼 비교 후보, 증자·전환사채·감자 등은 우선 참고 경고로 검토한 제안이다. 신규 점수나 자동 매수 제한을 적용한 결과로 기록하지 않는다. 외부 API의 현행 제공 범위는 이번 수집에서 확인하지 않았다.

## 관련 맥락

입력 수정의 수익 효과와 소스 우위는 [[ht-trading-live-data-improvement-analysis]]의 8거래일 근사 재생을 참조한다. 재무 보정 후 수익이 같아도 낡은 입력을 바로잡을 필요가 없다는 뜻은 아니다. 구현 연결은 [[n-stock-info]]에 기록했다. 점수식·62점·매매 규칙은 유지했고, 10/19 첫 정상 수집·추천 저장·실매수 후보 연결 확인은 남아 있다.
