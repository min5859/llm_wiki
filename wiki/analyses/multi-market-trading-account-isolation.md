# 다중 시장 자동매매의 계좌·실행 환경 분리 설계

국내 자동매매에 미국 시장을 추가하는 경우, 계좌번호만 바꾸기보다 시장별 실행 환경과 주문 생명주기를 분리하는 설계가 필요하다. 10월 11일 계획에 이어 10월 12일 기반과 오프라인 페이퍼 구현이 기록됐다. 후속 기록에서는 기존 계좌의 조회와 실제 시세 관측까지 진행됐다. 주문 권한·공동 위험 관리·전략 수익성은 검증 전이다. 시장 확장을 위한 도메인 핵심 설계로 기록한다.

## 핵심 내용

- 코드는 공유하되 계좌 설정·인증 캐시·거래 DB·전략 상태·로그를 분리한다. 주문 대상 계좌와 실행 모드를 검증하고 중복 프로세스를 차단한다.
- 주문 접수를 체결로 간주하지 않는다. 실제 체결가·수량을 확인하고 미체결·부분체결·취소·재시작 복구를 일관된 경로로 처리한다. 비멱등 주문 제출 재시도 위험은 [[order-post-retry-double-fill]]을 참조한다.
- 잔고·매수가능금액·취소 API는 대상 시장 전용으로 연결한다. USD 주문·손실 한도를 계산하고 수수료와 환율 손익을 구별한다([[kis-balance-api-fields]]).
- 거래 세션은 현지 시간·서머타임·휴장·조기 폐장과 한국 자정을 넘는 구간을 처리한다. 현지 거래일과 서버 달력 날짜를 동일하게 가정하지 않는다.
- 알림에는 시장·페이퍼/실거래를 명시한다. 초기 실행 범위는 정규장·현금·정수 수량·지정가로 제한하는 안을 검토한다.

## 검증과 적용 순서

계좌·프로세스 분리 → 시장별 조회·주문·체결 처리 → 장애·재시작·기존 국내 회귀 검증 → 미국 전용 페이퍼 → 예산·중단 기준 확정 후 소액 실거래 순서다. 계좌 개설 전에도 기반 구현은 가능하지만 기존 계좌 또는 신규 계좌의 해외주식/API 권한은 별도로 확인한다.

기존 국내 62점 컷이나 하락일 역행 전략의 미국 시장 수익성을 가정하지 않는다. 1~2주 관측은 실행 안정성 점검이며, 전략 채택에는 완결 거래 표본과 비용 후 성과가 별도로 필요하다.

## 관련 맥락

[[ht-trading]]의 당시 해외주식 코드는 주문 코드 불일치·실제 체결 확인 미구현이 보고됐다. 10월 11일 당시 계좌의 해외 권한은 확인되지 않았고, 신규 계좌가 반드시 필요하다는 결론도 내리지 않았다. 10월 11일에는 계획만 작성했으며, 이후 구현 상태는 아래와 같다.

## 계좌 없이 검증한 구현과 주문 상태 경계

10월 12일 세션에는 미국 설정·인증 캐시·DB·상태·중복 실행 방지, 지정가 주문·잔고·실체결 조회·취소 API 교정, 거래일·서머타임·조기 폐장, USD 위험 한도와 오프라인 점검 명령이 구현됐다고 기록됐다. 시장가·비정상 가격·소수점 수량을 요청 전에 차단하고, 잔고의 매입금액을 사용 가능한 현금으로 해석하지 않는다.

- 국내 실행기로 해외 주문을 호출해 임의 체결을 기록하는 경로를 차단한다. 조회 전용 연결은 주문과 취소 요청 자체를 허용하지 않는다.
- 부분체결은 이미 기록한 체결과 중복되지 않게 반영한다. 재시작 뒤 미확인 주문을 보존하고, 취소가 확정되지 않은 예약금은 새 주문에 재사용하지 않는다.
- 오프라인 페이퍼는 가상 지정가·부분체결·만료와 거래·현금의 원자적 저장을 연결한다. 같은 입력을 재처리하거나 재시작해도 거래가 늘어나지 않아야 한다.
- 수수료·슬리피지·배당·분할·입출금·환율을 구분한다. 입출금을 투자 수익으로 집계하지 않고 USD 손익과 환산 효과를 별도로 표시한다.

신호 이후 새 호가로만 체결을 판단하는 검증은 [[backtest-fill-model-adverse-selection]]에 보강했다. 합성 테스트와 실제 관측 기반 성과를 구분하고, 보고 화면을 만들었다는 이유로 실시간 관측이나 실거래가 시작됐다고 해석하지 않는다.

오프라인 구현 단계의 보고는 ht_trading 640개·서브테스트 13개, ht_dde 269개 통과이며 반복 실행 후 체결 3건·완결 1건이 유지됐다는 것이다. 이번 ingest에서 테스트를 재실행하거나 실제 계좌에 접속하지 않았다. 이 단계에서 남았던 실제 관측·조회 연결은 아래 후속 기록으로 보강한다. 첫 전략과 실제 주문 연동은 미완료다.

## 동일 계좌 운용과 실제 관측의 경계

후속 세션은 신규 계좌가 필수라는 전제를 수정했다. 기존 계좌의 미국 시세·호가·보유 잔고·매수가능금액 조회가 성공했다. 조회 성공은 주문 권한이나 실제 체결 가능성의 확인과 다르다. 페이퍼 자금은 가상 예산이며 실제 계좌 현금을 그대로 사용하지 않는다.

계좌를 공유하더라도 시장별 프로필·장부는 분리한다. 통합증거금으로 원화와 국내 매도대금이 해외 주문에 사용될 수 있으므로, 계좌 전체 투자금·미체결 예약금·손실 한도를 공동 관리해야 한다. 이 공동 위험 관리는 아직 미구현이다. 장부 분리만으로 실제 자금이 격리됐다고 판단하지 않는다.

미국 일봉 원응답은 최신인데 함수가 오래된 N개를 선택하는 오류를 실패 테스트로 재현해 수정했다. 최신 N개를 선택하고 장중 미완결 일봉을 제외한다. 한국 자정 이후에도 현지 거래일이 유지되는지를 검증한다. 달력 날짜·관측 시각·완결 세션을 구별하는 것은 시장 확장 시 재사용할 패턴이다.

10월 12~13일 최종 보고에서는 QQQ·SPY·DIA를 정규장 15초 간격으로 실제 관측하고 상태·시세 신선도를 저장·표시했다. 첫 세션은 장중 시작한 부분 관측이며 가상 매매 전략은 미가동, 실주문은 0건이다. 데이터 도착과 EOD 확인을 정상 세션의 완전성이나 전략 전방 검증 일수로 세지 않는다. 첫 전략·대조군·비용·판정 기준 및 거래상태 해석을 확정한 뒤 관측 기반 가상 체결을 연결해야 한다.

## 전략 버전과 체결 방식 확정 후 페이퍼 연결

같은 전략 이름이라도 회당 고정 수량과 예산 정액 분할은 서로 다른 실험이다. 진입·부분매도·완전 청산·회차 집계·예산 소진·사이클 초기화 규칙을 버전으로 고정한 뒤 연결한다. 확인하지 못한 버전별 규칙을 혼합하지 않는다. 장마감 지정가(LOC) 전략은 기존 지정가 엔진과 동등하다고 가정하지 않고 미국 세션·체결 시점·재시작 처리부터 검증한다.

~~10월 13일 TQQQ·SOXL 라오어 무한매수 페이퍼 요청은 종목별 독립 가상 계정·고정 USD 예산과 같은 초기 자본·시작일·비용의 정기 분할매수 대조군 방향으로 기록됐다. 기존 국내 변형은 최대 40회·회당 2주·평단 이하 추가 매수·수익 3%부터 트레일링이며 예산 40분할과 동일하지 않다. 공식 규칙 일부는 접근 제한으로 확인하지 못했고 기존 미국 엔진도 LOC 미지원으로 기록돼, 최종 상태는 버전 확인 대기·전략 코드 미변경·가상 매매 미가동이다.~~

10월 13일 후속 구현으로 위 미가동 판단은 갱신됐다. 아래 최종 상태를 참조한다.

실험에서는 비용 후 평가 수익률뿐 아니라 최대 낙폭·미청산 손실·예산 소진·회복 기간·완결/미완결 거래를 함께 비교한다. 추가 입금으로 손실을 가리지 않으며 하락 구간을 포함한 장기 백테스트를 병행하는 안이다. 레버리지 상품의 일간 배율을 여러 날의 누적 배율로 가정하거나 두 종목을 독립적인 분산 자산으로 전제하지 않는다. 이 평가안과 상품 설명은 세션의 검토 내용이며, 수익 우위·실거래 적합성은 미검증이다.

## V1 재현 실험의 후속 적용과 검증 한계

후속 요청으로 기본형 V1을 선택하고, TQQQ·SOXL의 V1 재현 계정과 동일 익절 정기 분할매수 대조군 총 4계정을 가동했다. 각 USD 10,000의 고정 가상 예산이며 추가 입금 없이 예산 소진을 관찰한다. 공식 규칙의 완전한 검증이 없으므로 최신 공식판의 완전 복제가 아닌 **V1 재현 페이퍼**로 기록한다. 일반화할 원칙은 전략 이름뿐 아니라 재현 버전·가정·예산 소진 정책·대조군의 청산 조건까지 고정하는 것이다.

첫 실제 호가 기반 가상 체결은 두 전략 모두 TQQQ 3주·SOXL 2주로 확인됐다. 실행기는 ht_trading, ht_dde는 조회만 담당한다. 실주문 0건이며 동일 실계좌의 공동 위험 관리와 주문 권한 검증은 여전히 미완료다.

LOC는 사전 주문 계획을 종가로 평가하는 가상 모델로 연결했다. 다음 호가 체결·부분매도·재시작 보존 테스트는 보고됐지만 실제 장마감 LOC 처리는 첫 세션 이후 관찰 과제다. 연결 완료와 수익성 검증을 구별한다([[backtest-fill-model-adverse-selection]]).

## 성과 보고는 장부의 마감 평가 이력을 읽는다

최신 평가액만 담은 보고 파일로는 전략별 수익률의 시간 흐름을 비교할 수 없다. 가상매매 장부에 저장된 마감 평가 이력을 읽기 전용 보고로 전달하고, 같은 거래일·마감 시점의 전략과 대조군을 비교한다. 장중 잠정 평가는 마감 평가와 구분하며 투자금·현금 비중과 날짜별 수치를 함께 보여 준다. 조회 화면을 위한 데이터 확장이 매매 규칙이나 기존 장부를 바꾸지 않도록 한다.

10월 15일 후속 세션에서는 미국 거래일 10/13~14의 2일 이력으로 비교 그래프를 연결했다. 짧은 관측 구간을 표시하고, 같은 수익률의 선이 겹칠 수 있음을 고려했다. 그래프·API 연결과 테스트 통과는 보고 기능의 증거이며 전략 우위·추가 LOC 체결 검증을 뜻하지 않는다. 웹 응답 확인과 브라우저 시각 검증도 구분한다. 구체적인 적용 범위와 미검증 항목은 [[ht-dde]]를 참조한다.

## 전략 원형과 구현 변형은 별도 장부로 비교한다

10/17 후속 검토에서는 기존 미국 V1 재현이 첫날 하루 예산 내 가능한 수량을 매수하고, 익절 주문은 다음 거래일부터 내며, 예산 소진 뒤 계속 보유하는 변형임을 명확히 했다. 세션이 대조한 2021년 공개 설명은 첫날 1주·첫날부터 평단 +10% 익절이며 40거래일 뒤 대응도 포함하지만, 그 이후 손실·추가 자금 정책은 확정하지 못했다. 기존 V1 장부를 완전한 원본 복제로 해석하지 않는다.

기존 거래·평가 이력을 유지하면서 TQQQ·SOXL 각각 새 공개규칙 실험과 **같은 날 새로 시작하는 기존 방식 대조군**을 등록했다. 새 네 장부는 각각 USD 10,000이며 첫 가상매수는 10/19 미국장 개장 이후 대기다. 새 실험은 첫날 1주·당일 익절·사전 계획 LOC를 적용하고, 40거래일 이후 추가매수 보류·익절 감시 유지로 제한한다. 미확정 정책을 임의의 원형 규칙으로 기록하지 않으며 수집 중단·복구가 거래일 제한을 우회하지 않도록 검증했다고 보고했다.

규칙 변경 때는 이전 장부를 이어 쓰지 말고 시작일·자본·비용을 맞춘 새 대조군을 둔다. 기존 구현과 같은 입력에서 대조군 장부가 일치하는지도 확인한다. 구현·등록과 첫 체결·성과 검증은 구분한다.

## 매수 횟수·사이클·손익의 분모를 명시한다

예산을 40분할한다는 것은 매수일이 반드시 40회라는 뜻이 아니다. 기존 변형의 사이클은 최초 매수부터 전량 익절까지이며 예산 잔액과 조건에 따라 매수일 수가 달라진다. 같은 날 두 조건 주문이 체결되더라도 매수일은 하루로 집계한다. 두 주문은 예산 절반씩 평단 이하/계획 당시 시세 대비 상한 조건을 적용하는 것으로, 항상 1주+1주를 사거나 시간차로 매수한다는 의미가 아니다. LOC 상한은 허용 가격의 상한이며 가상 체결가는 조건을 만족한 종가다.

보유 손익률의 분모는 매입 원가이고, 계좌 수익률의 분모는 현금 포함 초기 자본이므로 둘을 같은 지표로 표시하지 않는다. 기본 화면에는 최근 매수 수량·매수일·사이클·평단·보유 손익을 두고 계좌 성과와 대조군은 상세로 구분하되 시세 오류·매매 중단 경고는 항상 보이게 했다([[ht-dde]]). 이는 세션의 구현·설명 정정이며 원형 규칙이나 현행 주문 제도를 외부에서 재확인한 기록은 아니다.
