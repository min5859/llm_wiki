# 백테스트 체결 모델과 역선택 — 즉시체결 가정이 은폐하는 것

백테스트의 "지정가 주문은 무조건 즉시 체결" 가정은 단순한 낙관 편향이 아니라, **진입 규칙에 내재한 역선택(adverse selection)을 통째로 은폐**한다. ht_trading 백테스트 신뢰도 검토(2026-07-04)에서 낙관 편향 2개를 순차 제거하며 실측한 결과.

## 1. 슬리피지 dead code (commit ce9724a)

`_calc_fill_price` 가 `order.price` 유무로 슬리피지 적용을 분기하는데, `Strategy.buy/sell` 이 항상 종가로 price 를 채워 **슬리피지 경로가 도달 불가** → 모든 체결이 종가·슬리피지 0. 라이브의 MARKET 매도(ord_dvsn=01)는 `order.price` 를 무시하므로 백테스트가 청산에서 체계적으로 낙관적이었다. 분기 기준을 price 유무 → `order_type` 으로 수정, 기준가도 open → close (신호가 종가에 생성되므로).

## 2. 즉시체결 → 대기 큐 모델이 드러낸 역선택 (commit bbf8fff, 890d860)

지정가를 대기 큐로 변경 (매수금 예약 → 다음 봉 시가가 유리하면 시가, 저가가 닿으면 지정가 체결, 미도달 시 만료 환불) 하자:

- 수익률 **+18.13% → -2.54%**, MDD 24.7% → 43.2%.
- 메커니즘 — **지정가 = 현재가(ratio 1.0)는 "가격이 내려와야만" 체결**된다. 하락 진입(신호 붕괴)은 다 잡히고, 갭업 승자는 놓친다. 모멘텀 전략에서 현재가 미만 대기 호가는 **"공짜 옵션 매도"** 와 같다.
- `limit_price_ratio` 스윕(일봉): `1.0 = -2.5% / 1.005 = +14.7% / 0.99 = +28%` (V자). **+0.5% 프리미엄은 "가격 상한 있는 시장가"처럼 동작**해 역선택을 해소한다.
- 부수 버그: 신규 포지션이 `current_price=0` 으로 생성돼 체결 직후 -100% pnl 로 같은 봉에서 절대손절 오발동.

## 3. 일봉 fill-window 아티팩트 — 스윕의 0.99=+28% 는 가짜 (commit 314082b)

일봉 스윕에서 0.99 (현재가 -1% 대기) 가 최고로 보이지만, 이는 **주문이 하루 종일 살아있다는 일봉 가정** 때문이다. 라이브는 ~26분 창에서 만료된다. 장중 스냅샷 리플레이(11거래일·128체인)로 검증:

```
체결률:  0.99 = 55.5%  /  0.995 = 77.3%  /  1.0·1.005 = 100%
미체결 체인의 당일 종가: +1.1~1.7%   ← 놓친 것이 승자 (역선택 실증)
```

**결론: 일봉 백테스트로는 "짧은 창에서 현재가 미만 지정가가 체결되는가"라는 질문에 답할 수 없다.** 봉 간격 민감도([[backtest-timeframe-sensitivity]])와 다른 축의, 체결 모델 자체의 해상도 한계.

## 일반 원칙

1. **즉시체결/100% 체결 가정은 낙관 편향을 넘어 역선택을 은폐한다** — 어떤 주문이 체결되고 어떤 주문이 만료되는지가 곧 표본 선택이다.
2. **지정가 프리미엄/디스카운트는 체결률과 함께 스윕**해야 한다 — 수익률만 보면 "하루 종일 살아있는 주문" 아티팩트에 속는다.
3. **체결 모델을 바꾸면 과거 파라미터 결정의 근거가 무효**가 된다 — ht_trading 의 `limit_price_ratio` 반전 이력(1.0→1.005→0.995→1.0)은 전부 즉시체결 구모델 하의 결정이라, 신모델 통찰로 1.005 재채택.

## 오프라인 페이퍼의 시간 순서와 재처리 검증

10월 12일 미국 페이퍼 구현에서는 신호가 나온 뒤의 새 호가로만 가상 체결을 판단하고, 수수료·슬리피지·부분체결·만료를 모델에 포함했다. 신호 생성에 사용한 가격으로 곧바로 체결시키는 낙관적 가정을 피하려는 설계다.

같은 합성 입력을 재실행해도 체결 3건·완결 1건이 늘어나지 않았다는 검증 결과가 기록됐다. 이는 시간 순서와 회계·재처리 기능을 확인한 결과이며 체결 가정의 현실성이나 미국 전략 수익성을 입증하지 않는다. 실제 관측 데이터가 연결되기 전에는 합성 결과를 국내 전략 순위나 실제 관측 성과에 합산하지 않는다. 실행·계좌 격리는 [[multi-market-trading-account-isolation]]을 참조한다.

## 장마감 주문은 종가 확인 전에 계획한다

10월 13일 V1 재현 페이퍼는 LOC 사전 계획을 저장한 뒤 종가 기반 가상 체결로 평가하도록 연결했다. 종가를 확인하고 같은 종가로 주문을 소급 생성하면 미래 정보가 진입에 섞인다. 장마감 자료가 누락되면 신규 매수를 보류하며, 부분매도·재시작 후에도 계획과 체결 기록을 보존한다.

첫 호가 기반 체결과 장부 테스트가 통과했다는 보고는 실제 종가 경매의 체결 가능성을 입증하지 않는다. 실제 장마감 처리와 전략 수익성은 별도 관찰 과제로 남았다. 고정기간 백테스트·일반 지정가·LOC 가상 모델의 결과를 동일한 체결 계약으로 취급하지 않는다.

## 종가 신호와 익일 진입은 같은 추천으로 전방 비교한다

10월 14일 후속 RS 분석은 정상 관측 20일·복구 후 2일, 기존 페이퍼 +10.48%·72완결을 보고했다. 그러나 다음 날 진입 참고 시세는 전일 종가보다 최대 15.7% 높았다. 이는 참고 가격차이며 실제 체결 슬리피지나 모든 종목의 평균이 아니다. 종가 기반 성과를 익일 실거래 기대수익으로 그대로 옮길 수 없다.

이를 확인하려고 같은 추천 스냅샷을 고정하고, 같은 초기자본·비용·청산 규칙의 두 새 계정을 만들어 **진입 시점만** 비교했다. 각 계정의 현금·보유·청산 장부는 분리하고 기존 페이퍼 이력은 보존한다. 새 비교군은 앞으로 생성되는 추천부터 시작해 과거 거래를 소급 생성하지 않는다. 익일군은 정해진 시간창의 첫 유효 시세를 사용하며, 결측 시세·중복 실행·재시작·장부 저장 실패는 검증 대상으로 둔다.

이 설계는 추천의 효과와 실행 시점의 영향을 분리하려는 실험이다. 구현 당시 거래 0건이므로 성과 차이나 실거래 체결 가능성은 아직 확인되지 않았다. 실제 주문 전송·체결 추적 연결도 별도 과제다. 구현 일정과 상태는 [[ht-dde]], 비활성 주문 미리보기 범위는 [[ht-trading]]을 참조한다.

## 애프터마켓 가상 체결의 데이터 계약

10/15 후속 구현은 거래시간 숫자만 늘리는 대신 정규장·애프터의 시세, 주문 수명, 마감 평가를 분리했다. 같은 체결 현실성 문제가 국내 시간 확대에서도 반복되므로 기존 분석에 통합한다.

- 진행 중인 분봉과 다른 날짜 자료를 제외하고 완료된 분봉만 사용한다.
- 주문 생성 이후의 다음 호가부터 체결하며, 여러 주문이 같은 호가 잔량을 중복 소비하지 않는다. 부분체결·잔량 만료·재시작·중복 실행을 검증한다.
- 정규장 미체결은 애프터에 자동 이월하지 않고 만료한다. 하루 매수 한도와 재진입 쿨다운은 세션 경계를 넘어 유지하고 정규장/애프터 마감 평가를 나눈다.
- 거래일·장 구분·대상 여부·정지/VI 상태를 확인할 수 없으면 가상 체결을 생성하지 않는다. 가격 조회 성공만으로 체결 가능성을 보증하지 않는다.

세션 보고상 실제 애프터 완료 분봉 240개(16:00~19:59)를 조회했지만 REST 호가에는 거래일·장 구분이 없어 단독으로 체결 가능 입력으로 인정하지 않았다. `87640ff` 기반 코드와 761개 테스트 통과는 보고됐으나, 장중 수집기 연결과 실제 데이터 대조·비교 계정 등록은 미완료다. **자동 페이퍼 운용은 아직 시작하지 않았다.**

비교는 공통 추천의 당일 애프터/익일 진입과, 기존 매수시간을 유지한 매도 감시 연장을 별도 실험으로 나누는 제안이다. 기존 종가 가정의 수익을 실행 가능한 성과로 읽지 않는다. 적용 상태는 [[ht-trading]]을 참조한다.

## 10/16 후속: 관측기 등록과 가상 체결 승인은 다르다

후속 세션은 KIS 호가·체결·장운영정보의 구독 3종 승인 응답을 확인하고 08:55 자동 수집을 등록했다고 보고했다. 당시 개장 전이라 시세 수신은 0건이었다. **구독 승인·수집 등록은 실제 장중 수신·거래 대상/정지/VI 판정 검증의 완료가 아니다.** 자동 애프터 비교 매매는 여전히 시작하지 않았다.

전체 과거 재생에서는 종가를 확인한 뒤 같은 가격으로 체결하는 오류를 막기 위해 15:20~15:30을 평가만 하는 구간으로 검증 중이라고 보고됐다. 이는 해당 재생의 가정이며 거래소 제도로 일반화하지 않는다. 고점 반영 모형에 따라 후보 합집합의 우위가 바뀐 결과도 있어 체결·봉 내 순서 민감도를 함께 제시해야 한다([[scoring-version-comparison-methodology]]). 후속 적용 상태는 [[ht-trading]]을 참조한다.

## 다음 조회 체결 모형도 실제 즉시체결을 놓칠 수 있다 (10/22 후속)

장후/09:35 비교 페이퍼는 매도호가로 가상 지정가를 만들고 약 15초 뒤 호가가 지정가 이하일 때 보이는 잔량만 체결하며 2분 후 잔량을 취소한다고 보고됐다. 미래 정보 사용을 막는 ‘다음 호가’ 계약은 유지할 수 있지만, 주문 시점에 즉시 살 수 있었던 물량이 다음 조회 전에 사라지면 실제로는 매수된 종목을 페이퍼가 미체결로 남길 수 있다. **보수적인 모형도 실제 체결의 정확한 복제가 아니다.**

최종 대조에서 뉴인텍은 새 장후 계정에 매수가 없었고 새 09:35 계정도 849원 가상 주문 후 미체결 취소였다. 실제 매수는 854원이었다. 앞선 ‘아침 페이퍼 약 850원 체결/손실’ 설명을 이 새 계정의 확정 체결로 재사용하지 않는다. 기존 종가형의 약 778원 진입은 별도 연구 장부다. 계좌 합계 손익으로 특정 미체결 종목의 손실을 설명하지 않는다.

질문이 어느 시점의 매수가 더 저렴했는지라면 같은 추천의 장후/익일 09:35 매도호가를 직접 짝지어 비교하고 가상체결·매도손익은 별도로 둔다. 한쪽 호가 누락은 비교 불가로 남긴다. 첫 공통 추천에서 비교 가능한 3종목 중 2종목은 09:35가 저렴했으나 1회 표본으로 우위를 확정하지 않았고 09:35 매수를 유지했다. 최소 공통 진입 5회·각 20완결의 재판정 기준은 이 실험의 합의값이다. 보유 이력·체결 가정이 다른 계정의 성과 비교는 [[paper-to-live-strategy-isolation]]과 함께 읽는다.

## 최종 추천의 과거 종가 체결과 마감 전 후보를 구별한다 (10/23 분석)

세션은 기존 종가형 페이퍼가 16:10경 확정한 추천을 이미 지난 종가에 샀다고 가정한다고 설명했다. 덱스터는 페이퍼의 전일 1,012원 진입·익일 09:13 1,079원 익절과 실거래의 익일 09:35 1,175원 진입·1,116원 손절로 가격 구간이 달랐다. 같은 아침 진입 페이퍼도 손절이었다고 보고됐다. 추천·청산 숫자가 같다는 이유만으로 진입시점이 다른 성과를 동일 전략의 실행 성과로 비교하지 않는다.

최종 제안은 **15:28까지 실제 수신한 자료로 후보를 확정한 뒤 종가 동시호가 체결을 시도**하는 별도 검증이다. 핵심은 몇 분 차이보다 정보가 이용 가능했던 시점이다. 이후 확정 추천을 앞 시점 후보로 소급 대체하지 않고, 당시 후보 스냅샷과 최종 후보의 일치 정도·지정가/물량에 따른 미체결·실제 체결평단과 비용을 확인해야 한다. 종가 체결을 보장하거나 페이퍼 수익을 재현한다고 주장하지 않는다.

이는 앞선 종가 소급 주문 금지 원칙의 국내 후속 사례이며, 세션 말미에는 제안 단계로 실거래 매수시각은 바뀌지 않았다. 거래소 제도 설명은 세션의 조사 보고이고 이번 수집에서 재확인하지 않았다. 주문 보류에 따른 누락은 [[paper-to-live-strategy-isolation]]의 별도 실행 문제다.

## 진입 상한은 체결 모형·투자 노출과 함께 검증한다 (10/24 후속)

앞 절의 마감 전 진입 제안 이후, 실제 반영된 경로는 최종 추천 후 당일 장후 매수이며 15:00 선정·15:28 주문은 비교 후보로 남았다([[ht-trading]]). +3% 상한은 데이터로 최적화한 값이 아니었다. 3거래일 추천 32건 중 장후 유효 최초 호가가 남은 25건은 모두 종가 대비 +2% 이내여서 +3%가 추가로 허용한 최초 기회는 없었다. **호가 통과는 실제 체결률이나 수익의 증거가 아니며**, 누락 7건을 체결된 것으로 간주하지 않는다.

세션이 보고한 10/15~22의 6추천일을 10/23까지 재생한 결과다. 각 초기자본 1천만원·수수료/세금 포함, 실현+평가손익이며 **분봉 기반 가상 결과**다. 실제 장후 체결 성과와 합산하지 않는다.

| 진입안 | 실현+평가손익 | 최대낙폭 | 완결/보유 |
|---|---:|---:|---:|
| 당일 장후, 종가 이하 상한 | +23.7만원 | 2.36% | 33/1 |
| 당일 장후, +3% 상한 | +12.3만원 | 2.79% | 34/1 |
| 익일 09:35, 상한 없음 | -43.9만원 | 5.33% | 42/2 |
| 15:00 선정 → 15:28 종가 주문 | +17.2만원 | 6.55% | 40/2 |

체결량 가정을 넓히면 +3% 상한이 더 유리해져 순위가 뒤집혔다. 따라서 이 표로 종가 이하 상한을 최적값으로 확정하지 않는다. 익일안은 상한도 다르므로 시간 효과만의 추정으로 해석하지 않는다. 종가~+0.5%와 1·2·3%를 같은 조건으로 비교하는 것은 후속 권고이며, 이번 분석에서 운영 상한을 변경하지 않았다.

조기 선정은 먼저 7거래일 최종 선정의 종목·순서를 재현한 뒤 15:00 이후 자료를 빼고 다시 계산했다. 최종 추천 123건 중 122건을 포함하고 5/7일은 구성이 같았지만, 이는 상위 매수 순서·실제 체결·수익 일치를 보장하지 않는다. 15:28안은 장후안보다 평균 투자 노출이 약 2.5배였고 형지I&C 손익을 제외하면 -19.7만원이었다. 종목당 비중을 10%에서 4%로 낮춘 모형은 +14.9만원·최대낙폭 2.40%였으나 특정 종목 의존은 남았다. 전량 전환의 근거로 삼지 않았다.

반복 활용할 검증 순서는 **당시 이용 가능한 정보로 선정 재현 → 현금·보유 한도와 미체결 적용 → 바뀐 진입가로 손절·트레일링 재계산 → 비용·지연·체결량 민감도 확인 → 노출·최고 수익 종목 제외 결과 대조**다. 과거 청산가격을 새 진입가에 그대로 붙이지 않는다. 양쪽 진입 판단이 끝난 공통 추천끼리 비교하고, 미청산 평가손익을 함께 봐야 먼저 진입한 쪽의 성과를 과장하지 않는다.

같은 추천·각 1천만원·같은 비용과 정규장 청산만 쓰는 새 장후/익일 비교도 등록됐다고 보고됐다. 과거 거래를 소급 생성하지 않았고 첫 비교는 10/26 추천 이후 예정이었다. 기존 공통 추천 2회의 장후 실현손익 +43,349원은 한일단조 +124,161원을 빼면 -80,812원이며, 익일군 미청산 2종목과 장후 매도도 포함했다. 이 구형 결과를 새 정규장 청산 비교나 위 분봉 재생의 성과로 혼용하지 않는다.

모든 수치는 지정 세션의 분석 보고이며 원 데이터·코드·테스트를 이번 수집에서 재실행하지 않았다. 단일 출처의 소표본 결과로, 장기 우위나 실거래 기대수익을 확정하지 않는다.
